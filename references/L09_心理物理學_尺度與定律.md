## 1. 四種尺度（Scales）（00:06:19–00:13:44）★★ 必考

| # | 尺度 | 定義 | 老師的例子 |
|---|---|---|---|
| 1 | **Nominal 名目尺度** | **數字只是名字/標籤**，用來區分群組 | **橄欖球背號**：1–4 號打前鋒（攻擊手）、5–8 號中衛、9–11 號後衛。**看背號就知道位置**。足球的 **7 號、10 號** 代表球隊招牌（Messi、C. Ronaldo）——「大家都在搶 7 號」 |
| 2 | **Ordinal 順序尺度** | 依「多/少」排序，**但不告訴你差多少** | 「這個比參考色**暗還是亮**？」；>28°C 是熱、15–28°C 是溫、<15°C 是涼 |
| 3 | **Interval 區間尺度** ✅ | **等距離處處等意義**：10 與 9 的差 = 2 與 1 的差 | A 比 B 亮 1 單位、C 比 D 亮 1 單位 → **兩組差異看起來一樣大** |
| 4 | **Ratio 比例尺度** ✅ | **區間尺度 + 有意義的零點** | **彩度/鮮豔度**：0 = 中性（無色相）；60 的顏色比 40 的**更鮮豔**，而且**倍數有意義** |

> **★ 老師的實務建議：「做實驗通常我們要的是第 3 種和第 4 種。」**

**典型實驗**：比較 Samsung 與 Apple 手機上的同一張影像 → 觀察者只回答「左邊還右邊」→ **再把比例轉換成區間尺度**。

## 2. 三大定律（00:13:44–00:20:16）★★★ 必考

### 2-1 Weber's Law 韋伯定律
**經典實驗**：手上放一個重物 I，一點一點加重量，直到你**剛好察覺到不同** → 加上去的那一份就是 **ΔI**。

```
ΔI / I = k          （基本式）
ΔI / (I + I₀) = k   （含雜訊式，老師講的版本）
```
| 符號 | 意義 |
|---|---|
| **k** | **比例常數 = Weber fraction 韋伯分數**（固定不變） |
| **ΔI** | 為了讓人**察覺到差異**，必須加到 I 上的**增量** |
| **I₀** | **感測機制的內部雜訊（internal noise）** |

**★ 核心洞察**：**不管你起始是 1 公克、10 公克還是 100 公克，ΔI/I 都是同一個常數。**
→ **「差異的察覺是相對的，不是絕對的。」**

**ΔI 就是 JND（Just Noticeable Difference，恰可辨差）。**
老師也提到聲音的版本：先給一個定值噪音，逐漸加，直到你察覺——這是聽覺實驗的做法。

### 2-2 Fechner's Law 費希納定律
把 Weber 的 ΔI 對整個範圍**積分**，得到連續尺度：
```
S = a + b · log₁₀( I + I₀ )
```
> **★ 結論：物理刺激與人的反應成「對數關係」。**

### ★★★ 2-3 Stevens' Power Law —— 投影片有「八種特例」，我原本只記了三種
（教材，標題 *Theory - Stevens's Power Law*）

```
Stevens's power law represents a wide range of psychophysical characteristics.

        s(I) = a·I^P + b            where a, b and P are constants.
```

| 式子 | 條件 | **名稱** |
|---|---|---|
| `s(I) = I` | b=0, a=P=1 | **Absolute scale 絕對尺度** |
| `s(I) = I + b` | a=P=1 | **Difference scale 差異尺度** |
| `s(I) = a·I` | b=0, P=1 | **Ratio scale 比例尺度** |
| `s(I) = b + a·I` | P=1 | **Interval scale 區間尺度** |
| `s(I) = I^P` | a=1 | **Power scale 冪次尺度** |
| `s(I) = b + I^P` | a=1 | **Power scale with a noise factor 含雜訊項的冪次尺度** |
| `s(I) = a·I^P` | b=0 | **Log interval scale 對數區間尺度** |
| `s(I) = b + a·I^P` | （完整式） | **Interval scale with a noise factor 含雜訊項的區間尺度** |

> **★★ 這張表的真正意義（我原本完全沒看出來）：**
> **Stevens 的冪次律是一個「總式」，L09 §1 那四種尺度全部是它的特例。**
> ```
> b = 0, a = P = 1   →  絕對尺度
> b = 0, P = 1       →  比例尺度      ← §1 的第 4 種
> P = 1              →  區間尺度      ← §1 的第 3 種
> ```
> **所以「冪次律更有彈性」不只是修辭——它字面上「涵蓋」了所有尺度型態。**
> 這就是老師說「要描述整個心理物理世界，該用冪次律」的真正理由。

## 3. Thurstone 比較判斷法則（1927）（00:20:16–00:28:16）★★★

**應用場景**：兩張影像並排，觀察者只回答 **「左邊好還是右邊好」** → **二項分布（binomial distribution）**。

**完整式**：
```
Rᵢ − Rⱼ = Zᵢⱼ · √( σᵢ² + σⱼ² − 2·r·σᵢ·σⱼ )
```
| 符號 | 意義 |
|---|---|
| **Rᵢ, Rⱼ** | 刺激 i、j 的**平均反應** |
| **Zᵢⱼ** | **常態離差（normal deviate）**，對應「j 被判定優於 i 的次數比例」 |
| **σᵢ, σⱼ** | 各自的**標準差（discriminal dispersion）** |
| **r** | 兩者的**相關係數** |

### ★★★ 六個 Case 的完整式子（教材 逐字）

| Case | **條件（投影片原文）** | **式子** |
|---|---|---|
| **I** | **Replication over ONE observer** | `Rᵢ − Rⱼ = zᵢⱼ √(σᵢ² + σⱼ² − 2rᵢⱼσᵢσⱼ)` |
| **II** | **Replication over OBSERVERS** | `Rᵢ − Rⱼ = zᵢⱼ √(σᵢ² + σⱼ² − 2rᵢⱼσᵢσⱼ)`（同上式） |
| **III** | **Independent process, rᵢⱼ = 0** | `Rᵢ − Rⱼ = zᵢⱼ √(σᵢ² + σⱼ²)` |
| **IV** | **Case III, rᵢⱼ = 0 且 σᵢ ~ σⱼ** | `Rᵢ − Rⱼ = zᵢⱼ √(σᵢ² + σⱼ²) · (√2 / 2)` |
| **★ V** | **Case III, rᵢⱼ = 0 且 σᵢ = σⱼ** | **`Rᵢ − Rⱼ = zᵢⱼ · σ · √2`** |
| **VI** | **Process is a constant** | `Rᵢ − Rⱼ = zᵢⱼ √(2(1 − rᵢⱼ))` |

> **★ Case I 與 II 的式子一模一樣**——差別只在**資料怎麼來的**：
> **Case I = 一位觀察者重複多次；Case II = 多位觀察者各判一次。**
> （這正好對應老師課堂上說的「一人判 1000 次 = 1000 人各判一次」。）

**★ 95% 信賴區間的推導**：
```
Case V:  Rᵢ − Rⱼ = zᵢⱼ · σ√2

★ Because R has a scale of (σ√2)^(1/2), thus the 95% confidence interval is calculated by

     ± 1.96 · σ/√N     ⟹     ★ ± 1.96 / (√N · √2)
```
> ✅ 我筆記裡的 `1.96 / (√n · √2)` 得到確認，而且投影片給了它的來歷。

> **★ 老師的結論：「以後你做成對比較（pair comparison），就用 Case III 和 Case V。」**

**★ 有趣的觀念（00:24:15）**：
> **「你可以只用『一位觀察者判 1000 次』，也可以用『1000 位觀察者各判一次』——這個方程式兩種情況都成立。」**
> 前者是「跟自己比」，後者是「跟一群人比」。

**信賴區間**：
```
95% CI 的單位 = 1.96 / ( √n · √2 )
```

## 4. Torgerson 類別判斷法則（1954）（00:28:16–00:32:44）★★

**Thurstone 的延伸**：把「兩兩比較」擴展到「**給一個類別分數**」。

```
Bₖ − Rⱼ = Zⱼₖ · √( σₖ² + σⱼ² − 2·rⱼₖ·σₖ·σⱼ )
```
- **B = category boundary 類別邊界**（取代原式中的另一個刺激）
- **Zⱼₖ**：j 被判在邊界 k 以下的次數所對應的常態離差

**老師示範的量表設計**：
```
−3 = 非常差   −2 = 差   −1 = 有點差 │ +1 = 有點好   +2 = 好   +3 = 非常好
```

**★★ 為什麼「不設 0」？（00:29:47）** 這是老師的實務金句：
> **「你可以設 0，但不建議。因為只要有 0，很多人就會直接選 0——
> 我們做這種事的時候都很懶、都想站在安全的一邊。
> 所以要用 forced choice（強迫選擇），逼觀察者做出決定。」**

**結果轉換**：`−3 ~ +3` → 平移成 **`1 ~ 7`**（一般不希望出現負數）。
例：Samsung 的平均值是 **−1.5** → 落在「差」與「有點差」之間。

**兩者的差別（00:32:14）**：
| | 成對比較（Thurstone） | 類別判斷（Torgerson） |
|---|---|---|
| 任務 | **只比兩個，二選一** | **看一個，給一個級距分數** |
| 認知負荷 | **簡單** | **需要更多思考**（是「好」還是「非常好」？還是介於中間？） |

## 5. 常態分布與 z 值（00:32:44–00:39:12）

- **z = (每個樣本值 − 平均) / 標準差** → **normal deviate 常態離差**
- **1 個 z ≈ 68%；2 個 z ≈ 95%**（老師口述 65% / 95%）
- **累積常態分布（cumulative normal）**：把機率密度積分並歸一化到 0–1，就能把「**多少比例的人覺得 J 比 I 好**」換算成 z。
- **實作**：不必手算積分，**Excel 的 NORMSDIST / NORMSINV** 直接算。
- **F 值定義**：`F = (i 被判優於 j 的次數) / n`
  - 100 人全選 A → F = 1
  - 一半一半 → F = 0.5（對應 z = 0）
### ★★★ 邏輯斯（LG）函數的「確切式子」
```
Logistic (LG) Functions to approximate the relationship between
proportions and standard normal deviates

★ LG₁ = ln[ (f_ij + 0.5) / (N − f_ij + 0.5) ]              （圖：LG1 對 z，N=20 時幾乎完美直線）

★ MS Excel function: NORMSINV()
```

> **★★ 注意分子分母都加了 `+ 0.5` —— 這正是我在 L10 補註裡提到的
> 「Haldane / Berkson 連續性修正」，用來處理 `f = 0` 或 `f = N` 的極端格。**
>
> ```
> f = 0  →  LG₁ = ln(0.5 / 20.5)   ← 有限值，不會發散
> f = N  →  LG₁ = ln(20.5 / 0.5)   ← 有限值
> ```
> **所以老師教的「先做 logistic matrix 再轉 Z」，其修正機制就內建在這個 +0.5 裡。**
> 這解決了我原本標為「要在論文裡說明用了哪種修正」的疑問——**他用的就是 +0.5 法。**
>
> 圖上顯示 **LG₁ 對 z 幾乎是完美直線（N=20）**，這就是「用邏輯斯近似常態」可行的理由。
> **Excel 實作：`NORMSINV()`**（✅ 我的勘誤正確）。

## 6. ★ 五（六）種心理物理方法（00:39:41–00:44:10）必考清單

### ★★★ 投影片對「閾值」與「匹配」的鏡像定義（教材 逐字）
```
1. Thresholds
   – A discrimination process of finding a stimulus that ★ CAN BE distinguished
     as different from a standard stimulus.

2. Matching
   – A discrimination process of finding a stimulus that ★ CANNOT BE discriminated
     from a standard stimulus.

3. Measuring difference
   – Rank order, pair comparison, categorical judgement and rating

4. Direct ratio scaling
   – Magnitude estimation and production, ratio estimation and production
```

> **★★ 這組定義是完美的鏡像，比我原本的寫法清楚太多：**
> ```
> 閾值法：找一個「剛好『能』被分辨出來」的刺激   →  找差異的下限
> 匹配法：找一個「剛好『不能』被分辨出來」的刺激 →  找相同的上限
> ```
> **兩者都是「辨別歷程（discrimination process）」，只是方向相反。**

| # | 方法 | 做什麼 |
|---|---|---|
| 1 | **Threshold 閾值法（JND 法）** | 找出「**剛好『能』與標準刺激區分**」的刺激量 |
| 2 | **Matching 匹配法** | 找出「**剛好『不能』與標準刺激區分**」的刺激量 |
| 3 | **Rank Order 排序法** | 「這五支手機的影像品質，**從好到壞排出來**」 |
| 4 | **Paired Comparison 成對比較法** | **兩兩比較，二選一** → Thurstone |
| 5 | **Categorical Judgement 類別判斷法** | **只看一個**，給 −3 到 +3 的分數 → Torgerson |
| 6 | **Rating Scale 評分法** | 以標準 = 1，比標準好 → 2、3；比標準差 → 0.5、0.3 |
| 7 | **Direct Ratio Scaling / Magnitude Estimation 直接比例估計** | 「這個色的鮮豔度是 20，請給另一個色打分」→ 先問**更鮮豔還是更不鮮豔**，再問**幾倍** |

> **★ 老師的收尾提醒（00:44:10）：**
> **「所有這些實驗，你都必須訓練觀察者，讓他們完全清楚自己要做什麼。這非常重要。」**

## 🔍 與標準說法的出入 / 需要留意

### 1. Fechner 的年份
- 老師說 **1850**。這是 **Fechner 在 1850 年 10 月 22 日早晨獲得靈感的日子**（心理學界稱為 **Fechner Day**）。
- **正式出版《Elemente der Psychophysik》是 1860 年**。
- 兩個年份都對，但意義不同；答題寫 1860（著作）較安全，可加註 1850（構想）。

### 2. Weber 的年代講成「1990 年代」
- **Ernst Heinrich Weber 的實驗發表於 1834 年**。屬記錄或口誤。
- 記憶順序：**Weber (1834) → Fechner (1860) → Thurstone (1927) → Torgerson (1954) → Stevens (1957)**。

### 3. 「1 個 z ≈ 65%」
- 正確是 **68.27%**（±1σ）、**95.45%**（±2σ）、**99.73%**（±3σ）。
- 常用的 **95% 對應 1.96σ**（老師後面用 1.96 是對的）。

### 4. Case III 與 Case V 的敘述在課堂上有些跳動
- 標準定義：
  - **Case III**：**r = 0**，但 **σᵢ ≠ σⱼ**（各刺激的辨別離散度不同）
  - **Case V**：**r = 0 且所有 σ 相等** → 尺度單位固定為 √2·σ，實務上直接設為 1
- **Case V 是實務上壓倒性最常用的**（因為只需要比例資料，不需要估各自的 σ）。
- 老師講到一半自己修正過來了，方向沒錯。

### 5. Stevens 冪次律的實用價值（老師沒展開，補上）
Stevens (1957) 的 `S = k·I^n`，**指數 n 隨感覺型態差很多**，這才是它的威力：
| 感覺 | 指數 n |
|---|---|
| **明度 / 亮度（brightness）** | **≈ 0.33（立方根）** |
| 響度（loudness） | ≈ 0.67 |
| 重量 | ≈ 1.45 |
| 電擊 | ≈ 3.5 |

**★ 關鍵連結：CIELAB 的 L\* 用「立方根」，正是 Stevens 明度指數 ≈ 1/3 的直接體現。**
換句話說，**你之後要背的 L\* 公式，理論根據就在這一節。**

反過來，**Fechner 的對數律**則活在**攝影密度（density）、聲音的分貝（dB）**等領域。
現代共識：**冪次律在中高刺激範圍描述得比對數律好**，但兩者在有限範圍內差異不大。

### 6. 「不要設中間點 0」是設計偏好，不是鐵律
- 老師的理由（**觀察者會偷懶選中間**）是真實存在的 **central tendency bias / 中間點偏誤**。
- 但學界對「奇數點 vs 偶數點量表」仍有爭論：**強迫選擇**能避免中間偏誤，但也可能**製造出不存在的偏好**（觀察者其實真的覺得一樣）。
- 折衷做法：**允許「無法判斷」但另外記錄**，或改用**成對比較 + 允許平手（ties）**。
- 老師的立場很明確：**forced choice**。實作時照他的做法即可，但要知道這是一個有取捨的設計決定。

### 7. 「一位觀察者判 1000 次」= 「1000 位觀察者各判一次」的但書
- Thurstone 的 **Case I / Case II** 確實在數學上等價。
- **但實務上兩者測到的東西不同**：
  - 單人重複 → 測的是**個人的辨別離散度（discriminal dispersion）**
  - 多人各判 → 測的是**族群的個體差異（inter-observer variability）**
- 色彩研究通常**兩者都要**：用 **重複性（repeatability）** 與 **觀察者間一致性（accuracy / inter-observer variability）**兩個指標來報告，通常以 **STRESS** 或 **PF/3** 表示。老師在色差那一節會用到。
