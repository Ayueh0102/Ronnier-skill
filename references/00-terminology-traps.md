# 專有名詞辨異：那些中文長得一樣、意思完全不同的詞

> **這一份專治「亮度 / 明度 / 光度 / 彩度 / 色度 / 飽和度」這一類的混淆。**
> 學色彩學最容易卡住的地方不是公式，是**你以為你懂那個詞了，其實你懂的是另一個詞**。

---

## 為什麼會混？—— 先講清楚這件事不是你的錯

**英文在「明暗」這個概念上有 9 個不同的詞，在「鮮豔」上有 6 個。中文常用的只有兩三個字。**

```
英文：Luminous flux / Luminous intensity / Illuminance / Luminance /
      Luminance factor / Brightness / Lightness / Value / Darkness
                              ↓  被翻成  ↓
中文：      光通量 / 發光強度 / 照度 / 亮度 / 亮度因數 / 明亮度 / 明度 / 明度 / 暗度
                              ↓  但口語上  ↓
                     「亮度」「明度」兩個詞被拿來混用
```

**更麻煩的是：翻譯用的字有重疊。**
- **`亮`** 出現在：**亮**度（Luminance，物理）、明**亮**度（Brightness，知覺）、**亮**度因數（Y，比值）
- **`明`** 出現在：**明**度（Lightness）、**明**亮度（Brightness）、**明**視覺（Photopic）
- **`色`** 出現在：**色**度（Chromaticity，座標）、彩度…等一下，彩度沒有色 —— 但**色**度和**彩**度只差一個字，意思天差地遠

**所以要先建立兩把刀，把所有詞切開。**

---

## ★★★ 第一把刀：這個詞是「物理量」還是「知覺量」？

```
┌─────────────────────────────────────────────────────────┐
│  物理量（光度學 photometry）                              │
│  · 用儀器量得出來                                         │
│  · 有單位（lm、cd、lx、cd/m²）                            │
│  · 跟「有沒有人在看」無關                                  │
│  · 英文字根多半是  lumin- / illumin-                      │
└─────────────────────────────────────────────────────────┘
                          ↕  中間隔著「人眼」
┌─────────────────────────────────────────────────────────┐
│  知覺量（色貌 colour appearance）                         │
│  · 只能靠「問人」量出來（心理物理實驗）                     │
│  · 沒有物理單位，只有尺度                                  │
│  · 換個觀看條件，數值就變                                  │
│  · 英文字是  Brightness / Lightness / Colourfulness ...   │
└─────────────────────────────────────────────────────────┘
```

**★ 一句話判準**：
> **「這個量，用分光光度計量得出來嗎？」**
> 量得出來 → 物理量。量不出來、只能問人 → 知覺量。

---

## ★★★ 第二把刀：這個知覺量是「絕對」還是「相對」？

**這把刀只切知覺量那一半，但它是整堂課最重要的一刀**（老師說「這題 100% 會考」）。

```
絕對量：沒有分母。燈開亮，數值就變大。
        Brightness (Q) 、 Colourfulness (M)

相對量：分母是「參考白」。燈開亮，白也一起變亮，比值不變。
        Lightness (J)  、 Chroma (C)

比值的比值：分子分母都在同一個條件下取。
        Saturation (s) = M/Q = C/J
```

**★ 生活例子（把三種一次串起來）**：同一張紅紙，拿到窗邊 vs 拿到室內

| 量 | 窗邊（亮） | 室內（暗） | 為什麼 |
|---|---|---|---|
| **Q 明亮度** | 大 | 小 | 絕對量，跟著光走 |
| **M 鮮豔度** | 大 | 小 | 絕對量，跟著光走（**這就是 Hunt effect**） |
| **J 明度** | 幾乎不變 | 幾乎不變 | 都跟旁邊的白紙比 |
| **C 彩度** | 幾乎不變 | 幾乎不變 | 都跟白紙的明亮度比 |
| **s 飽和度** | **完全不變** | **完全不變** | 分子分母同步變，抵銷掉了 |

# 一、明暗這一族（最大的坑）

## A. 物理量 —— 光度學的四兄弟

**先搞懂一件事：這四個量描述的是「光在旅程的哪一段」。**

```
        💡 光源
         │
         │  ① Luminous flux 光通量  —— 光源總共放出多少光
         │     「這顆燈泡有多亮」（不管往哪射）
         │
         │  ② Luminous intensity 發光強度 —— 往「某一個方向」放出多少
         │     「這支手電筒的光束有多強」
         ▼
    ┌─────────┐
    │  桌面    │  ③ Illuminance 照度 —— 打「到」桌面上多少光
    └─────────┘     「這張桌子上夠不夠亮讀書」
         │
         │  ④ Luminance 亮度 —— 桌面反射「出來」、進到你眼睛的有多少
         ▼        「這張桌子看起來多亮」
        👁
```

| 英文 | 中文 | 符號 | 單位 | 白話 |
|---|---|---|---|---|
| **Luminous flux** | **光通量** | Φ_v | **lm（流明）** | 光源總輸出。買燈泡看的就是這個 |
| **Luminous intensity** | **發光強度** | I_v | **cd（燭光）** | 每單位立體角的光通量 |
| **Illuminance** | **照度** | E_v | **lx（勒克斯）= lm/m²** | **★ 光「照到」表面上** |
| **Luminance** | **亮度** | L_v | **cd/m²（尼特 nit）** | **★ 光從表面「射出來」朝向觀察者** |

### ★★★ 照度 vs 亮度 —— 這一組一定要分清楚

```
Illuminance 照度  =  進來的（incident）    單位 lux    量的是「光源給了多少」
Luminance   亮度  =  出去的（emergent）    單位 cd/m²  量的是「眼睛收到多少」
```

**為什麼重要**：**本課兩個關鍵規格分別用不同的量**
- **CIEDE2000 的參考條件寫 `1000 lux`** → 那是**照度**（燈箱打在樣品上）
- **CIECAM02 的輸入 `L_A` 寫 `cd/m²`** → 那是**亮度**（適應場射向眼睛的）

**★ 把 lux 直接餵進 L_A 是實作上最常見的錯誤之一。** 粗略換算：
```
L_A ≈ (照度 × 樣品的 Y%) / (100 × π)        單位 cd/m²

例：1000 lux 打在 Y=20 的灰背景上
    L_A ≈ (1000 × 20) / (100 × 3.1416) ≈ 64 cd/m²
```

**★ 同一顆燈泡，照度隨距離變（平方反比），但被照物體的亮度也跟著變。**
而**光源自己的亮度不隨距離變** —— 這就是為什麼遠處的路燈仍然刺眼。

### ★ 還有一組：輻射量（Radiometric）—— 沒有經過人眼加權

| 光度量（有 V(λ)） | 輻射量（沒有 V(λ)） | 中文 |
|---|---|---|
| Luminous flux（lm） | **Radiant flux**（W） | 輻射通量 |
| Illuminance（lx） | **Irradiance**（W/m²） | 輻照度 |
| Luminance（cd/m²） | **Radiance**（W/sr·m²） | 輻射亮度 |

> **差別只有一件事：光度量乘過 `V(λ)`（明視覺光效函數），輻射量沒有。**
> **所以 555 nm 的綠光與 450 nm 的藍光，輻射功率相同時，光通量差非常多。**
> **紫外線的輻射通量很大，但光通量是 0 —— 因為 V(λ) 在那裡等於 0，人眼看不見。**

## B. 那個介於中間的：Luminance factor 亮度因數

| 英文 | 中文 | 符號 | 單位 | 是什麼 |
|---|---|---|---|---|
| **Luminance factor** | **亮度因數** | **β 或 Y** | **無單位（0–100）** | **樣品的亮度 ÷ 完全漫反射體的亮度** |

**★ 這就是 XYZ 裡的那個 `Y`。**

```
Y = 100  →  完全白（完全漫反射體 PRD）
Y =  20  →  中灰（CIECAM02 的預設背景 Y_b）
Y =   0  →  全黑
```

> **★ 它是物理量還是知覺量？—— 物理量，但它是「比值」，所以沒有單位。**
> **這就是為什麼 Y 可以同時出現在物理計算與知覺模型裡** ——
> 它是**物理世界通往知覺世界的那道門**。
>
> **⚠️ 陷阱：`Y = 20` 的灰，看起來大約是「中灰」，但它不是 `L* = 50`。**
> ```
> Y = 20  →  L* = 51.84   （接近，所以中灰的 Y 才會取 20）
> L* = 50 →  Y  = 18.42
> ```
> **`Y` 是線性的物理量，`L*` 是立方根壓縮過的知覺量。兩者不是同一件事。**
>
> ### ★★ 一個很值得記的巧合：**「中灰」在三個系統裡都指向同一個地方**
> ```
> Munsell Value  V = 5     →  Y = 19.77   （代五次多項式）
> CIELAB         L* = 51.8 →  Y = 20
> CIECAM02 預設背景         →  Y_b = 20
> ```
> **三個系統各自獨立發展，最後都落在 `Y ≈ 20`。**
> **這不是巧合 —— 那是「人眼覺得剛好一半」的物理反射率。**
> **★ 而它離「物理上的一半」（Y = 50）差非常遠**：
> 你以為的中灰，其實只反射了 **兩成** 的光。
> **這就是明度為什麼要開立方根**：人眼對暗部的分辨力遠高於亮部。

## C. 知覺量 —— 明暗這一族的四個詞

| 英文 | 中文 | 符號 | 尺度 | 定義 |
|---|---|---|---|---|
| **Brightness** | **明亮度**（也有人寫「視亮度」） | **Q** | **0 → 開放** | 一個區域顯得**發出/反射較多或較少的光** |
| **Lightness** | **明度** | **J**（CIECAM）<br>**L\***（CIELAB） | **0–100** | **相對於「參考白」**顯得較多或較少的光 |
| **Value** | **明度** | **V** | **0–10** | **Munsell 系統自己的明度尺度** |
| **Darkness degree** | **暗度** | **D** | **0–10（方向相反）** | **DIN 系統**：以「同色度的最佳色」為原點的相對亮度 |

### ★★★★ 全課最大的坑：**亮度 ≠ 明亮度 ≠ 明度**

```
Luminance   亮度     物理量   cd/m²    儀器量的
Brightness  明亮度   知覺量   絕對     人看的，燈亮就大
Lightness   明度     知覺量   相對     人看的，跟白比
```

**三個中文詞只差一個字，三個英文詞完全不同，而且分屬兩個世界。**

**★ 為什麼一定要分？舉個例子：**

> 你在**強光下**看一張灰紙，和在**暗處**看同一張灰紙。
> - **Luminance（亮度）**：強光下高、暗處低 —— **儀器量得出來，差很多倍**
> - **Brightness（明亮度）**：強光下高、暗處低 —— **你也覺得它比較亮**
> - **Lightness（明度）**：**兩邊幾乎一樣** —— **你兩次都說「這是一張中灰的紙」**
>
> **★ 最後這一點就是「色恆常」。**
> 你的視覺系統把「這張紙有多亮」（會變）換算成「這張紙是什麼顏色」（不會變）。
> **Lightness 才是你真正在判斷的東西，Luminance 只是進入眼睛的原始訊號。**

### ★★ Value（Munsell 明度）與 Lightness（CIE 明度）的關係

**兩個中文都叫「明度」，但尺度不同：**
```
Munsell Value   V  :  0 – 10       （0 = 黑，10 = 白）
CIELAB L*          :  0 – 100      （0 = 黑，100 = 白）

粗略換算：  L* ≈ 10 × V            （只是近似，兩者的曲線不完全相同）
```
**★ 講「明度 5」時，一定要問清楚是 Munsell 的 5（中灰）還是 L\* 的 5（幾乎全黑）。**

### ★★ DIN 的 Darkness Degree（暗度）—— 方向是反的

```
Munsell Value   V = 0 是黑，V = 10 是白       （越大越亮）
DIN Darkness    D = 0 是最亮，D = 10 是黑     （★ 越大越暗）
```
**★ 而且 D 的「最亮」不是白，是「該色度的最佳色（optimal colour）」。**
所以同一個 D 值，黃色與藍色的實際 Y 可以差非常多。

# 二、鮮豔這一族

| 英文 | 中文 | 符號 | 分母是什麼 | 絕對/相對 |
|---|---|---|---|---|
| **Colourfulness** | **鮮豔度**（也譯「色彩度」） | **M** | **沒有分母** | **絕對** |
| **Chroma** | **彩度** | **C** | **參考白的 brightness** | **相對** |
| **Saturation** | **飽和度** | **s** | **★ 它自己的 brightness** | 比值的比值 |

```
        Colourfulness              Colourfulness
C  =  ────────────────      s  =  ──────────────      ⇒  s = M/Q = C/J
      Brightness_white              Brightness
              ↑                          ↑
          白的亮度                   自己的亮度
```

### ★★★ 彩度 vs 飽和度 —— 差在分母

**這是老師說「100% 會考、大家都被搞混」的那一題。**

> **用一個例子分開它們**：一面**紅色的牆**，一半在陽光下、一半在陰影裡。
>
> - **Chroma（彩度）**：**陽光那半比較高**。因為分母是「那個場景的白」，
>   但陰影那半的紅色本身就少了很多彩色訊息。
> - **Saturation（飽和度）**：**兩半一樣**。因為分母是「它自己的明亮度」，
>   陰影裡光少了，紅色的量也少了，比值不變。
>
> **★ 所以你會說「這整面牆是同一種紅」——你判斷的是 saturation。**
> **而你也看得出「陽光那半比較鮮豔」——你判斷的是 colourfulness / chroma。**
> **兩件事同時成立，因為它們是不同的量。**

### ★★★★ 色度（Chromaticity）≠ 彩度（Chroma）—— 只差一個字，完全不同

```
Chromaticity  色度   =  一組「座標」(x, y) 或 (u', v')     ← 不是「量」，是「位置」
Chroma        彩度   =  一個「量」，離中性軸多遠           ← 是「量」
```

**★ 這是中文特別容易死的一組。**
- 「這個顏色的**色度**是 (0.31, 0.32)」 ✅ 座標
- 「這個顏色的**彩度**是 40」 ✅ 量
- ~~「這個顏色的色度很高」~~ ❌ **語意不成立**，座標沒有高低

> **★ 記憶法**：**色度圖（chromaticity diagram）上的每一個「點」，就是一個色度。**
> **色度不帶亮度資訊** —— 這正是為什麼 `xy` 只有兩個數，而 `XYZ` 有三個。
> ```
> XYZ  =  色度（xy，兩個數）  +  亮度（Y，一個數）
> ```

### ★ 純度（Purity）—— 物理版的「鮮豔」

| 英文 | 中文 | 是什麼 |
|---|---|---|
| **Excitation purity** | **刺激純度** | 在色度圖上，「白點 → 樣品點」佔「白點 → 光譜軌跡」的**百分比** |
| **Colorimetric purity** | **色度純度** | 另一種定義，用亮度加權 |

> **★ 純度是「用尺在色度圖上量出來的」，是物理/色度量；彩度是「問人問出來的」，是知覺量。**
> **Ostwald 色序系統的 `full colour` 就是定義在「最大可得刺激純度」上** ——
> 也正因為綁死在當時買得到的顏料，每出一款更飽和的新顏料就過期一次，最後停產。

### ★ NCS 的自用詞

| NCS 用詞 | 中文 | 符號 |
|---|---|---|
| **Blackness** | **黑度** | s |
| **Chromaticness** | **彩度** | c |
| **Whiteness** | **白度** | w |

> `w + s + c = 100`。**注意 NCS 的 `chromaticness` 與 CIE 的 `chroma` 不是同一個量**，
> 只是中文都翻「彩度」。

# 三、色相這一族

| 英文 | 中文 | 符號 | 用在哪 |
|---|---|---|---|
| **Hue** | **色相** | — | 泛稱 |
| **Hue angle** | **色相角** | **h** | **★ 算色差**（0°–360°） |
| **Hue composition** | **色相組成** | **H** | **★ 描述色貌**（如 `Y50R`） |
| **Unique hue** | **唯一色相** | — | **紅黃綠藍**四個，不帶其他成分 |
| **Dominant wavelength** | **主波長** | λ_d | 物理版的色相 |

**★ 為什麼要有兩個色相屬性？**
```
Hue composition (H)  →  給人看的     「這是帶 50% 紅的黃」
Hue angle       (h)  →  給電腦算的   「這是 87.3 度」
```

**⚠️ 而且 `h` 不能直接相減當距離用**（角度不是距離）：
```
ΔH* = 2 √(C₁ · C₂) · sin(Δh / 2)        ← 老師說「這條一定要記住」
```

# 四、其他常混的成對詞

| A | B | 差在哪 |
|---|---|---|
| **Illuminant 照明體** | **Light source 光源** | **★ 照明體是「一組數表」，光源是「一個實體」。**<br>D65 是照明體（世界上做不出來），D65 simulator 是光源（燈箱裡那支燈） |
| **Reflectance 反射率** | **Reflectance factor 反射因數** | 反射率是絕對比例；反射因數是「相對於完全漫反射體」。<br>實務上量到的幾乎都是**反射因數** |
| **Tristimulus values 三刺激值** | **Chromaticity coordinates 色度座標** | **XYZ 三個數（含亮度）** vs **xy 兩個數（不含亮度）** |
| **Photopic 明視覺** | **Scotopic 暗視覺** | 錐細胞（>10 lux）vs 桿細胞（<0.1 lux）。中間叫 **Mesopic 中間視覺** |
| **Metamerism 同色異譜** | **Colour constancy 色恆常** | **同色異譜是「兩個樣品」的事**（換條件就不配）<br>**色恆常是「一個樣品」的事**（換條件會不會變色） |
| **Colour difference 色差** | **Colour inconstancy 色不恆常** | 前者比「兩個顏色」，後者比「同一個顏色在兩個光源下」 |
| **CCT 相關色溫** | **Colour temperature 色溫** | **色溫**只用於**落在黑體軌跡上**的光源；<br>不在軌跡上的只能講**相關**色溫（CCT） |

# 五、中文 → 英文 反查表（你想講的是哪一個？）

| 你說的中文 | 可能是 | 怎麼分辨 |
|---|---|---|
| **「亮度」** | **Luminance**（cd/m²，物理） | 有單位、儀器量的 → 就是它 |
| | Brightness（明亮度，知覺） | 在講「看起來多亮」→ 應該說**明亮度** |
| | Lightness（明度，知覺） | 在講「這是深色還淺色」→ 應該說**明度** |
| **「明度」** | **Lightness / L\***（0–100） | CIE 體系 |
| | **Munsell Value**（0–10） | 講色票時 |
| **「彩度」** | **Chroma / C\***（÷ 白的亮度） | CIE 體系 |
| | NCS chromaticness | 講 NCS 時 |
| **「飽和度」** | **Saturation**（÷ 自己的亮度） | 色彩學 |

# 六、老師課堂上的用字習慣（聽逐字稿時要注意）

- 他講 **"brightness"** 時，**大多數情況指的是知覺的明亮度 Q**，但偶爾口語上會拿來泛指「亮」
- 他講 **"luminance level"** 時指的是**物理亮度水準**（例如「1000 lux」「2 cd/m²」）
- **★ Hunt 的投影片用 `ρ γ β` 表示三種錐細胞，其他地方用 `L M S`** —— 同一件事的兩套符號
- 逐字稿把 **CIELAB 與 CIELUV 都寫成 "C-Lab"**，要靠上下文分辨

# 七、寫論文 / 答題時的建議

**① 第一次出現時，中英並列。**
> 「明度（lightness, J）」「亮度（luminance, cd/m²）」

**② 只要在講「量」，就把單位或尺度寫出來。**
> 「背景為 `Y_b = 20`」比「背景為中灰」精確得多。

**③ ★ 絕對量與相對量不要混著比。**
> 不要說「A 的 colourfulness 比 B 高」卻沒說兩者在同一個觀看條件下 ——
> 換個燈就翻盤了。**要比就比 chroma。**

**④ ★★ 遇到「亮度」兩個字，先自問：這是 cd/m² 還是「看起來」？**
> 這一問可以擋掉這門課八成的誤解。
