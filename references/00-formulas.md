## 1. 三刺激值 XYZ

**物體色（反射/透射）**
```
X = k · Σ S(λ)·R(λ)·x̄(λ)·Δλ
Y = k · Σ S(λ)·R(λ)·ȳ(λ)·Δλ
Z = k · Σ S(λ)·R(λ)·z̄(λ)·Δλ

k = 100 / Σ S(λ)·ȳ(λ)·Δλ        ← 使白（PRD）的 Y = 100
```
**自發光色（顯示器/光源）**：不含 R(λ)，只用 CMF × SPD；通常用絕對歸一（Y = cd/m²）。 → `L02`

**色度座標**
```
x = X/(X+Y+Z) ,  y = Y/(X+Y+Z) ,  z = Z/(X+Y+Z)      x+y+z = 1
r = R/(R+G+B) ,  g = G/(R+G+B) ,  b = B/(R+G+B)      r+g+b = 1
```
**完整規範 = (x, y, Y)**。 → `L02`

**激發純度**
```
p_e = NQ / NP        （N=白點, Q=樣品, P=光譜軌跡交點）
λ_d = 主波長；紫色系改用 λ_c 補色波長
```

## 2. 物體的光學性質

**Snell's Law**
```
n₁ · sin θ₁ = n₂ · sin θ₂
```

**Fresnel 反射率（垂直入射）**
```
ρ = [ (n₂ − n₁) / (n₂ + n₁) ]²        n₂=1.5 → ρ ≈ 4%
```

**Lambert–Beer**
```
A = ε · c · l
A = log₁₀(100 / T%) = log₁₀(I₀ / I_T)
★ 吸光度可加：A₁ + A₂ = A(混合)
```

**Kubelka–Munk**
```
K/S = (1 − R∞)² / (2 R∞)
K = 吸收係數, S = 散射係數；K/S 可加 → 電腦配色 (CCM) 的基礎
```
→ `L03`

## 3. 量測不確定度

```
U_T = √( U_A² + U_B² )

U_A = 隨機誤差 (Type A) = MCDM／重複性
U_B = 系統誤差 (Type B) = √( U_N² + U_D² )
      U_N = 頂級實驗室的認證不確定度
      U_D = 你的儀器量 transfer standard 與認證值的差
```

**MCDM（Mean Colour Difference from the Mean）**
```
① 同一樣品量 31 次 → ② 丟掉第 1 次 → ③ 剩 30 組算 L*a*b*
④ 算平均 L*a*b* → ⑤ 各組對平均算 ΔE → ⑥ 30 個 ΔE 取平均 = MCDM
```

**螢光樣品的三個輻射因數**
```
β_T = β_S + β_L
（總 = 反射 + 螢光發光）
```
→ `L04`, `L05`

## 5. 心理物理三大定律

```
Weber   :  ΔI / (I + I₀) = k                    （k = Weber fraction；ΔI = JND）
Fechner :  S = a + b · log₁₀(I + I₀)            （對數關係）
Stevens :  S = a · I^p + b                      （冪次關係）
           明度指數 p ≈ 0.33（立方根）← CIELAB L* 的理論根據
```

**Thurstone 比較判斷法則 (1927)**
```
Rᵢ − Rⱼ = Zᵢⱼ · √( σᵢ² + σⱼ² − 2·r·σᵢ·σⱼ )

Case III : r = 0
Case V   : r = 0 且 σᵢ = σⱼ  → 尺度單位 = 1（最常用）
95% CI 單位 = 1.96 / (√n · √2)
```

**Torgerson 類別判斷法則 (1954)**
```
Bₖ − Rⱼ = Zⱼₖ · √( σₖ² + σⱼ² − 2·rⱼₖ·σₖ·σⱼ )     B = 類別邊界
```

**成對比較的配對數**
```
成對數 = n(n − 1) / 2
```
→ `L09`, `L10`

## 5b. 色序系統的解析式（唯二有公式的兩個）

**★ Munsell Value → Y（五次多項式，1943 Renotation）**
```
Y = 1.2219 V − 0.23111 V² + 0.23951 V³ − 0.021009 V⁴ + 0.0008404 V⁵
                                          ↑↑ 負號
驗算：V = 10 → Y = 102.57 ✅       （教材 印成 +0.021009 → Y = 522.75 ❌）
```

**★★ DIN 6164 Darkness Degree D（唯一的封閉解析式）**
```
D = 10 − 6.1723 · log₁₀( 40.7 · A/A₀ + 1 )

A  = Y                 樣品的亮度因數
A₀ = 同色度之「最佳色（optimal colour）」的 luminous reflectance（查 LUT）

邊界：A = A₀ （最佳色）→ D = 0        A = 0（黑）→ D = 10
      ★ 方向與 Munsell Value 相反（D 越大越暗）

⚠️ 教材 / s026 印成 6.1273（27/72 顛倒）→ 最佳色會得到 D = 0.0729 ≠ 0
   正確常數 = 10 / log₁₀(41.7) = 6.17232
```
→ `L11`, `L12`

## 6. CIELAB / CIELUV

**CIELAB**
```
L* = 116·f(Y/Yn) − 16
a* = 500·[ f(X/Xn) − f(Y/Yn) ]
b* = 200·[ f(Y/Yn) − f(Z/Zn) ]
f(t) ≈ t^(1/3)                （暗端另有線性段）

C*ab = √(a*² + b*²)
h_ab = arctan(b*/a*)          0°–360°
```

**CIELUV**（★ 獨有飽和度）
```
u* = 13 L* (u′ − u′n)
v* = 13 L* (v′ − v′n)
C*uv = √(u*² + v*²)
★ s_uv = C*uv / L*            ← CIELAB 沒有這個量
```

**色差**
```
ΔE*ab = √( ΔL*² + Δa*² + Δb*² )                （直角座標）
ΔE*ab = √( ΔL*² + ΔC*ab² + ΔH*ab² )            （極座標）

★★ ΔH*ab = 2 · √(C*₁ · C*₂) · sin(Δh_ab / 2)
   （或 ΔH* = √(ΔE*² − ΔL*² − ΔC*²)，但無正負號）
```
→ `L13`

## 7. CMC 與 CIEDE2000

**CMC(l:c)**
```
ΔE_CMC = √[ (ΔL*/(l·S_L))² + (ΔC*/(c·S_C))² + (ΔH*/S_H)² ]
CMC(2:1) = 紡織業標準；CMC(1:1) = 感知性
```

**CIEDE2000（四項 = 三項 + 旋轉項）**
```
ΔE₀₀ = √[ (ΔL′/(k_L·S_L))² + (ΔC′/(k_C·S_C))² + (ΔH′/(k_H·S_H))²
          + R_T · (ΔC′/(k_C·S_C)) · (ΔH′/(k_H·S_H)) ]

S_L = 1 + [0.015 (L̄′−50)²] / √(20 + (L̄′−50)²)      ← V 形，L*=50 最小
S_C = 1 + 0.045 C̄′
S_H = 1 + 0.015 C̄′ T
T   = 1 − 0.17cos(h̄′−30°) + 0.24cos(2h̄′)
        + 0.32cos(3h̄′+6°) − 0.20cos(4h̄′−63°)
R_T = − sin(2Δθ) · R_C
Δθ  = 30 · exp{ −[(h̄′−275°)/25]² }                  ← ★ 藍區 275°
R_C = 2 · √( C̄′⁷ / (C̄′⁷ + 25⁷) )

★ 第五項修正（近中性色的 a* 拉伸）：
a′ = (1 + G)·a*
G  = 0.5·[ 1 − √( C̄*⁷ / (C̄*⁷ + 25⁷) ) ]
```

**★ CIEDE2000 = 對 CIELAB 的五項修正：S_L、S_C、S_H、R_T、a′(G)**

**參數因子**
```
一般：k_L = k_C = k_H = 1
★ 影像：k_L = 2, k_C = 1, k_H = 1   →  ΔE₀₀(2:1:1)
```
→ `L13`, `L14`

## 8. 空間色差

**Michelson 對比**
```
C = (L_max − L_min) / (L_max + L_min)
對比敏感度 = 1 / C
```

**空間頻率（CPD, cycles per degree）**
```
θ  = 2 · arctan( (螢幕寬/2) / 觀看距離 )
SF = cycle 數 / θ(度)

例：8 cycles，螢幕 50 cm，距離 400 cm
    θ = 2·arctan(25/400) ≈ 7.15°  →  SF = 8/7.15 ≈ 1.1 CPD
```

**CSF 形狀**
```
亮度通道   : band-pass 帶通，峰值 ≈ 3–5 CPD，截止 ≈ 50–60 CPD
紅-綠通道  : low-pass 低通，截止 ≈ 10–12 CPD
黃-藍通道  : low-pass 低通，截止 ≈ 5–8 CPD
```
→ `L14`

## 9. 色貌屬性關係 ★★★（老師說「100% 會考」）

```
J = Q / Q_w                （明度 = 明亮度 ÷ 白的明亮度）
C = M / Q_w                （彩度 = 鮮豔度 ÷ 白的明亮度）
s = M / Q                  （飽和度 = 鮮豔度 ÷ 自己的明亮度）

★ 推得： s = M/Q = C/J

絕對屬性（隨觀看條件變）：Q Brightness、M Colourfulness
相對屬性（除以參考白，大致不變）：J Lightness、C Chroma
```

**戶外大太陽下**：Q↑、M↑；J、C、s 不變
**非相關色（孔徑色）**：沒有參考白 → **只有 Q, M, s, h；沒有 J 和 C**
→ `L16`

## 10. 色適應變換 CAT

**von Kries 係數法則（六步驟）**
```
① X_wr Y_wr Z_wr ──[3×3]──► R_wr G_wr B_wr     （參考白）
② X_w  Y_w  Z_w  ──[3×3]──► R_w  G_w  B_w      （測試白）
③ X    Y    Z    ──[3×3]──► R    G    B        （樣品）
④ 比值：R_wr/R_w , G_wr/G_w , B_wr/B_w
⑤ R_c = (R_wr/R_w)·R ,  G_c = … ,  B_c = …
⑥ R_c G_c B_c ──[逆矩陣]──► X_c Y_c Z_c        （對應色）
```

**CAT02 矩陣（sharpened cone space，注意有負值）**
```
M_CAT02 = [  0.7328   0.4296  −0.1624 ]
          [ −0.7036   1.6975   0.0061 ]
          [  0.0030   0.0136   0.9834 ]
```

**適應程度因子 D（不完全適應）**
```
D = F · [ 1 − (1/3.6) · exp( (−L_A − 42) / 92 ) ]
D = 1 完全適應；D = 0 完全不適應
```

**Surround 參數（CIECAM02 / CAM16）**
| Surround | F | c | N_c |
|---|---|---|---|
| Average | 1.0 | 0.69 | 1.0 |
| Dim | 0.9 | 0.59 | 0.9 |
| Dark | 0.8 | 0.525 | 0.8 |

**L_A 慣用算法**
```
L_A = L_w × Y_b / 100          （L_w = 白的亮度 cd/m²）
```
→ `L17`, `L18`, `L19`

## 12. 色不恆常指數 CII

```
X_R Y_R Z_R  ：樣品在參考照明體（D65）下的 XYZ
X   Y   Z    ：樣品在測試照明體（A）下的 XYZ
                  ↓ CAT
X_c Y_c Z_c  ：預測的對應色

★ CII = ΔE( X_R Y_R Z_R , X_c Y_c Z_c )

向量分解：
  參考點 → 測試點   = Illuminant Colorimetric Shift（純物理）
  測試點 → 對應色   = Adaptive Shift（人眼適應）
  參考點 ↔ 對應色   = ★ Colour Inconstancy
```
→ `L18`, `L19`

## 13. 演色性 CRI / Ra

```
【1】量測試光源 SPD → 【2】算 CCT
【3】選參考光源（同 CCT）：
       CCT < 5000 K → Planckian radiator（黑體）
       CCT ≥ 5000 K → D 系列日光
【4】8 個測試色樣 TCS01–08（Munsell Value 6，中等彩度，不同色相）
【5】算兩光源下的 XYZ
【6】von Kries 型 CAT 轉到同一適應條件
【7】在 CIE 1964 U*V*W* 空間算色差 ΔE_i
【8】★ R_i = 100 − 4.6 · ΔE_i
【9】★ Ra = (R₁+…+R₈) / 8

ΔE = 0 → Ra = 100
```
→ `L19`

## 14. 同色異譜指數 MI

```
✗ 錯（低估）：MI = √(ΔL² + ΔC² + ΔH²)  直接用測試照明體下的色差

✓ 對：先修正參考照明體下的殘差（參考條件必須 ΔE = 0）
   ΔL(調整) = ΔL(測試) − ΔL(參考)
   ΔC(調整) = ΔC(測試) − ΔC(參考)
   ΔH(調整) = ΔH(測試) − ΔH(參考)
   MI = √( ΔL(調整)² + ΔC(調整)² + ΔH(調整)² )
```
→ `L15`
