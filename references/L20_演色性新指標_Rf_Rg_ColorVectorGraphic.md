# L20｜演色性的新指標：Rf、Rg 與 Color Vector Graphic
**性質**：⚠️ **這一篇不在 2021 年的課程裡** —— 是 L19（CRI）的續集與後繼。
**動機**：**CIE 已於 2025 年 1 月正式建議照明產業「從 CRI 轉換到 Rf」**（見 `00-differences.md` E11）。
L19 教的 Ra 仍是歷史基礎與法規標示的內容，但**實務規格、選燈、研究應該改用這一套**。

**建立日期**：2026-08-26（第三輪文獻研究）

---

## 0. 一句話定位

```
CRI / Ra  （1974 定版）  →  只有「一個數字」，只問「準不準」
                              ↓
TM-30 / CIE 224           →  「Rf + Rg + 一張圖」
                              Rf 問「準不準」、Rg 問「鮮不鮮」、CVG 問「哪個色相出問題」
```

> **CRI 的根本限制不是它算錯，而是「它只給你一個數字」。**
> 一個數字沒辦法同時回答「這盞燈準不準」和「它讓東西看起來好不好」——**這是兩個不同的問題。**

---

## 1. ★★ Rf 保真度指數（Fidelity Index）

### 1-1 與 CRI 的逐項對照 ★ 這張表是本篇的核心

| 項目 | **CRI / Ra**（CIE 13.3） | **Rf**（CIE 224:2017 / TM-30） |
|---|---|---|
| **色樣數** | **8 個**（TCS01–08） | **★ 99 個（CES, Colour Evaluation Samples）** |
| **色樣來源** | Munsell 色票，**全部 Value 6、中低彩度** | **★ 真實物體的反射率光譜**，涵蓋膚色、植物、紡織、塗料、印刷等 |
| **色樣設計目標** | — | **① 均勻覆蓋色空間 ② 光譜靈敏度中性（spectrally neutral）③ 對應真實物體** |
| **觀察者** | **CIE 1931 2°** | CIE 1931 2° |
| **色空間** | **CIE 1964 U\*V\*W\***（已廢止、非均勻） | **★ CAM02-UCS**（現代均勻色空間） |
| **色適應** | **von Kries 型**（過時） | **CAT02**（內含於 CAM02-UCS 流程） |
| **參考光源** | **< 5000 K → 黑體；≥ 5000 K → D 系列**<br>**⚠️ 在 5000 K 處「不連續」** | **★ ≤ 4500 K → 黑體<br>≥ 5500 K → D 系列<br>4500–5500 K → 「按比例混合」** |
| **計算式** | `R_i = 100 − 4.6·ΔE_i`<br>`Ra = mean(R₁…R₈)` | `Rf = 100 − 6.73 · mean(ΔE′)`（99 個 CES 平均） |
| **輸出** | **一個數字** | **Rf + Rg + 16 個局部指標 + 圖形** |

### 1-2 ★★ 最漂亮的一個改進：參考光源的「混合過渡」

**CRI 的問題**：在 **5000 K 有一個硬切換**（黑體 ↔ D 系列）→ **4999 K 與 5001 K 的燈，Ra 不能互相比較**。

**TM-30 的解法**：
```
CCT ≤ 4500 K        →  100% 黑體輻射體（Planckian）
CCT ≥ 5500 K        →  100% CIE D 系列
4500 K ~ 5500 K     →  ★ 兩者按比例混合

例：CCT = 4750 K
    →  75% 黑體（4750 K） + 25% CIE D4750
```
> **結果：整條 CCT 軸上的過渡是「平滑的」。**
> **★ 這對現代「可調色溫（tunable white）」的燈具特別重要**——一盞燈從 3000 K 調到 6500 K，
> 用 CRI 會在 5000 K 處出現數值跳動，用 Rf 不會。

### 1-3 為什麼常數從 4.6 變成 6.73
- 兩者的意義相同：**把「平均色差」線性映射成 0–100 的分數**
- 常數不同是因為**色空間換了**（U\*V\*W\* → CAM02-UCS），一個色差單位代表的知覺量不一樣
- **⚠️ 因此 Ra = 85 與 Rf = 85 不能直接互相換算**，兩者是不同尺度

### 1-4 ⚠️ 需要標準原文確認的細節
- TM-30 對 Rf 另外施加了一個**對數型的「軟下限」轉換**，避免分數掉到 0 以下（一般寫成 `Rf = 10·ln[exp((100 − 6.73·ΔE̅′)/10) + 1]` 的形式）。**這一點我目前只在二手資料看到形式描述，未取得標準原文驗證——實作前請查 ANSI/IES TM-30-20 或 CIE 224:2017 原文。**
- TM-30 各版本（-15 / -18 / -20）之間的差異在於：**CES 的外插方法**、**參考光源過渡區**、**保真度的縮放係數**。

## 2. ★★ Rg 色域指數（Gamut Index）—— CRI 完全沒有的維度

### 2-1 定義
```
Rg = 100 × ( A_test / A_reference )

A_test      = 測試光源下，16 個色相區平均點所圍成的多邊形面積
A_reference = 參考光源下，同樣 16 個點所圍成的面積
```

### 2-2 怎麼解讀 ★
| Rg | 意義 |
|---|---|
| **Rg = 100** | **飽和度與參考光源相同** |
| **Rg > 100** | **★ 平均而言「提高」了飽和度**（顏色比在參考光源下更鮮豔） |
| **Rg < 100** | **平均而言「降低」了飽和度**（顏色變濁） |

**典型範圍**：**約 60 – 140**（在 Rf > 60 的前提下）
**業界常引用的「可接受」區間**：**Rg 80 – 120**

### 2-3 ★★★ Rf 與 Rg 為什麼必須一起看
```
Rf 高、Rg = 100   →  非常忠實，接近參考光源       （博物館、印刷打樣、醫療）
Rf 高、Rg > 100   →  忠實但略微增豔                （零售、生鮮、服飾——常是「偏好」的甜蜜點）
Rf 低、Rg > 100   →  顏色不準，但看起來很鮮豔      （某些商業展示燈刻意這樣做）
Rf 低、Rg < 100   →  又不準又很濁                   （最糟）
```

> **★ 這正是 CRI 最大的盲點：CRI 會「懲罰」任何偏離參考光源的行為，
> 包括「人類其實更喜歡的增豔」。**
> Rf 與 Rg 把「準確」與「好看」拆成兩個獨立的軸——**這是 TM-30 最重要的哲學突破。**

**⚠️ 但要注意**：**CIE 2025 年的立場聲明只推薦了 Rf，沒有納入 Rg**（也沒納入 TM-30 的 Preference Design Intent）。
**IES TM-30 的完整做法才是 Rf + Rg 雙指標。** 兩個體系在這一點上還沒完全一致。

## 3. 16 個色相區與局部指標

### 3-1 色相區
在 **CAM02-UCS 的 a′b′ 平面**上，把 360° 切成 **16 個色相區（hue bins）**，每區 **22.5°**。
**Hue bin 1 對應紅／橙區**，然後依序繞一圈。

> ⚠️ 各區的精確角度邊界請查標準原文；此處只給結構。

### 3-2 三個局部指標 ★
| 符號 | 名稱 | 問的問題 |
|---|---|---|
| **R_f,hj** | **局部保真度（local fidelity）** | 「**第 j 個色相區準不準？**」 |
| **★ R_cs,hj** | **局部彩度位移（local chroma shift）** | 「**第 j 個色相區被「增豔」還是「變濁」？**」（正值=增豔、負值=變濁） |
| **R_hs,hj** | **局部色相位移（local hue shift）** | 「**第 j 個色相區的色相「偏掉」了嗎？**」 |

### 3-3 ★★ R_cs,h1 —— 業界最該看的單一數字
> **R_cs,h1 = 第 1 色相區（紅／橙）的彩度位移。**
>
> **為什麼它最重要**：**局部彩度位移（尤其是紅色）與人對「自然、正常（naturalness）」的知覺相關性最好。**
> 紅色不對，膚色、生鮮肉品、木頭、紅酒全都不對。
>
> **★ 業界的現實**：**大多數市售產品的 R_cs,h1 是「負值」** —— 也就是**紅色被去飽和了**。
> 這正是「LED 可以 Ra = 90 但 R9 是負的」那件事的量化版本（見 L19）。

**★ 對照關係**：
```
CRI 的 R9（飽和紅，不計入 Ra）
        ≈ 對應到
TM-30 的 R_cs,h1（紅／橙區的彩度位移）
```
**兩者都在講同一件事：紅色是最容易被犧牲、也最該被檢查的顏色。**

## 4. ★★★ Color Vector Graphic（CVG）怎麼讀

### 4-1 圖的結構
```
        ┌──────────────────────────────┐
        │        ●  黑色圓圈           │
        │     = 參考光源（基準）        │
        │                              │
        │   ↗ ↑ ↖   16 個箭頭          │
        │  →  ⊙  ←  = 每個色相區的      │
        │   ↘ ↓ ↙    平均位移           │
        │                              │
        │  外側的實線 = 測試光源的       │
        │              色域輪廓         │
        └──────────────────────────────┘
```

### 4-2 讀圖規則 ★ 記住這三條就夠了

| 看什麼 | 意義 |
|---|---|
| **黑色圓圈** | **參考光源**——所有判讀的基準。圓上每一點代表該色相在參考光源下的位置 |
| **★ 測試光源的線在圓「外側」** | **該色相區被「增豔（saturating）」** |
| **★ 測試光源的線在圓「內側」** | **該色相區被「去飽和（desaturating）」** |
| **箭頭「沿著圓周方向」偏** | **色相偏移（hue shift）**——顏色跑到隔壁色相去了 |
| **箭頭「指向圓心/背離圓心」** | **彩度位移（chroma shift）**——只是變濁或變豔，色相沒跑掉 |

### 4-3 CVG 真正的價值
> **Rf 和 Rg 都是「平均值」。**
> **★ 平均值會掩蓋災難**：一盞燈可以 Rf = 88、Rg = 100 看起來很好，
> 但 CVG 一畫出來，發現**紅色區塌陷、青色區暴衝**——這兩個相反的偏差在平均時互相抵銷了。
>
> **CVG 是唯一能告訴你「問題出在哪個色相」的工具。**

**這與 L14 的教訓完全同構**：
```
L14：影像的「平均 ΔE」會掩蓋空間分布   →  用 S-CIELAB / error map
L20：光源的「平均 Rf/Rg」會掩蓋色相分布 →  用 Color Vector Graphic
```
> **★ 兩者是同一個方法論：不要只信平均值，要看分布。**

## 5. CIE 224:2017 與 IES TM-30 的關係

| | |
|---|---|
| **共同框架** | **兩者共用同一套核心計算框架**（99 CES、CAM02-UCS、參考光源混合規則） |
| **★ 關鍵事件** | **TM-30-18 發布後，CIE 224:2017 的 Rf 與 IES TM-30-18 的 Rf 完全一致（harmonized）** |
| **差別** | **CIE 224 只定義 Rf（保真度）**；**TM-30 另外定義 Rg、16 個局部指標、CVG、以及 Design Intent 規格框架** |
| **定位** | CIE 224 說自己是 **"for accurate scientific use"**（科學用途）；TM-30 是**設計與規格實務導向** |

> **記法：Rf 是兩邊共通的「共同語言」；Rg 與 CVG 是 TM-30 獨有的「加值」。**

## 6. 實務：怎麼看規格、怎麼選燈

### 6-1 索取數據的優先順序
```
1. Rf          ← 準不準
2. Rg          ← 鮮不鮮
3. ★ R_cs,h1   ← 紅色有沒有被犧牲（最容易被隱藏的問題）
4. CVG 圖      ← 有沒有哪個色相塌陷
5. （若只拿得到舊指標）Ra + ★ 務必額外索取 R9
```

### 6-2 依應用場景
| 場景 | 要求 |
|---|---|
| **博物館、印刷打樣、醫療、色彩品管** | **Rf 高、Rg ≈ 100**（要忠實，不要美化） |
| **零售服飾、生鮮、餐飲** | **Rf 尚可、Rg 略高於 100、R_cs,h1 ≥ 0**（適度增豔是加分） |
| **一般辦公、住宅** | Rf ≥ 80、Rg 80–120 |
| **可調色溫燈具** | **★ 一定要用 Rf 而非 Ra**——因為 Ra 在 5000 K 有跳動 |

### 6-3 老師課堂那條鐵律仍然成立
> **「一般來說，你越省電，色彩品質就越差。」**（L19 `11-19-07.mp4` 00:24:22）
>
> LED 把整條曲線往上推了，但取捨還在：**要高 Rf/R_cs,h1 就要補 620–660 nm 的紅色螢光粉，
> 而那個波段的視覺效率低 → 效能會掉 10–25%。**
