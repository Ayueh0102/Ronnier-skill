## 1. 兩套原色系統（00:01:37–00:03:07）

| 系統 | 原色 | 混合結果 | 場合 |
|---|---|---|---|
| **加法混色 Additive** | **R + G + B（光）** | **白** | 螢幕、投影、燈光 |
| **減法混色 Subtractive** | **C + M + Y（顏料/墨）** | **黑** | 印刷、噴墨 |

- 老師的定義法：**Cyan = 綠+藍（青）**、**Magenta = 紅+藍**、**Yellow = 紅+綠**。
- **為什麼墨水匣是 CMY + K？** 因為 CMY 三色能產生**最大色域（gamut）**；三色疊起來理論上是黑，但實務上疊出來是髒黑，所以另加 K。

## 2. 色匹配實驗 Color Matching Experiment（00:03:07–00:06:29）★ 核心

**實驗裝置**：
- 全黑房間、黑色背景
- 視野是**兩個半圓（bipartite field）**，中間有**黑色隔線（partition）**
- 右半 = **待測色（test color）**；左半 = 觀察者用 **R、G、B 三原色光**調出來的匹配色
- 任務極簡單：**「請把左邊調到跟右邊一樣」**

**為什麼要做色匹配？** 老師的邏輯：*人類視覺系統極度複雜，我們無法直接「量測」它；但我們可以量測「什麼時候兩個光看起來一樣」*。色匹配是把主觀視覺變成可重複實驗的唯一入口。

**數學表達**：
```
C  ≡  R·(R) + G·(G) + B·(B)
```
`≡`（雙箭頭）= **matching，看起來一樣**，不是數值相等。

**單位歸一化**：先讓 R、G、B 三者等量相加時匹配出一個指定白，此時把三者各定為 1（或 100%）單位。

**Grassmann's Law 葛拉斯曼定律（00:05:07–00:05:31）★ 必考**
- 色匹配遵守**線性代數**：可加、可減、可縮放、可移項。
- **移項 = 負值的來源**：某些色無法用 R+G+B 匹配，必須把 R 加到「待測色那一側」，寫回方程式就成為 **−R**。
- 考題形式：「什麼是 Grassmann's law？為什麼它能用在色匹配？」→ 要能解釋加法原色 R/G/B 相加成白，以及線性可加減。

**色度座標（chromaticity）**：
```
r = R/(R+G+B),  g = G/(R+G+B),  b = B/(R+G+B)   →   r + g + b = 1
```
所以只需要兩個數就能定「色」（但丟掉了亮度資訊）。

## 3. 視野大小：2° vs 10°（00:06:29–00:07:59）★ 必考

- **色匹配結果會隨視野（field of view）改變** → CIE 必須訂兩套。
- **老師的手部估算法**：
  - **手臂伸直、大拇指指甲 ≈ 2°**
  - **握拳（拳頭）≈ 10°**
- **選用規則（rule of thumb）**：**θ > 4° 用 10° 觀察者，否則用 2°**。
- 實務上：小色塊/精細比色 → 2°；大面積（牆面、布料、大螢幕）→ 10°。工業界多數用 10°。

**RGB → XYZ 線性轉換的約束（投影片 `L02_s019 / s023`）**：
```
x̄ = a₁₁·r̄ + a₁₂·ḡ + a₁₃·b̄
ȳ = a₂₁·r̄ + a₂₂·ḡ + a₂₃·b̄
z̄ = a₃₁·r̄ + a₃₂·ḡ + a₃₃·b̄

where   1 = a₁₁ + a₁₂ + a₁₃
        1 = a₂₁ + a₂₂ + a₂₃
        1 = a₃₁ + a₃₂ + a₃₃          ← ★ 每一列的係數和 = 1
```
> **★ 值得注意的呼應**：**「矩陣每列和為 1」這個約束，60 年後在 CAM16 的 M16 矩陣上再次出現**（見 L17）。
> 這是色彩科學裡反覆使用的設計手法——**保證白點不被縮放**。
- 老師的重要提醒：**兩套觀察者的受試者基本上都是白種人（Caucasian）**，而虹膜色素、黃斑色素密度、水晶體黃化程度會因人種與年齡不同 → **CMF 有族群偏差**。

**r̄ḡb̄ → x̄ȳz̄ 的轉換（00:12:29–00:15:30）**
- 原始 RGB 色匹配函數在 **cyan～green 區有負值**（約 440–545 nm 的 r̄ 為負）。
- 負值不好用（儀器不能發負光、計算不便）→ CIE 做**線性變換**，得到**全部為正**的 **x̄, ȳ, z̄**。
- 圖上：**實線 = 2°，虛線 = 10°**；兩者看似相似，但**藍區差異巨大**。

**負值的物理意義（老師特別展開）**：不是所有顏色都能被 R、G、B 三色光匹配出來。這直接推論到：
> **任何 RGB 顯示器，在青綠（cyan–green）區域必然無法完整重現真實色彩。**
- 老師的態度：「這重要嗎？**99% 的情況不重要**」——因為看電影時，你不會拿螢幕上的天空和湖水去跟真實比對。
- **但什麼時候重要？電視購物 / 網購**：螢幕上看到的和收到的布料不一樣，就出事了。

## 5. XYZ 三刺激值怎麼算（00:15:30–00:21:32）★ 核心公式

**物體色（反射色）**：
```
X = k · Σ S(λ) · R(λ) · x̄(λ) · Δλ
Y = k · Σ S(λ) · R(λ) · ȳ(λ) · Δλ
Z = k · Σ S(λ) · R(λ) · z̄(λ) · Δλ

k = 100 / Σ S(λ) · ȳ(λ) · Δλ
```
- `S(λ)` = 照明體 SPD；`R(λ)` = 物體反射率；`x̄ȳz̄` = 色匹配函數（2° 或 10°）
- **k 的意義**：讓**白（PRD，R=100%）的 Y = 100**。所以 Y 是「相對於完美白」的亮度因子。

> ### ⚠️★ 投影片上的 k 公式寫錯了（2026-08-26 發現）
> 投影片 `L02_s025_016m30s.png` 與 `s027` 寫的是：
> ```
> where k = 100 / Σ R(λ) S(λ) ȳ(λ)          ← ⚠️ 分母含了 R(λ)
> ```
> **這樣寫的話，R(λ) 在分子分母都出現 → 任何樣品算出來的 Y 都會是 100**，顯然不對。
>
> **正解（CIE 15 / ASTM E308）**：
> ```
> k = 100 / Σ S(λ) · ȳ(λ) · Δλ              ← 分母「只有照明體與 ȳ」，不含樣品反射率
> ```
> 這樣完美反射漫射體（R ≡ 1）才會得到 Y = 100。
>
> **善意解讀**：分母那個 R(λ) 或許是指「完美漫射體的 R = 1」，若是如此就只是多餘而非錯誤。
> **但照投影片字面抄去寫程式一定算錯。實作請用正解。**
- 若你做印刷，也可以把「紙白」定義為基準來算 k。

**自發光色（顯示器/光源）**：
- **沒有反射率、沒有分離的光源項** → 只用 **CMF × 螢幕 SPD**
- **老師強調：自發光和物體色的 XYZ 算法不同**，這是常見錯誤來源。

### ★★★ 自發光的常數是 683，不是 k（2026-08-26 由投影片 `L02_s032_020m35s.png` 補上）

**投影片「Calculating XYZ for self-luminous stimulus」的完整算例**（樣品是 **CRT 峰值白**）：
```
X = 683 · Σ W_x(λ)·R(λ) = 61.168 cd/m²
Y = 683 · Σ W_y(λ)·R(λ) = 64.979 cd/m²        x = 0.3104
Z = 683 · Σ W_z(λ)·R(λ) = 70.917 cd/m²        y = 0.2974
```

| | 物體色 | **自發光色** |
|---|---|---|
| **常數** | **k = 100 / Σ S(λ)ȳ(λ)**（相對歸一，白 = 100） | **★ 683**（= K_m，最大光視效能 683 lm/W） |
| **Y 的意義** | **亮度因數**（無單位，0–100） | **★ 亮度本身，單位 cd/m²** |
| **基準** | 完美反射漫射體 | **絕對輻射量** |

> **★ 這就是「自發光與物體色算法不同」的具體內容**——不只是少乘一個反射率，
> **連歸一化常數的性質都不一樣**：一個是相對的 k，一個是絕對的 683。

### ★ 物體色的完整算例（投影片 `L02_s026 ~ s031`，D50 加權表）

**Step 1：建加權表**
```
標準色度觀察者(CIE 1931)  ×  SPD(D50)  =  加權表(D50/2)

資料來源：ASTM E308 Tables 5 and 6
可用照明體：A, C, D50, D65, D75, F2, F11
可用觀察者：1931 與 1964
```
**D50 白點**：`Xw = 96.422　Yw = 100.000　Zw = 82.521　x = 0.3457　y = 0.3585`

**Step 2：算 XYZ**（樣品是橘色）
```
X = k · Σ W_x(λ)·R(λ) = 47.113        x = 0.5407
Y = k · Σ W_y(λ)·R(λ) = 38.027        y = 0.4364
Z = k · Σ W_z(λ)·R(λ) =  1.997
```

> **★ 這解開了 A2 的謎**：老師口頭說「D65 的色度座標是 0.346、0.359」——
> **那是這張 D50 投影片上的 0.3457 / 0.3585**。他看著 D50 的算例卻說成 D65。
> **D65 2° 正解是 (0.3127, 0.3290)。**

**Weighting Table 加權表**
`SPD × CMF` 事先乘好做成表（例如「D65 + 2°」一張表），量到反射率後直接相乘積分。查表來源：**ASTM E308**。

**XYZ 的另一種理解方式（老師的說法，00:16:01）**：
> 「CIE 定義了標準原色 x̄ȳz̄，也就是**標準的紅綠藍**。給你 XYZ，就是告訴你**要多少量的這三個標準原色才能匹配這個顏色**。」

**XYZ 的存在意義**：**色彩溝通工具**。我不用把實體樣品寄給你，只要給你 XYZ，你在世界任何地方都能重現這個顏色。

## 6. 色度圖與色彩規範（00:21:32–00:27:00）

**xy 色度圖上的地標**：
- **Spectral locus 光譜軌跡**：外緣馬蹄形，最飽和的單色光
- **Purple line 紫線**：底部直線，連接 380 與 700 nm，**上面沒有對應波長**
- **Planckian locus 普朗克軌跡 / 黑體軌跡**（轉錄誤植為 "plantain locus"）
- 各標準照明體的座標點

**三個描述量（把 xy 圖翻譯成人看得懂的話）**：

| 感知屬性 | 色度圖上的量 | 算法 |
|---|---|---|
| 色相 hue（紅黃綠藍） | **主波長 λd (dominant wavelength)** | 白點 N →樣品 Q 連線延伸到光譜軌跡的交點波長 |
| 彩度/純度（強弱） | **激發純度 pe (excitation purity)** | `pe = NQ / NP`，NP 為白點到光譜軌跡的全長，故最飽和 = 1 |
| 明暗 | **Y（luminance factor）** | 來自 XYZ 的 Y |

- **紫色系的特例**：紫色落在 purple line 附近，往外延伸碰不到光譜軌跡（那裡沒有波長）→ 改往**反方向**延伸，得到 **λc 補色波長（complementary wavelength）**，並用 N-P′-Q′ 算純度。
- **完整規範 = (x, y, Y)**：因為色度圖本身**不含亮度資訊**。
- 老師點名：**XYZ 是非均勻色空間（non-uniform color space）**——這是後面要學 CIELAB / CIEDE2000 的動機。

## 7. 本節總複習（老師自己的收尾，00:26:55–00:29:00）

## 🔍 與標準說法的出入 / 需要留意

1. **「三原色等量相加匹配 D65 白」**（00:04:39）
   - 老師用 D65 當歸一化白來講解。
   - **CIE 1931 RGB 系統的正式定義，是讓 R、G、B 等量相加匹配「等能白 Illuminant E」**，不是 D65。
   - 這是為了讓學生好懂的替換；但若考「CIE RGB 的單位如何定義」，標準答案是 **equi-energy white (E)**。

2. **D65 白點座標唸成 0.346 / 0.359**（00:19:29）
   - 這組數字是 **D50 2°：x = 0.3457, y = 0.3585**。
   - **D65 2° 應為 x = 0.3127, y = 0.3290**（10°：0.3138 / 0.3310）。
   - 投影片上可能同時列了多個照明體，口誤或看錯行。**這兩組數字都要背，別記混。**

3. **「人種不同 → pupil（瞳孔）顏色不同」**（00:11:30）
   - 應為 **iris 虹膜**的色素差異；瞳孔本身是開孔，永遠是黑的。
   - 更關鍵的生理變數其實是 **macular pigment（黃斑色素）密度** 與 **lens yellowing（水晶體黃化，隨年齡）**——這才是造成觀察者間色匹配差異（observer metamerism）的主因。近年 CIE 已提出 **CIE 2006 生理基礎 CMF（cone-fundamental-based）** 與 **individual observer model** 來處理此問題。

4. **激發純度 ≠ 知覺飽和度；主波長 ≠ 知覺色相**
   - `pe` 與 `λd` 是**色度圖上的幾何量**，不是感知量。
   - 已知的偏差：**Abney effect**（同一主波長加白後色相會偏移）、**Bezold–Brücke effect**（同一波長改變亮度色相會偏移）。
   - 老師在此節把它們當成「色相/彩度的描述」，是實務上的近似；嚴格的感知量要等 **Lecture 9/10 的色貌模型（J, C, h）**。

5. **「RGB 螢幕在青綠區必然不準」的因果**
   - 老師的推導是「因為 CMF 有負值」。
   - 更精確的講法：**負值反映的是「三個實體原色所張的三角形無法涵蓋整個馬蹄形」**，是**色域（gamut）**限制而非 CMF 本身的缺陷。任何三原色顯示器都受此限；解法是增加原色數（多原色顯示器）或雷射窄帶原色（如 Rec.2020）。

6. **17 位觀察者的統計代表性**
   - 老師誠實承認「不代表全世界」，這點值得記住：**整個現代色度學建立在 1920 年代 17 個英國人的視覺上**。
   - 這是 CIE 近 20 年推動 CIE 2006/2015 CMF 與 CAM16 等修正的根本動機之一。
