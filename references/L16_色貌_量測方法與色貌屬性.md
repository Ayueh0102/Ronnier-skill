## 2. ★★ 三種色貌尺度化技術（00:15:10–00:38:11）

### 2-1 Haploscopic Matching 分眼匹配
**做法**：
```
左眼 → 看「標準色」（例如在照明體 A 下）
右眼 → 看「測試刺激」，可以調整 RGB
光學裝置把兩眼影像「合併」成一個被分成兩半的圓
→ 觀察者調到「外觀相配」為止
```
典型用途：**求出「照明體 A 下的某色」等於「D65 下的哪個色」**（即**對應色資料 corresponding colours**）。

| 優點 | 缺點 |
|---|---|
| **精度高** | **兩眼的適應狀態不同、互相競爭 → 無法達到穩定適應** |
| **任務簡單**（只要調到滿意） | **不符合真實觀看條件**（現實中兩眼不會看不同畫面） |
| | **雙眼競爭（binocular rivalry）** |

**★ 老師的補充（00:18:12）**：
> 「XYZ 的基礎 x̄ȳz̄ 是怎麼來的？就是色匹配實驗。
> 而那個實驗**全部是西方人、2°、17 位英國觀察者**，我們用了快 100 年。
> 現在我們意識到——**亞洲人可能跟他們不一樣**。
> 我不敢說『非常不同』，但**原始資料缺乏檢驗其穩健性的能力**。
> **所以我實驗室現在正在建一台新的、多通道的色匹配設備。**」

### 2-2 Memory Matching 記憶匹配
**兩種形式**：

**(i) 用色序系統的記憶**
> **★ 投影片 `L16_s011_020m16s.png` 的定義逐字：**
> ```
> To describe a colour under different viewing conditions using the colour attributes
> of a particular ★ COLOUR ORDER SYSTEM such as Munsell (H V/C), NCS (φ-s-c).
> ```
> **★★ 這一句把 L11/L12 與 L16 接了起來** ——
> **色序系統在這裡的角色不是「產品」，而是「量測色貌的語言／單位」。**
> 觀察者腦中先裝好一套 Munsell 或 NCS，之後任何觀看條件下看到的顏色，
> 都用這套語言報出來。**色書變成了尺，人變成了儀器。**
>
> **★ NCS 寫成 `φ-s-c`**：`φ`（phi）= 色相、`s` = 黑度（svarthet）、`c` = 彩度（chromaticness）。

- 觀察者**背下 Munsell HVC 或 NCS 標記（約 1500 個顏色）**
- 不管在鎢絲燈下還是日光下，看到顏色就直接寫下 **HVC** 或 **S 1050-Y90R**

**(ii) 產生真實物體色**（老師團隊現在的做法）
- 給觀察者一個螢幕上的調色控制
- **「請調出一顆你現在就想吃的紅蘋果的顏色」**、**「請調出一根熟到剛好可以吃的香蕉」**
- **★ 用途：比較不同族群的記憶色**——他們在 **Leeds（白人 + 非洲裔）** 和 **中國（華人 + 巴基斯坦裔）** 各做了一輪

| 優點 | 缺點 |
|---|---|
| **正常觀看條件**（雙眼一起看） | **需要極長的訓練期——至少一個月，隔天就要練一次** |
| **穩定的適應狀態**（可以先適應 2–5 分鐘） | **資料分析複雜**（HVC 要先轉成 XYZ 才能分析） |
| **使用知覺屬性（H、V、C）** | **精度較低**（要經過記憶） |
| | **★ 記憶失真（memory distortion）** |
| | 記憶容量有限 |

**★★ 記憶色的系統性偏移（00:23:37）—— 一個重要的實驗事實**
> **「記憶中的顏色，總是比實際量到的『更亮一點』而且『更鮮豔一點』。」**

老師的示範：實際量到某個紅色是 `5R`，但憑記憶寫下來會變成 **`7.5R 5/10`（色相更純、彩度更高）**。
（→ 這正是為什麼商業影像的「偏好色（preferred colour）」總是比實際更飽和。）

### 2-3 ★ Magnitude Estimation 量值估計（老師團隊 1990–1992 年發展的方法）
**動機**：分眼匹配**太慢、設備太貴**；記憶匹配**訓練期太長**。

**做法：直接給三個數字**

| 屬性 | 尺度 | 錨點 |
|---|---|---|
| **Lightness 明度** | **黑 = 0，參考白 = 100** | 兩端固定 |
| **Colourfulness 鮮豔度** | **中性（灰階上的所有色）= 0**；**★ 上端開放（open-ended）** | **給一個參考色當錨**（例如「這個是 50」），可以答 200、1000 |
| **Hue composition 色相組成** | **兩個相鄰唯一色相的百分比，加起來 = 100** | 例如「70% 藍 + 30% 紅」 |

**★ 為什麼色相只需要兩個成分？（00:36:12）**
> **「Hering 的對立理論：你永遠不可能同時看到『紅和綠』、也不可能同時看到『黃和藍』。
> 這非常重要——這就是互補色相、就是對立理論。
> **所有的色彩模型都是這樣：CIELAB 的 a 是紅綠、b 是黃藍；CIELUV 的 u 是紅綠、v 是黃藍。」**

**★★★ 投影片 `L16_s017_027m57s.png`「Magnitude Estimation」的三把尺（圖示逐字）**
```
   Lightness              Colourfulness              Hue composition
   100 ▲ (白)             ▲ Open（★ 上端開放）        100 Y
     ▲                    ▲                     G50Y  ┌─┐  Y50R
     ▲                    ▲                      100 G│ │100 R
     ▲                    ▲                     B50G  └─┘  R50B
     0 ▼ (黑)             0 ▼                          100 B
```
> **★★ 三把尺的「兩端」設計完全不同，這正是七大屬性性質差異的來源：**
> | 尺 | 下端 | 上端 | 性質 |
> |---|---|---|---|
> | **Lightness** | **0 = 黑** | **100 = 參考白** | **兩端都封閉** → 相對量 |
> | **Colourfulness** | **0 = 中性** | **★ Open 開放** | **上端不封閉** → 絕對量，可以答 200、1000 |
> | **Hue composition** | — | — | **循環、且兩成分和 = 100** |
>
> **★ 「Colourfulness 的尺是開放的」這件事直接對應 L16 §3 的核心**：
> **Colourfulness（M）與 Brightness（Q）是絕對量**（燈越亮就越大，沒有上限）；
> **Chroma（C）與 Lightness（J）是相對量**（除以白點，封頂在 100 附近）。
> **→ 尺的設計不是隨便定的，它反映了屬性本身是絕對還是相對。**

**★★★ Hue composition 的標記法（投影片色相環上的八個標籤）**
```
100 Y  →  Y50R  →  100 R  →  R50B  →  100 B  →  B50G  →  100 G  →  G50Y  →（回到 100 Y）
```
> **讀法**：`Y50R` = **「黃裡面帶 50% 的紅」**，即 **50% Yellow + 50% Red**。
> **`100 Y`** = **純黃（unique yellow，唯一黃）**，不帶任何紅或綠。
>
> **★ 這就是第七個屬性 `H (Hue composition)` 的實體**：
> **不是角度（那是 h），而是「兩個相鄰唯一色相的百分比組合」。**
> **★ 這個標記法直接借自 NCS**（`S 1050-Y90R` 裡的 `Y90R` 是同一套邏輯）——
> **又一次印證「色序系統是色貌實驗的語言」。**
>
> **★ 為什麼只有四個唯一色相（R/Y/G/B）而不是六個或八個？**
> 因為 **Hering 對立色理論**：紅↔綠、黃↔藍互斥，
> **任何顏色最多只能落在「一個紅綠成分 + 一個黃藍成分」之間** → 相鄰兩個唯一色相。
> **→ 所以百分比一定只需要兩個數，且和為 100。**（見下方老師 00:36:12 的原話）

| 優點 | 缺點 |
|---|---|
| **正常觀看條件（雙眼）** | **精度較低** |
| **穩定適應狀態** | **→ 必須增加觀察者人數來補** |
| **使用知覺屬性** | |
| **★ 概念簡單、訓練期短（`Short training period`）** | |
| **有錨點** | |

> ### ★★★ 三種方法的優缺點數量對比（投影片 `s010 / s012 / s018`）—— 一眼看出誰贏了
> | 方法 | 優點數 | 缺點數 | 缺點內容 |
> |---|---|---|---|
> | **Haploscopic** | 2（高精度、任務簡單） | **3** | 兩眼適應狀態不同、觀看條件不切實際、**雙眼競爭** |
> | **Memory Matching** | 3 | **5** ← 最多 | 訓練期長、分析複雜、精度低、**記憶失真**、**記憶容量有限** |
> | **★ Magnitude Estimation** | **4**（多了「訓練期短」） | **★ 1** ← 最少 | **只有「精度較低」一項** |
>
> **★★ 這張對比表就是「為什麼老師團隊選擇量值估計」的完整答案**：
> **它的唯一缺點（精度低）可以靠「增加觀察者人數」用錢和時間解決；
> 另外兩種方法的缺點（雙眼競爭、記憶失真）是生理性的，花再多錢也解決不了。**
>
> **→ 這就是 LUTCHI 資料集用量值估計建起來的原因，也間接決定了 CIECAM97s/02 的形態。**

> 老師註記：他們最近在 CIC 發表的論文，就是用這個方法研究**極高彩度照明**下的色貌。

## 3. ★★★ 七大色貌屬性（00:38:11–00:53:20）—— 老師說「100% 考題」

### 3-1 三組核心對照

```
                【絕對屬性 Absolute】        【相對屬性 Relative】
                （隨觀看條件改變）           （除以參考白，故大致不變）

明暗   ──────►   Brightness  Q   ──── ÷ Q_white ────►   Lightness  J
彩度   ──────►   Colourfulness M ──── ÷ Q_white ────►   Chroma     C
                      │
                      └──── ÷ Q（自己的 brightness）───►  Saturation s
```

### 3-2 逐一定義（★★ 以下全部是投影片 `L16_s020 / s021 / s022 / s023` 的**逐字原文**）

**投影片 `s020`「Colour appearance attributes (I)」**
```
Brightness (Q)
   An area exhibited more or less light.
Lightness (J)
   An area exhibited more or less light ★ relative to a reference white.

              Lightness = Brightness / Brightness_white
```
**投影片 `s021`「Colour appearance attributes (II)」**
```
Colourfulness
   An area exhibited more or less chromatic.
Chroma
   The colourfulness judged as a ★ proportion of the brightness of a reference white.

              Chroma = Colourfulness / Brightness_white
```
**投影片 `s022`「Colour appearance attributes (III)」**
```
Saturation
   The colourfulness ★ in proportion to ITS brightness.

              Saturation = Colourfulness / Brightness
```
**投影片 `s023`「Colour appearance attributes (IV)」**
```
Hue
   An area appears to be similar to one of the ★ 4 unitary hues:
   red, yellow, green and blue, ★ or a combination of two of them.

   Hue composition (H) -  ★ colour appearance   (Y50R)
   Hue angle       (h) -  ★ colour difference   (0° to 360°)
```

| 屬性 | 定義 | ★ 分母是什麼 |
|---|---|---|
| **Brightness 明亮度 (Q)** | 一個區域**顯得發出/透射/反射較多或較少的光** | **沒有分母 → 絕對量** |
| **Lightness 明度 (J)** | 一個區域**相對於「參考白」**顯得較多或較少的光 | **參考白的 Q** |
| **Colourfulness 鮮豔度 (M)** | 一個區域**顯得較多或較少的彩色（chromatic）** | **沒有分母 → 絕對量** |
| **Chroma 彩度 (C)** | colourfulness，**以「參考白的 brightness」為比例基準** | **參考白的 Q** |
| **Saturation 飽和度 (s)** | colourfulness，**以「該區域自己的 brightness」為比例基準** | **★ 自己的 Q** |
| **Hue angle 色相角 (h)** | **0–360°** | **用於「色差」計算** |
| **Hue composition 色相組成 (H)** | 四個唯一色相中**兩個相鄰者**的**百分比組成**（如 `Y50R`） | **用於「色貌」描述** |

> ### ★★★ 兩個色相屬性的分工，投影片寫得比任何教科書都清楚
> ```
> Hue composition (H)  →  colour APPEARANCE      「這個顏色看起來像什麼」（Y50R）
> Hue angle       (h)  →  colour DIFFERENCE      「兩個顏色差多少」（0°–360°）
> ```
> **考題若問「為什麼要有兩個色相屬性」，答案就是這兩行 —— 用途不同。**
> **H 是描述用的（人看得懂），h 是計算用的（電腦算得動）。**
>
> **★ 而且 `h` 不能直接相減當距離**（見 L13 的 `ΔH* = 2√(C₁C₂)sin(Δh/2)`）——
> **這正是「角度」與「外觀」是兩回事的另一個證據。**

> **★ 注意 `Hue` 定義裡的 `or a combination of TWO of them`（兩個，不是三個）**
> —— 這一個「兩」字就是 Hering 對立色理論在定義裡的化身（紅綠互斥、黃藍互斥）。

### 3-3 ★★★★ 關鍵數學關係（投影片 `L16_s024_051m33s.png`「Relationship between colour appearance attributes」**逐字**）

> **★★★ 這一張就是老師說「100% 會考」的那一張。整段代數都印在上面：**

```
                        Brightness
   Lightness   =  ────────────────────
                    Brightness_white

                       Colourfulness
   Chroma      =  ────────────────────
                    Brightness_white

                       Colourfulness         Chroma  ×  Brightness_white
   Saturation  =  ──────────────────  =  ─────────────────────────────────
                        Brightness         Lightness × Brightness_white

                          Chroma
               =  ──────────────────
                        Lightness
```

**用符號寫（考試就寫這三行 + 一行推導）**
```
J = Q / Q_w                  （明度     = 明亮度   ÷ 白的明亮度）
C = M / Q_w                  （彩度     = 鮮豔度   ÷ 白的明亮度）
s = M / Q                    （飽和度   = 鮮豔度   ÷ 自己的明亮度）

推導：  M = C · Q_w  ,   Q = J · Q_w
        s = M/Q = (C·Q_w) / (J·Q_w) = C/J        ← ★ Q_w 抵銷

★  s = M / Q = C / J
```
> **★★★ 整段推導的關鍵只有一句話：「分子分母各自乘上 Q_w，然後 Q_w 消掉。」**
> 老師的原話：「Colourfulness = Chroma × Brightness of white；
> Brightness = Lightness × Brightness of white；**兩邊的 Q_w 抵銷 → M/Q = C/J。**」
>
> ### ★★ 為什麼這題「大家都會被搞混」（老師的原話）
> **因為 s 有兩個等價的寫法，而它們的「量級」看起來完全不同：**
> ```
> s = M / Q   ← 兩個「絕對量」相除     （燈開亮，M 和 Q 一起變大）
> s = C / J   ← 兩個「相對量」相除     （C 和 J 都已經除過 Q_w 了）
> ```
> **兩者一定相等，因為 Q_w 在上下同時出現。**
> **→ 這也是為什麼 `s` 是七個屬性裡唯一「與照明亮度無關」的量**：
> 它是唯一一個**分子分母都在同一個觀看條件下取的比值**，
> 所以**把燈調亮調暗，s 完全不變**（而 Q、M 會變大，J、C 大致不變但參考點變了）。
>
> **★ 生活例子（把三個比值一次串起來）**：
> ```
> 同一張紅紙，在強光下 vs 弱光下
>    Q（明亮度）  ：強光大、弱光小        ← 絕對量，跟著光走
>    M（鮮豔度）  ：強光大、弱光小        ← 絕對量，跟著光走
>    J（明度）    ：幾乎不變（都跟白紙比） ← 相對量
>    C（彩度）    ：幾乎不變              ← 相對量
>    s（飽和度）  ：★ 完全不變            ← 比值中的比值
> ```
> **這就是 Hunt effect 的反面**：Hunt effect 說「亮度上升 → colourfulness 上升」，
> 而 **saturation 之所以能保持不變，正是因為 Q 也同步上升，兩者相除抵銷。**

> **📌 2026-08 文獻補註**：**Hellwig & Fairchild (2022)** 指出 CIECAM02/CAM16 裡
> **Q 是 J 的「非線性」函數**（Hunt 模型的歷史遺產），並提出**線性關係**取代之，
> 連帶重寫了 chroma / colourfulness / saturation 的方程式，也導致 **CAM16-UCS 被修訂**。
> **★ 但上面這三條「比值定義」不受影響——他們改的是那個非線性函數的形式，不是定義本身。考試照舊寫這三條。**
> 詳見 `00-literature.md` E4 / E5。

### 3-4 ★★★ 三個必記的日常例子（這是理解的鑰匙）

**例一：走到戶外的大太陽下**
```
Brightness    ↑↑ （變很亮）        ← 絕對屬性，變了
Colourfulness ↑↑ （變很鮮豔）      ← 絕對屬性，變了
Lightness     ≈ 不變              ← 因為「參考白」也一起變亮，比值不變
Chroma        ≈ 不變              ← 同上
```
> **老師的觀察：「我們喜歡在天氣好的時候拍照——因為亮度高、colourfulness 高、影像好看。」**
> （這就是 **Hunt effect**。）

**例二：花園裡的一朵花**
下雨天或夜裡 → **brightness 降低、colourfulness 降低**（因為兩者是絕對屬性）。

**例三：陽光下的草地 vs 樹蔭下的草地（00:45:53）★ 最精采的一個**
```
同一片草地，一半在陽光下、一半在樹蔭下：

Colourfulness：差很多（陽光下高，樹蔭下低）
Brightness   ：差很多
★ Saturation ：幾乎相同！（因為兩者是同比例地降低）
```
> **★ 老師的推論：「所以如果你做機器人視覺（robotic vision），
> **saturation 是辨識物體非常好的工具。」**
>
> **示範**：一個各面漆同一種顏色的方塊，因為受光不同看起來差很多。
> **辨識策略：先看色相（hue）→ 再看飽和度（saturation）→ 就能準確辨識是同一個物體。**

### 3-5 ★ 什麼時候用 Chroma、什麼時候用 Colourfulness（00:44:21）
| 產業 | 用哪一個 | 理由 |
|---|---|---|
| **表面色產業**（紡織、塑膠、塗料） | **Chroma 彩度** | **永遠有一個參考白可以比**（白紙、白布） |
| **影像 / 顯示** | **Colourfulness 鮮豔度** | **常常沒有參考白**（例如夜景照片） |

### 3-6 Hue angle vs Hue composition —— 兩個不同的概念（00:50:45）★
| | **Hue angle (h)** | **Hue composition (H)** |
|---|---|---|
| 尺度 | **0°–360°** | **兩個相鄰唯一色相的百分比** |
| 用途 | **色差計算** | **色貌描述** |
| 問的問題 | 「這兩對的**色差**一樣大嗎？」 | 「這個色**由哪兩個唯一色相組成、各佔多少**？」 |

> **★ 重點：等角度差 ≠ 等知覺色差。兩者是不同的問題，不要混用。**

## 🔍 與標準說法的出入 / 需要留意

### 1. ★★ 「非相關色只有 4 個屬性」—— 老師沒明說，但這是最漂亮的推論
既然 **Lightness 與 Chroma 都定義成「除以參考白」**，那麼：
> **孔徑色 / 非相關色（unrelated colour）根本沒有參考白
> → 它「只有」Brightness、Colourfulness、Saturation、Hue
> → 它「沒有」Lightness 和 Chroma。**

**這個推論的實際後果**：
- **褐色（brown）與灰色（grey）只能以相關色存在。** 把它們單獨放在全黑背景中，褐色會變成橘色、灰色會變成暗白光。
- 夜間開車看到的號誌燈、遠處的路燈，都是非相關色 → 不能用 CIELAB 描述。
- CIECAM02 對非相關色的處理是另一套（CAM97u / Hunt 模型的 unrelated colour 模式）。

（呼應 L07 那句「灰 + 黃光 = 褐色」——現在有了完整的理論解釋。）

### 2. 兩個效應的正式名稱（老師描述了現象但沒命名）
| 老師的描述 | 正式名稱 |
|---|---|
| **「越亮 → 越鮮豔」** | **Hunt effect 亨特效應**（colourfulness 隨亮度提高而增加） |
| （下一節會講）**「越亮 → 明暗對比越強」** | **Stevens effect 史蒂文斯效應** |
- **Hunt effect 是 Robert Hunt 在 1950 年代用分眼匹配發現的**——正好呼應本節 2-1 講的方法。

### 3. 記憶色的偏移方向
- 老師說記憶色**「更亮且更鮮豔」**。
- **文獻最穩健的結論是「更飽和 / 彩度更高」**；**明度方向則因物體而異**（有些研究發現天空、草地的記憶色其實更暗）。
- 但老師的實務結論完全正確：**這就是為什麼「偏好的色彩重現」總是要加飽和度**（電視的「鮮豔模式」、手機的相片濾鏡都在做這件事）。

### 4. Saturation 對機器視覺的有效範圍
- 老師說「saturation 可用來做物體辨識」——**在「同一光源、只有強度改變（陰影）」時完全成立**。
- **但如果是「光源顏色改變」（例如從日光走到鎢絲燈下），saturation 也會變**。
- 完整的解法需要**色恆常演算法（colour constancy / white balance）**，或使用**光譜/多光譜影像**。
- 電腦視覺常用的 HSV 的 S 只對「強度縮放」不變，不是真的 CIECAM02 saturation——兩者不要混淆。

### 5. LUTCHI 資料集（老師沒點名，但這是他最重要的學術遺產之一）★
- **原始論文：Luo, Clarke, Rhodes, Schappo, Scrivener & Tait (1991), "Quantifying colour appearance. Part I. LUTCHI colour appearance data", *Color Res. Appl.*（263 次引用）**
- 老師 1986–1993 在 **Loughborough** 期間，用他發明的 **magnitude estimation** 方法，累積了**世界上規模最大的色貌實驗資料集**，通稱 **LUTCHI 資料**（Loughborough University of Technology Computer Human Interface）。
- **★ 三十多年後仍在被用來驗證新模型**——2022 年 Hellwig & Fairchild 修正 CAM16 時，用的正是 Munsell 系統與 **LUTCHI 資料**。
- **CIECAM97s 與 CIECAM02 的建立與驗證，主要就是靠這套資料。**
- 所以本節講的「magnitude estimation 方法」不是隨手提的——**它是後面所有色貌模型的資料來源**。

### 6. 「25% 商品因印刷顏色不準被退貨」
- 這是老師的產業回憶（1990 年 Crosfield，郵購目錄）。
- 這個數字說明了**為什麼色貌模型不是學術玩具，而是有明確 ROI 的工程問題**。這種產業動機貫穿老師整堂課的敘事。
