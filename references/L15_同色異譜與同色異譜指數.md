## 1. 定義（00:00–00:01:33）

### ★★★ 教材「Metamerism」原文（★ 這是官方定義，背這一句）
```
· ★ Two samples match to each other under one set of conditions,
  but fail to match under the other set of conditions.

     X₁ = X₂     ∫S₁(λ)R₁(λ)x̄(λ)dλ  =  ∫S₁(λ)R₂(λ)x̄(λ)dλ
     Y₁ = Y₂     ∫S₁(λ)R₁(λ)ȳ(λ)dλ  =  ∫S₁(λ)R₂(λ)ȳ(λ)dλ
     Z₁ = Z₂     ∫S₁(λ)R₁(λ)z̄(λ)dλ  =  ∫S₁(λ)R₂(λ)z̄(λ)dλ

· ★ Four types of metamerism:
  illuminant, observer, field size and geometric.
```
> **★★ 定義句要一字不漏地掌握它的結構：**
> ```
> 「在【一組條件】下相配，在【另一組條件】下不相配。」
>    ↑ 兩個「條件集合」，不是兩個顏色
> ```
> **很多人會答成「光譜不同但顏色相同」——那只答對一半。**
> **同色異譜的定義核心是「條件一換就破功」，光譜不同只是它的原因。**
>
> **★★ 那三條積分式在說什麼？**
> **三個式子的左右兩邊，`S₁` 都一樣、`x̄ȳz̄` 都一樣，只有 `R₁ vs R₂` 不同**
> —— **意思是：在照明體 S₁ 之下，兩個不同的反射率算出完全相同的 XYZ。**
> 這正是 L02「XYZ 是三個數字，反射率是幾十個數字」的必然後果：
> **從高維（光譜）壓到三維（XYZ），一定會有多個光譜對應到同一組 XYZ。**
> **→ 同色異譜不是意外，是「用三個數字代表顏色」這件事在數學上的必然代價。**

> **「兩個物體的 XYZ 值相同 → 這兩個顏色相配（colorimetric match）。
> 但它們的『反射率光譜』不同 → 這就是同色異譜（metamerism）。」**

回顧 XYZ 的三個組成：
```
XYZ = Σ  S(λ)  ×  R(λ)  ×  x̄ȳz̄(λ)
       照明體    反射率    觀察者
```

**★ 因此：只要「三個組成中的任何一個改變」，原本相配的一對就可能不再相配。
這三個組成就對應到三（四）種同色異譜。**

## 2. ★★★ 四種同色異譜（00:01:33–00:08:54）必考

| 型態 | 什麼相同 | 什麼改變 | 現象 |
|---|---|---|---|
| **① Illuminant Metamerism 照明體同色異譜** | 同樣品 R₁R₂、同觀察者 | **S(λ)：S₁ → S₂** | 在 **D65 下相配，換到 A 就不配** |
| **② Observer Metamerism 觀察者同色異譜** | 同樣品、同照明體 | **x̄ȳz̄：觀察者 A → 觀察者 B** | **甲說相配，乙說不配** |
| **③ Field-size Metamerism 視野大小同色異譜** | 同樣品、同照明體、同一人 | **視野：10° → 2°** | **大面積相配，小面積不配** |
| **④ Geometric Metamerism 幾何同色異譜** | 同樣品、同照明體、同觀察者 | **量測/觀看幾何：45/0 → 8/d** | **換角度就不配**（因為 R(λ) 隨幾何改變） |

> **★ 教材「Geometric Metamer(i)sm」底下有一行註解：**
> ```
> Special effect colours such as metallic and pearlescent coatings
> ```
> **→ 幾何同色異譜的主戰場就是「特殊效果色」：金屬漆與珠光漆。** 這正是 L04 需要**多角度分光儀**的理由。
>
> **★ 四張投影片的圖示各自畫出「什麼變了」，很好記：**
> | 型態 | 投影片的圖 |
> |---|---|
> | **Illuminant**（`s010/s012/s015`） | **左邊一顆鎢絲燈泡、右邊一顆太陽** ← 換光源 |
> | **Observer**（`s004/s005/s009`） | **左邊一位紅髮女性、右邊一位男性** ← 換人 |
> | **Field size**（`s006/s008`） | **左邊臉靠近色塊、右邊臉離很遠** ← 換視角大小 |
> | **Geometric**（`s007`） | **左右兩塊色片的擺放角度不同** ← 換幾何 |
>
> **⚠️ 投影片把 `Metamerism` 拼成 `Metamersim` 的地方不少**
> （`s004`、`s005`、`s006`、`s007`、`s008`、`s009` 的標題都是），只有 `Illuminant Metamerism` 那幾張是對的。純拼字。

**寫成式子的形式（老師的板書邏輯）**：
```
① S₁ R₁ x̄ = S₁ R₂ x̄      （相配）
   S₂ R₁ x̄ ≠ S₂ R₂ x̄      （不配）→ 照明體同色異譜

② S₁ R₁ x̄ᴬ = S₁ R₂ x̄ᴬ    （觀察者 A 看是相配）
   S₁ R₁ x̄ᴮ ≠ S₁ R₂ x̄ᴮ    （觀察者 B 看不配）→ 觀察者同色異譜

③ 把 x̄₁₀ 換成 x̄₂ → 不配                    → 視野大小同色異譜

④ 把 R(45/0) 換成 R(8/d) → 不配             → 幾何同色異譜
```

**★ 觀念連結**：
- **② 觀察者同色異譜** 就是 L04/L05 講的「**相機的 SSF ≠ 人眼的 CMF**」——**把相機當成另一個觀察者**。
- **③ 視野同色異譜** 的生理原因就是 L08 講的**黃斑色素**（只覆蓋中央 2–4°）。
- **④ 幾何同色異譜** 在**金屬漆、珠光漆**上最嚴重——正是 L04 需要多角度分光儀的理由。

## 3. ★★ 同色異譜指數 MI（Metamerism Index）（00:08:54–00:15:00）

### 3-1 錯誤的算法（會低估）
最直覺的做法：**直接算測試照明體下的色差**
```
MI(錯) = √(ΔL² + ΔC² + ΔH²)
       = √(1.0² + 1.5² + 2.0²) = 2.7
```
> **★ 老師：「這樣會低估同色異譜指數。」**

### 3-2 ★ 正確的算法（CIE 的做法）

#### ★★★ 官方三步驟（教材「Calculation of Metamerism Index - using additive correction」原文）
```
1. Calculating tristimulus under the 'match' and 'mismatch' conditions
      (XYZ)_r,S ,  (XYZ)_r,B ,  (XYZ)_t,S ,  (XYZ)_t,B

2. Calculating two sets of ΔL, ΔC, ΔH and ΔE values
      between (XYZ)_t,S and (XYZ)_t,B ,  and
      between (XYZ)_r,S and (XYZ)_r,B

3. ★ Additive correction
      MI = sqrt[ (ΔL_r − ΔL_t)² + (ΔC_r − ΔC_t)² + (ΔH_r − ΔH_t)² ]
```
**★ 符號對照（四個 XYZ 的下標一定要分清楚）**
| 符號 | 意思 |
|---|---|
| **r** | **reference（參考樣品 / 標準）** |
| **t** | **test（測試樣品 / 試樣）** |
| **S** | 第一個條件 —— **'match' 相配的那個照明體** |
| **B** | 第二個條件 —— **'mismatch' 不相配的那個照明體** |

> **★ 為什麼需要「四個」XYZ？** 因為要算**兩組色差**：
> ```
> 第一組：t 這一對在 S 與 B 之下的變化   →  ΔL_t , ΔC_t , ΔH_t
> 第二組：r 這一對在 S 與 B 之下的變化   →  ΔL_r , ΔC_r , ΔH_r
> 然後把兩組「相減」，剩下的才是真正的同色異譜量
> ```
> **★★ 這是「差的差（difference of differences）」，不是「差」。**
> 這正是為什麼直接算 `ΔE_test` 會錯 —— **它只算了一組，沒有扣掉基準。**

**核心原則**：
> **在「參考照明體」下，這一對樣品的色差必須等於 0。
> 如果不等於 0（實務上幾乎不可能剛好為 0），就必須先修正掉這個殘差。**

```
ΔL(調整) = ΔL(測試照明體) − ΔL(參考照明體)
ΔC(調整) = ΔC(測試照明體) − ΔC(參考照明體)
ΔH(調整) = ΔH(測試照明體) − ΔH(參考照明體)

MI = √( ΔL(調整)² + ΔC(調整)² + ΔH(調整)² )
   = √( 1.2² + 1.8² + 2.3² ) = 3.2
```

#### ★★★★ 完整計算範例（教材「Additive Correction based on a colour difference formula」原文）
```
                 ΔL       ΔC       ΔH
   Reference     0.2     -0.3      0.3
   Test         -1.0      1.5     -2.0
   Difference   -1.2      1.8     -2.3

   Metamerism Index (MI) = 3.2

   If without correction, ΔE_test = 2.7
```
**★ 我把兩個數字都驗算過了，完全吻合：**
```
MI       = √[(0.2−(−1.0))² + (−0.3−1.5)² + (0.3−(−2.0))²]
         = √[ 1.2² + (−1.8)² + 2.3² ]
         = √[ 1.44 + 3.24 + 5.29 ] = √9.97 = 3.157  →  ★ 3.2 ✅

ΔE_test  = √[ (−1.0)² + 1.5² + (−2.0)² ]
         = √[ 1 + 2.25 + 4 ] = √7.25 = 2.693        →  ★ 2.7 ✅

（順帶：參考對自己的殘差 ΔE_ref = √[0.2²+0.3²+0.3²] = 0.47，
  這就是「本來應該是 0、實際卻不是 0」的那個誤差）
```
> **⚠️ 注意投影片的 `Difference` 那一列寫的是 `−1.2, 1.8, −2.3`（Test 減 Reference 的相反號），
> 而公式寫的是 `ΔL_r − ΔL_t`（= `+1.2, −1.8, +2.3`）。
> 兩者符號整組相反，但因為最後要平方，MI 完全相同。** 不用糾結方向。

**兩個數字的對比（老師強調的重點）**：
| | 值 | |
|---|---|---|
| 不修正（錯） | **2.7** | ← 低估 |
| **修正後（對）** | **3.2** | ← 大了約 17% |

> ### ★★ 為什麼這裡「不修正會低估」？—— 看向量方向
> ```
> Reference 殘差 :  ( +0.2 , −0.3 , +0.3 )
> Test 的變化    :  ( −1.0 , +1.5 , −2.0 )
>                     ↑ 三個分量的符號「剛好都相反」
> ```
> **兩個向量接近反向。** 相減（等於加上反向量）→ **長度變大** → MI > ΔE_test。
>
> **★ 但要誠實：這不是必然的。**
> 如果參考殘差剛好與測試變化**同向**，修正後 MI 反而會**變小**。
> **加法修正的真正目的不是「放大」，而是「扣掉基準」**——
> **把「這一對樣品本來就配不準」的部分從「換照明體造成的不配」裡剝離出來。**
> 老師講的「會低估」是就**這個範例**而言；答題時寫「未修正會混入參考條件下的殘差，
> 導致 MI 失真」比寫「一定低估」更穩。

> 老師也提到還有其他修正方式：**加法修正（additive）** 與 **乘法修正（multiplicative）**，
> 但**核心觀念都是同一個：先讓參考條件下的色差歸零，再看測試條件下差多少**。
> **★ 投影片標題明寫 `using additive correction`** —— 上面那條公式是**加法修正版**。

### 3-3 工業場景
> **「客戶給你一個標準（standard），你生產出一批貨（batch）。
> 你必須判斷這兩者的色差有多大，以及**換了光源之後這個色差會怎麼變**。」**

## 🔍 與標準說法的出入 / 需要留意

### 1. CIE 正式的 MI 計算方式（老師講的是簡化版）★
- **CIE 15 定義的正式做法**是：
  1. **先修正「測試樣品」的三刺激值**（用**乘法修正**或**加法修正**），
     使它在**參考照明體**下與標準樣品**完全相配（ΔE = 0）**
  2. 再用修正後的值，計算**測試照明體**下的色差
  3. 這個色差就是 **MI**
- 老師教的「把參考照明體下的 ΔL、ΔC、ΔH 減掉」是**參數式的簡化近似**，
  在殘差很小時兩者結果接近，**但殘差大時會有差異**。
- **正式名稱**：
  - **CIE Special Metamerism Index: Change in Illuminant**（照明體改變）
  - **CIE Special Metamerism Index: Change in Observer**（觀察者改變）
- 慣例：**參考照明體通常取 D65**，測試照明體取 **A、F11（TL84）、F2（CWF）** 等。

### 2. 幾種同色異譜的「官方地位」不同
- **CIE 正式定義的**：**照明體同色異譜、觀察者同色異譜、視野大小同色異譜**（三種）。
- **幾何同色異譜**在文獻上有討論，但**不是 CIE 的正式分類**——嚴格說它是「反射率本身隨幾何改變」，而不是「觀察函數改變」。
- 老師列四種是為了教學完整（涵蓋 XYZ 三個組成 + 量測條件），是好的教學設計；**答題時可以寫四種並註明第四種的性質**。

### 3. 「現在主要只用 CIELAB」需要補充
- 在**色料/表面色**領域，這句話成立。
- **但在顯示器與照明領域，CIELUV 的 u′v′ 色度圖至今非常活躍**：
  - **CCT 與 Duv 的計算**建立在 CIE 1960 uv / 1976 u′v′ 上
  - **顯示器色域規格**（Rec.709、DCI-P3、Rec.2020 的色域面積比較）常用 u′v′
  - **CIE 的色差容差（如 SDCM / MacAdam step）** 用 u′v′
- 所以正確的說法是：**L\*a\*b\* 用於物體色；u′v′ 用於光與顯示器的色度**。

### 4. 「同色異譜黑（Metameric Black）」——理論上的漂亮補充
老師沒提，但這是理解同色異譜最深刻的一層：
> 任何反射率光譜都可以拆成兩部分：
> ```
> R(λ) = R_fundamental(λ)  +  R_black(λ)
> ```
> - **R_fundamental**：決定 XYZ 的那一部分（在三維「基本色刺激空間」內）
> - **R_black（metameric black）**：**XYZ 積分後為 (0, 0, 0) 的那一部分**——**它存在，但人眼看不到**
>
> **★ 一對同色異譜樣品的差異，就是一個 metameric black。**
> 這也解釋了為什麼**同色異譜的破裂量取決於「metameric black 的形狀」**：
> 形狀越劇烈（例如駝峰狀），換照明體時破裂越嚴重。
（此概念出自 Wyszecki 1958，是 L07「駝峰 vs 平滑曲線」那張圖的數學版本。）

### 5. 與「色恆常（colour constancy）」的關係（回顧 L05）
```
Metamerism        →  看「一對」樣品：換條件後「彼此」不再相配
Colour Constancy  →  看「一個」樣品：換條件後「它自己」的外觀改變
```
**兩者的橋樑**：
> **同色異譜的破裂量 = 兩個樣品各自「色不恆常向量」之差。**
> 若兩者的不恆常方向與大小完全相同，即使都不恆常，換光源後仍然相配。

### 6. 實務準則（把這一節變成可操作的規則）
1. **傳反射率，不要只傳 XYZ**（老師反覆強調的「反射率是指紋」）
2. **驗收時至少用三個照明體評色**：**D65 + A + 店內光源（F11 或 LED）**
3. **配方階段就要避免同色異譜**：用**光譜配色（spectral matching）**而不是**三刺激值配色（tristimulus matching）**
4. **報告 MI 值**，而不只報單一照明體下的 ΔE
