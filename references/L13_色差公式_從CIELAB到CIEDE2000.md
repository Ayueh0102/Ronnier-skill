## 2. 1976 之前的三大家族（00:07:31–00:18:15）

### 家族一：Munsell-based（以 Munsell 間隔為基礎）
**教材「Munsell Based Formulae」原文：**
```
· Nickerson's Index of fading (1936)
      ΔE(Index of fading) = (2/5)·C·ΔH + 6·ΔV + 3·ΔC
· Munsell Renotation system (1943)
· Adams and Nickerson (ANLAB) (1944)
      ΔE_ANLAB = √ 40{ (0.23ΔV_y)² + [Δ(V_x − V_y)]² + 0.4[Δ(V_z − V_y)]² }
  and I = 1.2219V_I − 0.23111V_I² + 0.23951V_I³ − 0.021009V_I⁴ + 0.00084045V_I⁵
  where I corresponds to X, Y or Z tristimulus values.
· Simplification of ANLAB
   – Sauderson et al (1946), Glasser et al (1958), Morton (1969)
· CIE 1976 L*a*b* (CIELAB)
```

| 年份 | 公式 |
|---|---|
| **1936** | **Nickerson's Index of Fading** ★ **史上第一個色差公式**，用 **HVC** 計算 |
| **1943** | Munsell Renotation（「蜘蛛網圖」） |
| **1944** | **Adams & Nickerson → ANLAB** |
| **1946 / 1958 / 1969** | ANLAB 的簡化版：**Saunderson et al. / Glasser et al. / Morton**<br>（投影片印成 `Sauderson`，應為 **`Saunderson`** —— 就是 Saunderson 修正的那位） |
| **1976** | **CIELAB** |

### ★★ 讀懂 Nickerson 1936：史上第一條色差公式
```
ΔE = (2/5)·C·ΔH  +  6·ΔV  +  3·ΔC
       色相項        明度項     彩度項
```
**兩個結構特徵，八十年後還活在 CIEDE2000 裡：**

1. **★★ ΔV 的權重 6 : ΔC 的權重 3 = 2 : 1**
   → 這正是 **L11 投影片「Munsell Uniformity」寫的 `1ΔV = 2ΔC`**。
   **同一個實驗事實，一個寫成色序系統的間隔關係，一個寫成色差公式的權重。**

2. **★★★ 色相項被 `C`（彩度）乘上去了**
   → **同樣大小的 ΔH，彩度越高就越顯眼**。
   這是**「色相差的權重必須隨彩度縮放」**這個概念的**第一次出現（1936）**，
   而它最後長成了 **CIEDE2000 的 `S_H = 1 + 0.015·C̄′·T`**。
   > **★ 一條可以貫穿整堂課的線**：
   > `Nickerson 1936: C·ΔH` → `CMC(l:c) 的 S_H` → `CIE94 的 S_H = 1+0.015C` → `CIEDE2000 的 S_H = 1+0.015C̄′T`
   > **「彩度加權」不是 2001 年才發明的，它從第一條公式就在了。**

   > **★ 但也要看出差別**：Nickerson 是**線性**乘 C（C·ΔH），
   > 現代公式是 **`1 + 0.015C`** —— **有截距 1**。
   > 差別在於：**C = 0（灰色）時 Nickerson 的色相項整個消失**（合理，灰色沒有色相），
   > 而現代公式仍留 `S_H = 1`（避免除以 0，且中性色附近仍有微弱色相辨別）。

### ★★★ 讀懂 ANLAB 1944：CIELAB 的直系祖先
```
ΔE_ANLAB = 40 · √{ (0.23·ΔV_Y)² + [Δ(V_X − V_Y)]² + [0.4·Δ(V_Z − V_Y)]² }
                    ↓                ↓                    ↓
                 明度項            紅綠項               黃藍項
                （只用 Y）      （X 減 Y）           （Z 減 Y，×0.4）
```
**把它和 32 年後的 CIELAB 並排看：**
```
ANLAB  (1944)                      CIELAB (1976)
─────────────────────────────────────────────────────────────
非線性: Munsell Value 五次多項式  →  非線性: 立方根 f(t) = t^(1/3)
明度  : 0.23 · V_Y                →  L* = 116·f(Y/Yn) − 16
紅綠  : V_X − V_Y                 →  a* = 500·[f(X/Xn) − f(Y/Yn)]
黃藍  : 0.4 · (V_Z − V_Y)         →  b* = 200·[f(Y/Yn) − f(Z/Zn)]
```
> ### ★★★★ 那個 `0.4` 就是 CIELAB 的 `200 / 500`
> **`200 / 500 = 0.4`。**
> **CIELAB 之所以 a\* 乘 500 而 b\* 乘 200，不是 1976 年重新做實驗定出來的
> —— 是 1944 年 Adams & Nickerson 就定好的黃藍/紅綠權重比，原封不動搬過來。**
>
> **記憶點**：`0.4` 這個數字從 1944 活到今天，**你每按一次 ΔE 都在用它**。
>
> **（順帶注意 b\* 的相減順序反了：ANLAB 是 `V_Z − V_Y`，CIELAB 是 `f(Y) − f(Z)`。
> 這是為了讓「黃為正、藍為負」符合直覺，是刻意翻的符號，不是錯誤。）**

**★★ 兩者真正的差別只有一個：非線性函數換掉了**
| | ANLAB | CIELAB |
|---|---|---|
| 非線性 | **Munsell Value 五次多項式** | **立方根**（≈ Stevens 定律 p ≈ 1/3） |
| 可否反解 | **不能**，只能數值逼近 | **可以**，直接開三次方 |
| 白點正規化 | 無（直接吃 XYZ） | **有**（X/Xn, Y/Yn, Z/Zn）← 這才是真正的新東西 |
| 算一次要多久 | **一整天（手算）** | **一瞬間** |

> **★ 所以「CIELAB 是怎麼來的」的標準答案是**：
> **把 ANLAB 的架構保留下來，只做兩件事 ——
> ① 把五次多項式換成可解析反轉的立方根，② 加上白點正規化。**
> 這就是為什麼 CIELAB 一出來就能被產業接受：**它算的東西跟大家用了 30 年的 ANLAB 幾乎一樣，只是算得動了。**

**ANLAB 的問題（00:13:12）★ 有趣的歷史細節**：
- 要先從 XYZ 算出 **V_X、V_Y、V_Z**（Munsell Value 函數，**五次多項式**）
- 只能用**數值分析法**逐步逼近
- **「那個年代沒有電腦。算一個色差要花一整天。完全不實用。」**
- **★ 老師的觀點：色彩科學無法普及，很大一部分原因就是算不動。到了 1960 年代電腦出現，色彩科學才真正被廣泛使用。**

### 家族二：MacAdam-based（以 MacAdam 橢圓為基礎）
**MacAdam（當時任職 Kodak）1942 年的經典實驗**：
- **25 個色中心（colour centres）**
- 用**視覺色度計（visual colorimeter）**，二分視野：一半是標準色，另一半由觀察者調整到剛好看出差異
- **從中心往各個方向找 JND → 連起來就是一個橢圓**
- **★ 橢圓的定義：從中心到橢圓邊界，各方向的知覺色差相等**

> **★ 判準：如果 xy 是均勻色空間，這些橢圓應該全部是「大小相同的正圓」。**
> **結果：全是大小懸殊的橢圓 → xy 不均勻。**

**衍生公式（教材「MacAdam Based Formulae」原文）**
```
· Simon-Goodwin graphic chart (1958)
· FMC-I  (1967)
· FMC-II (1971)
· FCM    (1978)
```
> **★ `FMC` = `Friele–MacAdam–Chickering`**（投影片圖說原文：
> *"FMC1 and FMC2 (Friele-MacAdam-Chickering 1967, 1971)"*）——三個人的姓縮寫。
> **⚠️ 第四項印成 `FCM (1978)`，字母順序與前兩項不一致**，極可能是 `FMC` 打字時顛倒。
> 文獻上明確且常被引用的只有 **FMC-1（1967）與 FMC-2（1971）** 這兩個版本，
> **答題寫這兩個就好**，1978 那項存疑、不必背。
>
> **★ Simon–Goodwin 是「graphic chart（圖表）」不是公式** —— 這點很有時代感：
> **1958 年沒有電腦，色差是「查圖表」查出來的**，跟老師講 ANLAB「手算一天」是同一個時代背景。

**★ 為什麼 MacAdam 資料現在很少用（00:15:46）**：
1. **只有一位觀察者**
2. 視覺色度計的觀看方式與日常不同（老師說是左右眼分看）
3. 後來的實驗結果與它不一致 → **決定放棄**

### 家族三：三刺激值的線性轉換（Linear transformation）
**★ 動機是一個很漂亮的數學理由（00:16:45）**：
> **xy 色度圖有「加法性（additivity）」**：兩個色光混合，結果一定落在兩點的連線上，而且比例可算。
> **線性轉換會保留這個性質**——所以照明與顯示產業非常想要這一類的色空間。

**成員與年份**（★ 2026-08-26 由教材 補上精確年份）：
| 年份 | 成員 |
|---|---|
| **1935** | Judd's chromaticity diagram |
| **1937** | MacAdam's chromaticity diagram |
| **1942** | Judd–Hunter NBS unit |
| **1958** | **Hunter LAB** |
| **1964** | **CIE U\*V\*W\*** |
| **1976** | **CIELUV** |

**Judd 的資料顯示**：要在色度圖上做到「等色相差」，**藍區（400–450 nm）與紅區需要大幅調整，而 500 nm（青）與 600 nm（橙）幾乎不需要調整**。
（投影片上的圖標示為 **"Wavelength Discrimination Data (Judd, 1934)"**，photometric field、2 degrees、approx. 70 trolands。）

## 3. ★★ 1976：關鍵的一年（00:18:45–00:24:45）

**CIE 在同一年推出三樣東西**：
1. **CIE 1976 u′v′ 色度圖**
2. **CIE 1976 L\*u\*v\*（CIELUV）** → **電視與照明產業用**
3. **CIE 1976 L\*a\*b\*（CIELAB）** → **表面色與影像產業用**

**教材「1976」原文：**
```
· CIE 1976 u'v' chromaticity diagram
· CIE 1976 L*u*v* or CIELUV
   – ★ for TV and lighting industries
· CIE 1976 L*a*b* or CIELAB
   – ★ for the surface (colorant) industries
```

> **老師的解釋：為什麼 CIE 要一次推薦「兩個」？**
> 因為**兩派資料各自支持不同的答案**（見第 4 節），CIE 擺不平，只好各推一個。

> ### ★★★ 更深一層的答案（從第 2 節的三大家族直接推出來）
> **這兩個空間不是「同一年做的兩個方案」，而是「兩條四十年血脈各自的終點」：**
> ```
> 家族一 Munsell-based ：Nickerson 1936 → ANLAB 1944 → 各種簡化 → 【CIELAB 1976】
> 家族三 線性轉換      ：Judd 1935 → MacAdam 1937 → Judd-Hunter 1942
>                        → Hunter Lab 1958 → CIE U*V*W* 1964 → 【CIELUV 1976】
> 家族二 MacAdam-based ：Simon-Goodwin 1958 → FMC-1 1967 → FMC-2 1971 → 【斷了】
> ```
> **① CIELAB 繼承的是「Munsell 視覺間隔」的傳統** —— 目標是**知覺均勻**，服務**表面色/染料業**
> **② CIELUV 繼承的是「線性轉換」的傳統** —— 目標是**保留加法性**，服務**電視/照明業**
> **③ MacAdam 那一支在 1971 之後斷掉**（老師在 00:15:46 給了三個原因：一位觀察者、觀看方式不同、後續實驗不一致）
>
> **→ 所以 1976 年 CIE 不是「猶豫」，而是「兩條互不相容的技術路線都已經有三、四十年的產業累積，
> 誰也裁不掉誰」。** 這比「一個給螢幕一個給印刷」深得多，很適合當申論題的開頭。
>
> **★ 為什麼互不相容？** 因為**「知覺均勻」與「加法性」在數學上不能兼得**：
> 加法性要求**線性**轉換（混色落在連線上），而知覺均勻必須**非線性**（立方根 / 五次多項式）。
> **CIELAB 用了立方根 → 失去加法性；CIELUV 的 u′v′ 保住了加法性 → 均勻性就比較差。**
> 這是一個真正的取捨，不是誰做得好不好的問題。

### 3-1 CIELUV
**教材「CIE 1976 u'v' diagram」原文：**
```
u' = 4X/ (X+15Y+3)          = 4x/(-2x+12y+3)
v' = 9Y/ (X+15Y+3)          = 9y/(-2x+12y+3)
```
> ### ⚠️★★ 投影片錯誤：分母的 `+3` 應該是 `+3Z`
> ```
> 投影片：u' = 4X / (X + 15Y + 3)      ❌   ← Z 掉了
> 正確：  u' = 4X / (X + 15Y + 3Z)     ✅
>         v' = 9Y / (X + 15Y + 3Z)     ✅
> ```
> **右邊的 xy 版本是對的**：`4x/(−2x+12y+3)`、`9y/(−2x+12y+3)` ✅
> **驗算（可以自己推一次）**：因為 `x + y + z = 1`，所以 `z = 1 − x − y`，
> ```
> X + 15Y + 3Z  →  正規化後  x + 15y + 3z
>                            = x + 15y + 3(1 − x − y)
>                            = x + 15y + 3 − 3x − 3y
>                            = −2x + 12y + 3   ✅ 完全吻合
> ```
> **→ 所以 xy 式裡那個「+3」是常數，XYZ 式裡的「+3」是「3Z」被打漏了。**
> **典型的簡報複製貼上錯誤：把下面那行的常數抄到上面那行去了。**
> **⚠️ 寫程式照抄會直接算錯**（分母少一項，藍色區完全跑掉）。

```
u′, v′  ← 由 XYZ 直接線性轉換
L*      ← 由 Y 計算
u* = 13 L* (u′ − u′n)
v* = 13 L* (v′ − v′n)      （n = 白點）

極座標：C*uv = √(u*² + v*²),   h_uv = arctan(v*/u*)
```

### ★★ CIELUV 的完整式（教材「CIEL\*u\*v\* (CIELUV)」原文）
```
For Y/Yn > 0.008856
      L* = 116(Y/Yn)^(1/3) − 16
Otherwise, L* = 903.0 (Y/Yn)

u*   = 13L*(u' − u'n)
v*   = 13L*(v' − v'n)
h_uv = tan⁻¹(v*/u*)
C*uv = (u*² + v*²)^(1/2)

s_uv = C*uv / L* = 13 (u*² + v*²)^(1/2)
```

> ### ⚠️★ 投影片錯誤之一：`903.0` 應為 `903.3`
> **CIE 的線性段係數是 `κ = 24389/27 = 903.2963`，通常寫 `903.3`。**
> **為什麼一定是這個數（一行證明）**：
> ```
> 設 ε = 216/24389 = 0.008856（轉折點）,  κ = 24389/27
> 則  κ · ε = (24389/27) × (216/24389) = 216/27 = 8   ← 恰好整數 8
> ```
> **兩段在轉折點必須接得上**：立方根段在 `Y/Yn = ε` 時
> `L* = 116×(0.008856)^(1/3) − 16 = 116×0.20690 − 16 = 8.000` ✅
> 線性段要給出同樣的 8，係數就只能是 `903.2963`。
> **用 `903.0` 會得到 `7.997`，在轉折點產生一個微小的不連續。**
> （實務影響極小，但**寫標準或寫論文要用 903.3**。）

> ### ⚠️★★ 投影片錯誤之二：`s_uv` 的最後一個表示式漏了撇號
> ```
> 投影片：s_uv = C*uv/L* = 13 (u*² + v*²)^(1/2)                     ❌
> 正確：  s_uv = C*uv/L* = 13 [(u'−u'n)² + (v'−v'n)²]^(1/2)          ✅
> ```
> **推導（自己算一次就永遠不會錯）**：
> ```
> u* = 13L*(u'−u'n),  v* = 13L*(v'−v'n)
> C*uv = √(u*² + v*²) = 13L*·√[(u'−u'n)² + (v'−v'n)²]
> s_uv = C*uv / L*    = 13  ·√[(u'−u'n)² + (v'−v'n)²]     ← L* 消掉了
> ```
> **★ 重點就在「L\* 被消掉」**：所以 `s_uv` **只跟色度座標有關，與明度完全無關**
> —— 這才是「飽和度」的本質。投影片寫成 `13(u*²+v*²)^½` 會變成 `13·C*uv`，
> **不但沒消掉 L\*，還多乘了一個 13L\***，量綱完全不對。

**★ CIELUV 獨有的東西：飽和度 saturation**
```
s_uv = C*uv / L*
```
> ### ★★★ 這條式子是「100% 會考」那條的前身
> ```
> CIELUV  (1976) ：  s_uv = C*uv / L*
> CIECAM02(2002) ：  s    = M / Q  =  C / J        ← 老師說「100% 會考」
> ```
> **結構一模一樣：飽和度 = 彩度 ÷ 明度。**
> **CIELUV 是 CIE 體系裡第一次正式定義 saturation，而它的定義方式被色貌模型完整繼承。**
> 所以 L16 那條「s = M/Q = C/J」不是憑空冒出來的，
> **它是 1976 年就寫進 CIELUV 的關係式，只是把 C→M、L\*→Q 換成色貌模型的量。**
> **答 L16 那題時可以加這一句，會非常加分。**
> **CIELAB 沒有飽和度！**（只有 L\*、a\*、b\*、C\*、h）
>
> **老師對飽和度的物理詮釋（00:22:41）**：
> **從黑點拉一條線出去，線上所有顏色的「飽和度」相同**（跟 DIN 的定義一樣）。
> 這條線對應的是**真實世界的現象**：
> **你不斷往布上加染料/顏料 → 顏色越來越飽和，同時也越來越暗** —— 就是沿著這條線走。
> 所以**飽和度是一個「二維」的量（彩度與明度的比值）**，而彩度是三維空間裡的一個座標。

### 3-2 CIELAB
**教材「CIEL\*a\*b\* (CIELAB)」原文（★ 這張完全正確，可直接照抄）：**
```
L* = 116 f(Y/Yn) − 16
a* = 500[ f(X/Xn) − f(Y/Yn) ]
b* = 200[ f(Y/Yn) − f(Z/Zn) ]

h_ab  = tan⁻¹(b*/a*)
C*_ab = (a*² + b*²)^(1/2)

where       f(I) = I^(1/3)
Otherwise,  f(I) = 7.787 I + 16/116
```
> **★ `7.787I` 的 `I` 是變數不是數字 1**（斜體大寫 I）。線性段是 **`7.787·I + 16/116`**，正確。
> **精確值**：`7.787 = 841/108`，`16/116 = 4/29`。
> **⚠️ 這張投影片沒寫轉折條件**（CIELUV 那張有寫 `Y/Yn > 0.008856`），
> 完整條件是 **`I > 0.008856` 用立方根，否則用線性段**，兩張要合起來看。

**★ 回頭對照 ANLAB（1944）** —— `500 : 200 = 2.5 : 1`，倒數就是 **`0.4`**，
就是 ANLAB 黃藍項那個係數。**32 年沒變。**（見 2-1 的比較表）

- 中心是**無彩色**，往外彩度遞增；一圈是**紅→黃→綠→藍→紫**
- **同一個 a\*b\* 平面上的顏色，明度相同**

### 3-3 ★★ 色差怎麼算（教材「CIELAB Colour Difference Formula」原文）
```
ΔE = √( (ΔL*)² + (Δa*)² + (Δb*)² )
   = √( (ΔL*)² + (ΔC*ab)² + (ΔH*ab)² )

where
    ΔL*    = L*_b   − L*_s
    Δa*    = a*_b   − a*_s
    Δb*    = b*_b   − b*_s
    ΔC*ab  = C*ab,b − C*ab,s
    ΔH*ab  = 2 √( C*ab,b · C*ab,s ) · sin( Δh_ab / 2 )
```
> ### ★★ 注意下標 `b` 與 `s` —— 這是紡織業的慣例，考試容易被扣分
> ```
> b = batch     試樣 / 批次（工廠這一批做出來的東西）
> s = standard  標準（客戶指定的目標色）
> ```
> **所有差值都是「試樣 − 標準」**，方向不能反。
> 這決定了**色差描述語的方向**（見第 4 節）：
> `ΔL* > 0` 代表**試樣比標準亮**（lighter），`ΔL* < 0` 代表**較暗**（darker）。
> **老師的產業視角**：「色差就是錢，你的客戶按照你的 ΔE 值付錢」
> —— 客戶是 standard，你是 batch，**永遠是你去對他**。

**★ 兩種座標算出來的 ΔE 完全相同**（只是把 a\*b\* 平面的直角座標換成極座標，長度不變）：
```
Δa*² + Δb*²  =  ΔC*ab² + ΔH*ab²      ← 這是 ΔH* 那條怪式子存在的唯一理由
```
> **★★ 這才是 ΔH\* 的來歷**：ΔH\* **不是**「定義出來的」，而是**「湊出來的」**——
> 為了讓極座標版的畢氏定理仍然成立，剩下那一項只能長成 `2√(C₁C₂)·sin(Δh/2)`。
> 換句話說：**ΔH\* ≡ √(Δa\*² + Δb\*² − ΔC\*²)**，那條 sin 式只是它的封閉解。
> **考試若問「為什麼不能直接用 Δh」，答案的完整版就是這一行。**

**★★ 老師特別叮嚀「這條式子非常重要，一定要記住」（00:25:47）**：
```
ΔH*ab = 2 · √(C*₁ · C*₂) · sin(Δh_ab / 2)
```
> **「你可能會問：兩個色的色相角相減不就好了嗎？
> 抱歉，不行。因為 Δh 的單位是『度』，而這裡需要的是『距離』。」**
>
> **直覺：同樣轉 10°，在高彩度處走過的距離遠大於在低彩度處。**
> 所以要乘上兩個彩度的幾何平均。

## 4. ★★ 色差描述語（Colour Difference Descriptors）（00:26:17–00:32:43）

老師花了很長時間講這個，因為**這是業界溝通的語言**。

| 維度 | 描述語 |
|---|---|
| **明度 Lightness** | **lighter 較亮 / darker 較暗** |
| **彩度 Chroma** | **higher chroma 較鮮 / lower chroma 較濁** |
| **色相 Hue** | **redder / yellower / greener / bluer**（四個） |

**★★ 鐵律：你不能說「這個紅比那個紅更紅」**（00:30:41）
> **"You cannot say this red is redder than that red."**

**正確做法：在某個色相區內，只能用「相鄰的兩個」描述語**：

| 樣品落在 | 只能用 |
|---|---|
| **紅色區** | **yellower（偏黃）或 bluer（偏藍）** |
| **黃色區** | **redder（偏紅）或 greener（偏綠）** |
| **綠色區** | **yellower（偏黃）或 bluer（偏藍）** |
| **藍色區** | **greener（偏綠）或 redder（偏紅）** |

> 老師的邏輯：**紅、黃、綠、藍是「色相群組」的名字**，群組內的成員之間，只能用「往哪個鄰居偏」來描述。

## 5. CIELAB vs CIELUV 的對決（00:32:43–00:35:17）★ 這段解釋了為什麼會有兩個

**把 Munsell 色票畫進兩個空間**：
- **CIELAB 明顯較好**：等彩度圈**比較圓**、等色相線**比較直**
- **原因：CIELAB 本來就是為了擬合 Munsell 間隔而設計的**（老師強調：「別忘了這一點」）

**把 MacAdam 橢圓畫進兩個空間**：
- **結果相反——CIELUV 較好**：橢圓大小比較一致
- 在 CIELAB 裡，中心的橢圓很小、外圍很大 → 不均勻

**→ 所以 CIE 只好推薦兩個**：
```
CIELUV  →  電視、照明產業（且保有加法性）
CIELAB  →  表面色、影像產業
```

## 6. 1976 之後：新資料集與新公式（00:35:17–00:50:36）

### 6-1 為什麼需要新資料（★ 老師點出的關鍵問題）
```
Munsell 的色差   →  太大（色票之間隔得太開）
MacAdam 的 JND  →  太小（是恰可辨差）
★ 工業界真正在意的色差在中間 —— 大約 CIELAB ΔE < 5
```
**所以兩個舊資料集都不對症。必須做新實驗。**

### 6-1b ★ 「After 1976」完整時間軸（教材 原文）

| 年 | 公式 | ISO 採用 |
|---|---|---|
| **1984** | **CMC(l:c)** | **→ 1992 ISO 105-J03（紡織業）** |
| **1987** | **Luo & Rigg's BFD(l:c)** | — |
| **1994** | **CIE94(K_L:K_C:K_H)** | **→ 1997 ISO 7724（塗料業）** |
| **1997** | **Kim & Nobbs's LCD(l:c)** | — |
| **2001** | **★ CIEDE2000(K_L:K_C:K_H)** | — |

> **★ 一個容易忽略的細節**：投影片對參數因子用了兩種寫法——
> **CMC / BFD / LCD 用小寫 `(l:c)`（兩個因子）**；
> **CIE94 / CIEDE2000 用大寫 `(K_L:K_C:K_H)`（三個因子）**。
> 這反映了兩代公式的結構差異：舊的只調明度與彩度權重，新的三個維度都可調。

### 6-2 CMC 公式（英國）★ 紡織業至今仍在用
**資料來源**（★ 數字已由教材 逐字確認）：
- **JPC Formula — McDonald (1979)**，在 J&P Coats（JPC）做的實驗
- **McDonald's data：55 個色中心，包含 600 個聚酯線（polyester thread）樣品，由 8 位評色員（colourists）評定**
- 另一組：**JPC's 8,000 pairs，由「一位」染廠經理（a dye-house manager）評定**
- 投影片上的圖標示為 **"Figure 7 – ANLAB (50) tolerance ellipsoids (full size)"**

**演進（精確年份）**：
```
McDonald 資料 (1979) → JPC79 公式 → （修正 bug、平滑化）
        → CMC(l:c) (1984) → ★ ISO standard for textile industry (1992)
```

**★ McDonald 的歷史貢獻（00:41:26）**：
> **「1976 年 CIELAB 出來時大家都說太棒了。McDonald 是第一個發現 CIELAB 不好的人——
> 因為在中性色附近橢圓非常小，往高彩度走就越變越大。」**

**CMC 的形式**：在 **CIELAB 上加「橢球（ellipsoid）」修正**
```
ΔE_CMC = √[ (ΔL*/(l·S_L))² + (ΔC*/(c·S_C))² + (ΔH*/S_H)² ]
```
- **S_L、S_C、S_H**：依樣品在色空間中的**位置**而變的權重函數
- **l、c**：**parametric factors 參數因子**（可設 1、1.5、2 等）
  - **CMC(2:1)** = 紡織業標準（可接受性）
  - **CMC(1:1)** = 感知性

### 6-3 ★★★ BFD 公式 —— 老師自己的博士研究
**教材「Small Colour-Differences — Luo & Rigg ellipses, 1986」原文：**
```
Acceptability
   Industrial data
   ★ Pass/Fail decision - A%

Perceptibility
   ★ Proportional to the magnitude of difference (ΔV)

Combine both data by preparing textile samples to adjust sizes of ellipses

★★★ BFD formula (rotation term added to CMC)
```

- **Luo & Rigg**（**Brian Rigg 是老師的指導教授**）
- **BFD = Bradford**（老師當時在 Bradford 大學，後來去 Leeds）
- **1986 年博士論文產生 132 個橢圓**，**1991 年擴充**

**★★ 兩種視覺資料的取得方式完全不同（投影片明列）**
| | **Acceptability 可接受性** | **Perceptibility 感知性** |
|---|---|---|
| 資料來源 | **產業資料（industrial data）** | 實驗室視覺實驗 |
| 觀察者做什麼 | **通過 / 不通過的二選一判斷** | **評估差異的「大小」** |
| 得到的量 | **A%（接受的百分比）** | **ΔV，與色差量成正比** |
| 對應的心理物理方法 | **L10 的閾值法 / 二擇一** | **L10 的比例尺度化（magnitude estimation）** |
| 對應的參數因子 | **CMC(2:1)** | **CMC(1:1)** |

> **★ 老師怎麼把兩種資料合在一起用（投影片第三句）**：
> **`Combine both data by preparing TEXTILE SAMPLES to adjust sizes of ellipses`**
> —— **實際做出紡織樣品**，用它當共同的尺規，把不同來源的橢圓「大小」校準到同一個尺度上，
> 然後才能合併。
> **這是「跨資料集合併」的標準難題**：每個實驗室的觀察者、樣品、指示語都不同，
> 橢圓的**形狀**可能一致，**大小**卻差很多。**老師的解法是造一組實體橋樑。**

> ### ★★★★ 投影片最後一行：`BFD formula (rotation term added to CMC)`
> **BFD = CMC + 旋轉項。**
>
> **這一句話把老師的個人貢獻標得清清楚楚：**
> ```
> CMC (1984)  ──加上旋轉項──▶  BFD (1986/87, Luo & Rigg)  ──▶  CIEDE2000 的 R_T (2001)
> ```
> **CIEDE2000 五項修正裡的第五項「旋轉項 R_T」，源頭就是老師 1986 年的博士論文。**
> 這也解釋了為什麼他在第 7 節講到 R_T 時特別興奮（那是全課的高潮）——
> **他在講自己十五年前做的東西怎麼被寫進國際標準。**
>
> **答題時可以這樣寫**：「CIEDE2000 的旋轉項並非 2001 年的新發明，
> 而是繼承自 Luo & Rigg 1987 年的 BFD 公式；BFD 的定位就是『在 CMC 上加入旋轉項』。」

## 7. ★★★ CIEDE2000 = 對 CIELAB 的五項修正（00:51:05–00:56:16）

> **老師的比喻：「CIELAB 就像一個生病的病人（病人），需要五種不同的治療。」**

### ★★★★ 教材「Five Corrections to CIELAB」原文（**背這一張**）
```
· Chroma weighting function (S_C) - ★ same as CIE94
· Lightness weight function (S_L)
· Hue weighting function - ★ interactive chroma and hue correction (T and S_H)
· Rotation function (R_T)
· Neutral correction (a')
```

**完整公式（教材「CIEDE2000 Formulae」原文）**
```
ΔE = √[ (ΔL*/(K_L S_L))² + (ΔC*ab/(K_C S_C))² + (ΔH*ab/(K_H S_H))²
        + R_T · (ΔC*ab/(K_C S_C)) · (ΔH*ab/(K_H S_H)) ]
```
> **★ 前三項是平方和（畢氏定理），第四項不是平方 —— 它是「交叉項（cross term）」。**
> **這正是旋轉的數學來源**：二次型裡有交叉項，橢圓的主軸就不再平行於座標軸。
> ```
> 沒有交叉項 → A·x² + B·y²           → 橢圓長軸必定沿 ΔC* 或 ΔH* 方向
> 有交叉項  → A·x² + B·y² + C·x·y     → 橢圓長軸可以是任意角度  ★
> ```
> **考試若問「R_T 為什麼能讓橢圓旋轉」，答這一行就滿分。**

**★★ 投影片旁邊那兩張小圖的術語（很好用的一組詞）**
| 詞 | 座標 | 看的是什麼 |
|---|---|---|
| **Macro-space** | **a\* vs b\*** | **橢圓長在色空間的哪裡**（全域分布） |
| **Micro-space** | **ΔC\* vs ΔH\*** | **單一個橢圓自己的形狀與傾角**（局部） |
> **五項修正裡：S_L / S_C / S_H 處理 macro（位置決定大小），R_T 處理 micro（傾角）。**

### ★★★ 五項修正各自出自哪個實驗室（投影片標題直接寫在上面）
| # | 投影片原文 | 對應數學 | **★ 出處實驗室** |
|---|---|---|---|
| **1** | **Chroma weighting function (S_C)** | `S_C = 1 + 0.045 C̄′` | **`same as CIE94`（直接沿用，沒有新工作）** |
| **2** | **Lightness weight function (S_L)** | `S_L = 1 + 0.015(L̄′−50)² / √(20+(L̄′−50)²)` | **Leeds**（`s046` 標題：*CIEDE2000 S_L Function - Leeds*） |
| **3** | **Hue weighting function — interactive chroma and hue correction (T and S_H)** | `S_H = 1 + 0.015 C̄′ T`<br>`T = 1 − 0.17cos(h̄′−30°) + 0.24cos(2h̄′) + 0.32cos(3h̄′+6°) − 0.20cos(4h̄′−63°)` | **RIT**（`s047` 標題：*CIEDE2000 T and S_H Functions - RIT*） |
| **4** | **Rotation function (R_T)** | `R_T = −sin(2Δθ)·R_C`<br>`Δθ = 30·exp{−[(h̄′−275°)/25]²}`<br>`R_C = 2√(C̄′⁷/(C̄′⁷+25⁷))` | **★ Derby**（`s048` 標題：*Rotation Functions - Derby*） |
| **5** | **Neutral correction (a′)** | `a′ = (1+G)·a*`<br>`G = 0.5·[1 − √(C̄*⁷/(C̄*⁷+25⁷))]` | **★ Derby**（`s049` 標題：*Neutral Correction - Derby*） |

> ### ★★★ 這張表最重要的一件事：**五項裡有兩項是「Derby」做的 —— 那就是老師自己**
> ```
> Derby  →  Rotation function (R_T)    ← 承接自他 1986 的 BFD（見 6-3）
> Derby  →  Neutral correction (a')
> Leeds  →  S_L
> RIT    →  T 與 S_H
> CIE94  →  S_C（照抄）
> ```
> **所以「CIEDE2000 是誰做的」的精確答案是：三個實驗室分工，各自負責不同的修正項，
> 最後由 Luo、Cui、Rigg 整合發表。** 老師講 R_T 時特別興奮，是因為那是他自己那一格。

> **★ 注意第 3 項的措辭 `interactive chroma and hue correction`**
> —— **S_H 同時吃彩度（C̄′）與色相（透過 T）**，是唯一一個「兩個變數交互作用」的權重函數。
> 這也是為什麼 T 那條式子有四個餘弦項：**它在描述色相角上的四個不對稱波峰**（`s047` 的圖就是那條波）。
> **回頭看 2-1**：Nickerson 1936 的 `(2/5)·C·ΔH` 已經有「彩度 × 色相」的乘積結構了，
> **CIEDE2000 只是把那個 C 換成 `C̄′·T`，把線性換成有截距的 `1 + 0.015C̄′T`。**

| # | 修正項 | 修正什麼 | 老師的說明 |
|---|---|---|---|
| 1 | **S_L**（明度權重） | 隨 L\* 變化 | **V 形函數，在 L\* ≈ 50 附近最小**（因為四個實驗的背景都接近 L\*=50）。「色差小的時候 ΔE/ΔV 大」 |
| 2 | **S_C**（彩度權重） | 隨 C\* 遞增 | 修正「中心橢圓小、外圍橢圓大」 |
| 3 | **S_H**（色相權重） | **隨色相角變化的正弦波（sine wave）函數** | 內含色相相依項 **T** |
| 4 | **R_T 旋轉項（rotation term）** ★★ | **讓橢圓可以「轉動」** | **這是 CIEDE2000 最大的創新** |
| 5 | **近中性色的 a\* 拉伸** | 把 C\* 0–10 區的橢圓**撐成圓** | 「就是把它拉開，讓它變成圓」 |

### ★★ 旋轉項 R_T 的意義（00:54:09）—— 這是整堂課的高潮
> **「以前的公式（CMC、CIE94）都假設：橢圓的長軸永遠指向中性軸。
> 但**藍色區的橢圓不指向中性軸——它們是斜的、是旋轉的。**
> 加入旋轉項就能讓橢圓轉動。**這就是 CIEDE2000 與前面所有公式的差別。」**

**作用範圍**：
```
色相角 275° 附近（藍區）
275° ± 25°  →  即 250°–300° 之間有修正
恰好 275° 時修正量最大；離開這個區間 → R_T = 0（不修正）
```
> **★ 教材 在那個橢圓群上直接畫了框並標註 `Saturated blue region`**
> —— **「高彩度的藍區」才是問題所在，不是整個藍色。**
> 這由 `R_C = 2√(C̄′⁷/(C̄′⁷+25⁷))` 保證：**C̄′ 小的時候 R_C → 0，旋轉修正自動關掉。**
> **所以 R_T 的開關是「兩個條件同時成立」**：
> ```
> ① 色相角要落在 275° 附近   （由 Δθ 的高斯型 exp 控制）
> ② 彩度要夠高               （由 R_C 的七次方 S 型控制）
> 任一條不成立 → R_T ≈ 0 → 退化回沒有交叉項的普通橢圓
> ```
> **★ 那個「七次方」也出現在第 5 項的 `G` 裡**（`C̄*⁷/(C̄*⁷+25⁷)`），
> 是同一個「以 C = 25 為轉折點的陡峭 S 型開關」被用了兩次 ——
> 一次用來**開啟**旋轉（高彩度時），一次用來**開啟**中性修正（低彩度時，`G` 隨 C 下降而變大）。
> **兩者剛好互補：R_C 管高彩度的藍，G 管近中性的灰。**

### 驗證結果（00:55:47）
把 **BFD 實驗橢圓（紅色）** 與 **CIEDE2000 預測橢圓（黑色）** 疊在一起：
- **完美的話兩者應完全重合**
- **實際結果：在各個色中心都吻合得很好**，包括最難的藍區

**同時證實 CIELAB 的三大缺陷**：
1. 灰區橢圓**太小**、高彩度區橢圓**太大** → 不均勻
2. 理想空間應該是**等半徑的圓**，但它們不是
3. **藍區的橢圓不指向原點**

## 🔍 與標準說法的出入 / 需要留意

### 1. MacAdam 的觀察者名字
- 老師說 "Peter Lutin"。實際上是 **Perley G. Nutting Jr.**，論文中以代號 **"PGN"** 出現。
- 「只有一位觀察者」這個批評是對的，也是 MacAdam 資料最大的弱點。

### 2. MacAdam 的觀看方式
- 老師說「右眼看一個、左眼看另一個」。
- MacAdam (1942) 用的是**雙眼觀看的二分視野（bipartite field）視覺色度計**，不是分眼（haploscopic）觀看。
- 不過老師想指出的**核心問題**是對的：**那套裝置的觀看條件與真實產業評色差很遠**（自發光、暗背景、單一觀察者），所以資料不宜直接推廣到表面色。

### 3. ΔH\* 的第二種算法（老師只給了一種）
除了 `ΔH* = 2√(C*₁C*₂)·sin(Δh/2)`，實務上也常用：
```
ΔH* = √( ΔE*ab² − ΔL*² − ΔC*ab² )      （只給大小，不給正負號）
```
- 這個式子**算不出方向**，所以要判斷「偏黃還是偏藍」還是要用第一式的符號。
- 考試若要求「寫出 ΔH\* 的定義式」，寫第一式最安全。

### 4. CIEDE2000 的第 5 項修正到底是什麼（老師講得比較口語）
正式名稱是 **G 因子對 a\* 的縮放**：
```
a′ = (1 + G) · a*
G  = 0.5 · [ 1 − √( C̄*⁷ / (C̄*⁷ + 25⁷) ) ]
```
- **C̄\* 很小（近中性）時 G ≈ 0.5 → a′ 被放大 1.5 倍**（把近中性的橢圓撐圓）
- **C̄\* 很大時 G ≈ 0 → 不修正**
- 老師說的「就是把它拉開變成圓」，講的就是這個。

### 5. 各修正項的完整式（考試若要求寫出來）
```
S_L = 1 + [0.015 (L̄′−50)²] / √(20 + (L̄′−50)²)      ← V 形，L*=50 時 S_L=1（最小）
S_C = 1 + 0.045 C̄′
S_H = 1 + 0.015 C̄′ T
T   = 1 − 0.17cos(h̄′−30°) + 0.24cos(2h̄′) + 0.32cos(3h̄′+6°) − 0.20cos(4h̄′−63°)
R_T = − sin(2Δθ) · R_C
Δθ  = 30 · exp{ −[(h̄′−275°)/25]² }                  ← ★ 275° 就在這裡
R_C = 2 · √( C̄′⁷ / (C̄′⁷ + 25⁷) )
```
（老師說 T 是「用 multi-sensors 技術算的」——那是記錄錯誤，T 就是上面這串餘弦項的和。）

### 6. **CIEDE2000 的參考條件（老師沒講，但用錯會出大問題）** ★
CIEDE2000 是在一組**明確指定的條件**下擬合出來的（CIE 142:2001）：
| 參數 | 參考條件 |
|---|---|
| 照明體 | **D65** |
| 照度 | **1000 lx** |
| 觀察者 | 正常色覺 |
| 背景 | **均勻中性灰，L\* = 50** |
| 樣品 | **均勻、無紋理，張角 > 4°** |
| **樣品間距** | **兩塊直接相鄰、無縫（no separation）** |
| **色差大小** | **ΔE\*ab 在 0–5 之間** |
- **偏離這些條件時，必須調整 k_L、k_C、k_H（parametric factors）**，而不是直接照用。
- 常見誤用：拿 CIEDE2000 去評 **ΔE > 10 的大色差**（超出擬合範圍）、或評**有紋理的樣品**、或**有間隔的樣品對**。

### 7. CIEDE2000 的已知數學缺陷 ★（★ 2026-08-26 更新：老師的投影片上其實有寫，只是課堂沒講到）
> **★ 教材（老師課後捲 PDF 時掃過的那一頁）明列：**
> **`Sharma's finding on irregularity on hue difference`**
> —— **這個缺陷是被官方承認的，不是外界的抱怨。** 詳見正文第 8 節後的專段。

- **它不是一個色空間**，只是一個**距離公式**。因此：
  - **不滿足三角不等式** → 不能拿來做內插、聚類、色域映射
  - **在色相角接近 0°/360° 的地方使用「算術平均色相」，會造成不連續（discontinuity）**
    → **這就是 Sharma 指出的 `irregularity on hue difference`**
  - **中性軸附近的行為不平滑**
- **★ 同一頁還記了 `Melgosa's significant test on the 5 correction terms`**
  —— 有人對「五項修正是否每一項都統計顯著」做過正式檢定。
- **★ 以及最誠實的一行：`Textile (no significant improvement from CMC)`**
  —— **紡織業用 CIEDE2000 相對 CMC 沒有顯著改善**，這才是 CMC 至今仍是紡織 ISO 標準的真正原因。
- **所以：品管算色差 → 用 CIEDE2000；要在空間裡做運算（色域映射、影像處理、色貌轉換）→ 用 CAM02-UCS 這類真正的均勻色空間。**
- 這正是老師那句「算色差用 CIEDE2000，但色空間別用 CIELAB」的完整意思。

### 8. 「ΔE > 3 就 fail」只是一個例子
- 實際容差**因產業與產品而異**：
  - 高階顯示器 / 影像複製：**ΔE₀₀ < 1–2**
  - 一般紡織品：**CMC(2:1) < 1** 或 ΔE₀₀ < 1
  - 塑膠、汽車內裝：常在 **ΔE < 1** 甚至更嚴
  - 印刷（ISO 12647）：對不同要素有不同容差
- **ΔE\*ab ≈ 1 大致相當於「並排仔細看剛好可分辨」**，但這個經驗法則在藍區和暗色區會失效——正是 CIEDE2000 要修的問題。

### 9. Nickerson 的第一個公式（補充，可能考「第一個色差公式是什麼」）
**Nickerson's Index of Fading (1936)**：
```
I = (2/5)·C·ΔH + 6·ΔV + 3·ΔC
```
- C = Munsell Chroma，ΔH、ΔV、ΔC 為 Munsell 三屬性差
- 注意 **ΔH 前面乘了 C** —— 這就是「高彩度時色相差被放大」的最早體認，**與 60 多年後的 ΔH\* = 2√(C₁C₂)sin(Δh/2) 是同一個直覺**。
