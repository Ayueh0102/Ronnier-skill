## 1. 演色性要解決什麼問題（00:00–00:01:29）

> **「演色性主要是用來判斷『光源的品質』。
> 你在店裡賣東西，顏色要對。
> **『對不對』是跟誰比？跟日光比。**
> **越接近越好——而『越接近』的定義是：零色差。**
> 也就是：在外面（日光下）看，跟在這個測試光源下看，**沒有色差**。」**

## 2. ★★ 兩階段的位移：Illuminant Shift vs Adaptive Shift（00:01:29–00:03:34）

當光源從一個換到另一個（例如等能白 → 鎢絲燈），會發生**兩件事**：

```
【第一階段】Illuminant (Colorimetric) Shift 照明體色度位移
  同一個樣品，SPD 乘上不同的光源 → XYZ 立刻大幅改變
  → 這是【純物理】的、瞬間發生的
        ↓
【第二階段】Adaptive Shift 適應位移
  眼睛經過適應後，把這個位移「補償」回來
  → 最後你說：「這兩個顏色是一樣的」
```

> **★ 老師的關鍵句：「光源改變時有兩個階段——
> 一個是 illuminant shift，另一個是 adaptive shift。
> 曲線看起來差很多，但**經過適應位移之後，它們就一樣了**。」**

### ★★★ 三個定義的官方措辭（投影片 `L19_s002 / s003 / s012` 逐字）—— 這三個很容易混，一次釐清

**① Illuminant Colorimetric Shift 照明體色度位移（`L19_s002 / s004`）**
```
The change in the ★ XYZ tristimulus values of A SINGLE SAMPLE
when its illuminant is changed.

   S₁(λ) × R₁(λ) = S₁(λ)R₁(λ)  →  X₁ Y₁ Z₁
   S₂(λ) × R₁(λ) = S₂(λ)R₁(λ)  →  X₂ Y₂ Z₂

The Illuminant Colorimetric Shift is the difference between X₁Y₁Z₁ and X₂Y₂Z₂.
```
> **一個樣品、兩個光源，XYZ 的差。純物理，不涉及人眼。**

**② Illuminant Metamerism Index 照明體同色異譜指數（`L19_s003 / s005`）**
```
The extent to which ★ A PAIR OF SAMPLES that match under an illuminant of one colour
fail to match when the colour of the illuminant is changed.
   ★ The change causes illuminant colorimetric shifts

   S₁R₁ 與 S₁R₂  →  ★ Equal      （在第一個光源下相配）
   S₂R₁ 與 S₂R₂  →  ★ Not equal  （換光源後不相配）
```
> **兩個樣品、兩個光源。★ 注意投影片的說明：「這個改變『造成』照明體色度位移」
> —— 也就是說 ② 是建立在 ① 之上的：一對樣品各自發生 ①，兩個位移不一樣，配對就破了。**

**③ Colour Constancy 色恆常（`L19_s012_007m57s.png`）—— ★★★★ 那張三角形圖**
```
The extent to which ★ A SINGLE SAMPLE stays the same colour
when the colour of the illuminant is changed

      COLORIMETRIC SHIFT AND ADAPTIVE COLOUR SHIFT

              Sample in                    Corresponding
           Test Illuminant  ──Adaptive──▶     Colour
              （紅色）        Colour Shift       ▲
                   ╲                            │
                    ╲                    ★ Colour Inconstancy（綠色）
       Illuminant    ╲                          │
       Colorimetric   ╲                         │
          Shift        ╲                        │
                        ▼                       │
              Sample in Reference Illuminant ───┘
                       （紅色）

The Corresponding Colour is that which in the Reference Illuminant has
★ THE SAME APPEARANCE as the sample seen in the Test Illuminant.

Corresponding Colours are obtained by using a ★ Chromatic Adaptation Transform (CAT).
```
> ### ★★★★ 這張三角形圖是本節最該記住的一張，它把三個量的關係一次講完
> ```
> 邊 1：Illuminant Colorimetric Shift  = 純物理位移（換光源，XYZ 就變了）
> 邊 2：Adaptive Colour Shift          = 人眼補償（用 CAT 算出來的）
> 邊 3：★ Colour Inconstancy            = 兩者「沒對上」的殘差 = CII
> ```
> **★★ CII 就是這個三角形的「閉合邊」。**
> ```
> 如果人眼能「完全補償」物理位移 → 兩條邊剛好抵銷 → 三角形塌成一條線 → CII = 0
> 補償不完全 → 留下一個缺口 → 這個缺口就是色不恆常
> ```
> **★ 這個圖同時解釋了 CII 的定義（L18 §5）為什麼要算「Corresponding Colour 與
> Reference Illuminant 下實測值」的色差 —— 那就是第三條邊的長度。**
>
> **★★ 三個定義的一句話對照（考試常考辨異）：**
> | 概念 | 幾個樣品 | 涉及人眼適應嗎 | 量的是什麼 |
> |---|---|---|---|
> | **Illuminant Colorimetric Shift** | **一個** | ❌ 純物理 | 換光源後 XYZ 差多少 |
> | **Illuminant Metamerism Index** | **一對** | ❌ 純物理 | 換光源後「配對破了多少」 |
> | **Colour Constancy / CII** | **一個** | ✅ **要用 CAT** | 換光源後「看起來」變了多少 |

**Illuminant Metamerism Index 照明體同色異譜指數**：
考慮的是**一對樣品**——SPD 改變了，**但它們之間的色差應該維持不變**（見 L15）。

## 3. ★★★ 色適應變換 CAT 的六個步驟（00:11:48–00:15:16）必考

### 3-1 問題設定
| 已知 | 符號 |
|---|---|
| **參考照明體的白**（例如 D65） | **X_wr, Y_wr, Z_wr** |
| **測試照明體的白**（例如 A） | **X_w, Y_w, Z_w** |
| **樣品在測試照明體下的 XYZ** | **X, Y, Z** |
| **要求的：樣品在參考照明體下的「對應色」** | **X_c, Y_c, Z_c** |

**對應關係**：
```
X, Y, Z         對應到    X_w,  Y_w,  Z_w    （測試條件）
X_c, Y_c, Z_c   對應到    X_wr, Y_wr, Z_wr   （參考條件）
```

### 3-2 六個步驟
**★★★★ 投影片 `L19_s014_012m03s.png`「VON KRIES CHROMATIC ADAPTATION TRANSFORM」逐字**
```
                            Test Colour        Reference White
   In conditions considered   X  Y  Z          X_w   Y_w   Z_w
   In reference conditions                     X_wr  Y_wr  Z_wr

   Typical transformation equations (★ normalized for D65):

     ρ =  0.40024X + 0.70760Y − 0.08081Z     X = 1.85995ρ − 1.12939γ + 0.21990β
     γ = −0.22630X + 1.16532Y + 0.04570Z     Y = 0.36119ρ + 0.63881γ
     β =                        0.91822Z     Z =                       1.08906β

   Step 1. From X_wr, Y_wr, Z_wr  calculate  ρ_wr, γ_wr, β_wr.
   Step 2. From X_w,  Y_w,  Z_w   calculate  ρ_w,  γ_w,  β_w.
   Step 3. Calculate  ρ_wr/ρ_w ,  γ_wr/γ_w ,  β_wr/β_w.
   Step 4. For the test colour, from X, Y, Z, calculate ρ, γ, β.
   Step 5. Calculate  ρ_c = (ρ_wr/ρ_w)ρ ,  γ_c = (γ_wr/γ_w)γ ,  β_c = (β_wr/β_w)β.
   Step 6. From ρ_c, γ_c, β_c, calculate X_c, Y_c, Z_c.
```
> **★★ 那個 3×3 矩陣是「Hunt–Pointer–Estévez（HPE）矩陣」（正規化到 D65）**，
> 是把 XYZ 轉到「生理錐細胞空間 ρ γ β」的經典矩陣。
> **★ 注意它的第三列只有 `0.91822Z`** —— **β（藍錐）只由 Z 決定，X 與 Y 的係數都是 0。**
> 這是 HPE 矩陣的特徵：**它盡量讓三個通道彼此獨立。**

```
① X_wr Y_wr Z_wr  ──[3×3 矩陣]──►  R_wr G_wr B_wr     （參考白 → 錐反應）
② X_w  Y_w  Z_w   ──[3×3 矩陣]──►  R_w  G_w  B_w      （測試白 → 錐反應）
③ X    Y    Z     ──[3×3 矩陣]──►  R    G    B        （樣品 → 錐反應）

④ 算出白的比值：   R_wr/R_w ,  G_wr/G_w ,  B_wr/B_w

⑤ ★ von Kries 變換：
      R_c = (R_wr / R_w) · R
      G_c = (G_wr / G_w) · G
      B_c = (B_wr / B_w) · B

⑥ R_c G_c B_c  ──[逆矩陣]──►  X_c Y_c Z_c
```
> **★★ 投影片的六步驟與我上面寫的六步驟完全對應，只是順序稍不同**
> （投影片先算兩個白、再算比值、最後才處理樣品；我把樣品放在第③步）。
> **答題照投影片的順序寫最安全：白 → 白 → 比值 → 樣品 → 相乘 → 逆轉換。**
>
> **★★★ 為什麼要先算「兩個白」？** 因為 von Kries 原則的正規化條件就是「讓兩個白對齊」
> （見 L18 §3 那張 `VON KRIES PRINCIPLE` 投影片）。
> **整個變換的全部資訊，都藏在那三個比值裡。**

**★ von Kries 的核心假設（老師的原話）**：
> **「從一個照明體轉到另一個，唯一改變的是『白的 RGB 比值』，
> 而**這個比值本身不會改變**——所以我們可以直接算出 D65 下的 RGB。」**

（呼應 L18 的「只有曲線高度改變、形狀不變」。）

### 3-3 ★★★★ CAT02（現行標準）—— 投影片 `L19_s015 / s017 / s018` 給了完整的四步驟與全部矩陣
- **「後來我們有了更好的變換，叫 CAT02。現在大家都在用 CAT02。」**

**Step 1（投影片 `L19_s015_014m50s.png`）：轉到「銳化的」RGB**
```
Convert the sample tristimulus values, X, Y, Z to ★ SHARPENED R, G, B responses
by using the CAT02 forward matrix, M_CAT02

  ⎡R⎤            ⎡X⎤                        ⎡  0.7328   0.4296  −0.1624 ⎤
  ⎢G⎥ = M_CAT02  ⎢Y⎥      M_CAT02 =         ⎢ −0.7036   1.6975   0.0061 ⎥
  ⎣B⎦            ⎣Z⎦                        ⎣  0.0030   0.0136   0.9834 ⎦
```

**Step 2（投影片 `L19_s017_015m20s.png`）：算 D 因子**
```
Compute the ★ D factor, the degree of adaptation to the white point.
Equation: default value;  ★ full adaptation: D = 1;  no adaptation: D = 0.
L_A is the luminance of the adapting field in cd/m²;
★ F equals 1.0, 0.9, or 0.8, for AVERAGE, DIM, and DARK
  (projected image in very low ambient light) surrounds, respectively;
e = 2.71828.

              ⎡     1     −(L_A + 42)/92 ⎤
    ★ D = F · ⎢ 1 − ─── e                ⎥
              ⎣    3.6                   ⎦
```
| Surround | **F** |
|---|---|
| **Average**（一般，辦公室） | **1.0** |
| **Dim**（昏暗，家裡看電視） | **0.9** |
| **Dark**（全暗，電影院／投影） | **0.8** |

> **★★ D 因子的行為（自己代幾個數字進去很有感覺）**
> ```
> L_A → ∞（極亮）  : e^(−∞) → 0     ⇒  D → F        （最大適應 = F）
> L_A = 0（全黑）   : e^(−42/92) = e^(−0.4565) = 0.6336
>                    D = F(1 − 0.6336/3.6) = F × 0.824
> ```
> **★ 所以即使在全黑環境，D 也還有 0.82F，不會掉到 0** ——
> **模型假設「人總是至少適應了八成」**，這與 L18 §4 講的「部分適應」一致。
> **★ 而且 `D` 永遠 ≤ F ≤ 1 → CAT02 永遠不會「完全適應」，除非你手動設 D = 1。**
> （這正是 **L18 §5 的 CII 要特地寫明「D factor set equal to 1」** 的原因 ——
> 它要跳過這個公式，強制完全適應。）

**Step 3（同 `L19_s017`）：套用增益**
```
Obtain R_c, G_c, B_c, the R, G, B values for corresponding colour
(the subscripts ★ w and wr indicate the reference white in the FIRST and
 SECOND illuminants respectively):

   R_c = D_R · R      D_R = (Y_w/Y_wr)(R_wr/R_w) · D + (1 − D)
   G_c = D_G · G      D_G = (Y_w/Y_wr)(G_wr/G_w) · D + (1 − D)
   B_c = D_B · B      D_B = (Y_w/Y_wr)(B_wr/B_w) · D + (1 − D)
```
> **★★★ 這條式子的結構是「線性內插」，值得看清楚：**
> ```
> D_R = [ 完全 von Kries 的係數 ] × D  +  [ 1（完全不動） ] × (1 − D)
>         ↑ (Y_w/Y_wr)(R_wr/R_w)              ↑ 不適應
>
> D = 1  →  D_R = (Y_w/Y_wr)(R_wr/R_w)   純 von Kries   ✅
> D = 0  →  D_R = 1                       完全不變       ✅
> 0<D<1  →  兩者之間的線性混合            部分適應
> ```
> **★★ 「部分適應」在數學上就是「在『完全 von Kries』與『什麼都不做』之間內插」。**
> **這是 CAT02 相對於古典 von Kries 的核心創新**，也是它能處理
> **L18 §4 那六種色恆常失效情況**的原因。
>
> **★ 另一個新東西是 `(Y_w / Y_wr)`** —— 古典 von Kries 沒有這一項。
> 它負責**亮度水準的正規化**：兩個照明體的絕對亮度不同時，先把亮度比拉平。

**Step 4（投影片 `L19_s018_015m29s.png`）：轉回 XYZ**
```
   ⎡X_c⎤              ⎡R_c⎤                    ⎡  1.096124  −0.278869   0.182745 ⎤
   ⎢Y_c⎥ = M⁻¹_CAT02  ⎢G_c⎥    M⁻¹_CAT02 =     ⎢  0.454369   0.473533   0.072098 ⎥
   ⎣Z_c⎦              ⎣B_c⎦                    ⎣ −0.009628  −0.005698   1.015326 ⎦
```

### ★★★ 「Sharpened（銳化）」到底是什麼意思？（投影片 `L19_s016_015m09s.png`）
```
圖例：──── Sharpened sensitivities      （實線）
      ---- Typical cone sensitivities   （虛線）
橫軸 400–700 nm，縱軸 0–1.6
```
> **兩組曲線疊在一起比較，可以看到：**
> ```
> 銳化後的曲線（實線）：★ 更窄、峰值更高（達 1.6）、彼此更分離、且有明顯的負值區
> 真實錐細胞曲線（虛線）：較寬、重疊很多、全部為正
> ```
> **★★ 「銳化」= 讓三個通道彼此更獨立（重疊更少）。**
> **代價是矩陣裡出現負值元素（`−0.7036`、`−0.1624`），這在生理上不存在
> —— 沒有哪個細胞會給出負反應。**
>
> **★★★ 所以 CAT02 的 RGB 是「數學上的通道」而不是「生理上的錐細胞」。**
> 這是一個重要的觀念分野：
> ```
> HPE 矩陣（s014）  → 目標是「逼近真實錐細胞」   → 全部或幾乎全部為正
> CAT02 矩陣（s015）→ 目標是「把色適應算得最準」 → 允許負值，只求配適資料
> ```
> **★ 為什麼銳化會算得比較準？** 因為 von Kries 假設「三個通道各自獨立縮放」，
> **通道之間重疊越少，這個獨立性假設就越接近真實** → 預測誤差越小。
> **→ 「銳化」是為了讓 von Kries 假設站得住腳而做的數學前處理。**
>
> **⚠️ 但這也埋下了 CAT02 的地雷**：矩陣有負值 → 極端顏色可能算出負的 RGB
> → 後續的非整數次方運算會爆掉。**這正是 CAM16 要用 M16 取代 CAT02 的原因**（見 L17 出入第 3 條）。

- 最後同樣得到 **X_c, Y_c, Z_c**

## 4. 色不恆常指數 CII（重述，這次把 CAT 明確放進來）（00:15:45–00:17:15）

```
X_R Y_R Z_R   ：樣品在【參考照明體】下量到的 XYZ
X   Y   Z     ：樣品在【測試照明體】下量到的 XYZ
                     │
                     ▼  CAT（色適應變換）
X_c Y_c Z_c   ：預測出來的【對應色】

★ CII = (X_R Y_R Z_R) 與 (X_c Y_c Z_c) 之間的色差
```

**幾何圖示的三個點/兩個向量**：
```
參考點 ●─────────────────────────► ○ 測試點
       └─ Illuminant Colorimetric Shift（照明體色度位移）

測試點 ○ ────CAT────► ◆ 預測的對應色
                       └─ Adaptive Shift（適應位移）

★ 參考點 ● 與 ◆ 之間剩下的距離 = Colour Inconstancy（色不恆常）
   完全重合 → 色恆常
```

**用途**：**「拿來測試任何產品」**——出貨前的色恆常品管（見 L18 的 Adidas 例子）。

## 5. ★★★ CIE 演色性指數 CRI / Ra 的完整計算（00:17:45–00:23:20）

> **★ 老師的說明：「我把演色性放在最後講，因為它把所有東西都包含進去了。」**
> 確實——**SPD + 反射率 + CMF + CAT + 色差**，五樣全部用上。

### ★★★★ 投影片 `L18_s080_049m25s.png`「CIE Colour Rendering Index (CIE-Rₐ)」的流程圖（六個編號方塊）
```
   Test source                             Reference illuminant
   [SPD 圖]                    Planckian (CCT<5000 K)  │  Standard Daylight (CCT ≥ 5000 K)
        │                              [圖：燈泡]       │       [圖：太陽]
        ▼                                    └──────────┴──────────┐
   Test Source (SPD) ──▶ ┌───────┐ ──▶ ┌──────────────────┐        │
                         │1. CCT │      │2. Ref. ill (SPD) │◀───────┘
                         └───────┘      └──────────────────┘
        │                                        │
   ┌────────┐                                    │
   │  R%ᵢ   │（8 個測試色樣的反射率）             │
   └────────┘                                    │
        └──────────────▶ ┌────────────────────┐ ◀┘
                         │3. Calculating XYZ  │
                         └────────────────────┘
                            │              │
                        (XYZ)-T        (XYZ)-R
                            └──────┬───────┘
                            ┌──────────────┐
                            │ 4. vK-CAT    │   ← ★ von Kries 型色適應變換
                            └──────────────┘
                                   │
                              (XYZ)-TR
                                   │
                            ┌──────────────┐
                            │ 5. U*V*W*    │   ← ★ CIE 1964 U*V*W* 色空間
                            └──────────────┘
                                   │
                     ┌──────────────────────────────┐
                     │ ★ 6.  Rᵢ = 100 − 4.6 ΔEᵢ     │  ← 洋紅色方塊（投影片上被強調）
                     └──────────────────────────────┘
```
> **★★ 這張圖把 CRI 的六個計算階段編號標得清清楚楚，考試若要畫流程圖就照這個畫：**
> ```
> 1. CCT  →  2. Ref. ill (SPD)  →  3. Calculating XYZ  →  4. vK-CAT
>         →  5. U*V*W*          →  6. Rᵢ = 100 − 4.6 ΔEᵢ
> ```
> **★ 三個常被漏掉的細節**：
> **① 參考照明體的分岔條件寫在圖的最上方：`CCT < 5000 K → Planckian`、`CCT ≥ 5000 K → Standard Daylight`**
> **② 第 4 步明寫是 `vK-CAT`（von Kries 型），不是 CAT02** —— **CRI 是 1974 年的標準，用的是老式的 von Kries 變換**
> **③ 第 5 步是 `U*V*W*`（CIE 1964），不是 CIELAB** —— **這是 CRI 最被詬病的地方之一**（見文末出入第 3 條）
>
> **★★ 記憶點：CRI 用的是「1964 的色空間 + 1970 年代的 CAT」，而不是現代工具。**
> 這正是 **Rf（CIE 224:2017）** 要改用 **CAM02-UCS** 的原因。

### 5-1 計算步驟
```
【1】量測【測試光源】的 SPD

【2】計算測試光源的【CCT（相關色溫）】

【3】選定【參考光源】——必須與測試光源【同色溫】
     ★ CCT < 5000 K  →  用【Planckian radiator 黑體】
     ★ CCT ≥ 5000 K  →  用【D 系列日光照明體】

【4】取【8 個測試色樣（TCS, Test Colour Samples）】
     → Munsell 色票，【明度 Value 都是 6】、【中等彩度】、【色相各不相同】
       （紅、橙、黃、綠、藍、紫…）

【5】用 CMF 計算每個色樣在【測試光源】與【參考光源】下的 XYZ

【6】用【von Kries 型色適應變換】把兩者轉到相同的適應條件

【7】在【CIE 1964 U*V*W* 色空間】中計算色差 ΔE_i

【8】★ R_i = 100 − 4.6 · ΔE_i          （每一個色樣一個 R_i）

【9】★ Ra = (R_1 + R_2 + … + R_8) / 8   （8 個取平均）
```

**★★★ 投影片的緊湊寫法（`L19_s021` 等，完全等價，計算時更好用）**
```
   R_a = 100 − [4.6/8] [ d₁ + d₂ + d₃ + d₄ + d₅ + d₆ + d₇ + d₈ ]

   其中 d₁ … d₈ 是這八個 Munsell 色樣在 U*V*W* 中的色差：
   ★ 7.5R6/4 , 5Y6/4 , 5GY6/8 , 2.5G6/6 , 10BG6/4 , 5PB6/8 , 2.5P6/8 , 10P6/8
```
> **一句話理解 Rₐ：`100 減去「平均色差」的 4.6 倍`。**
> **★ 那個 `4.6` 是怎麼來的？** 它是一個**尺度化常數**，選定的目的是讓
> **「一支典型的暖白螢光燈」大約得到 Rₐ ≈ 50**（那個年代的參照點）。
> 換句話說 **`4.6` 沒有理論依據，是為了讓分數落在好看的區間而定的**
> —— 這也是 CRI 常被批評的一點（見文末出入第 3 條）。
> **★ 反推：ΔE = 1 → 扣 4.6 分；ΔE ≈ 21.7 → Rₐ = 0；ΔE > 21.7 → ★ Rₐ 會變成負數。**
> （低壓鈉燈的 Rₐ 就是負的，所以投影片的光源表上直接寫 `---`。）

**★ 判準**：
```
ΔE = 0  →  Ra = 100  →  在測試光源下看到的顏色，與在參考光源下完全一樣
```
老師的實例：**ΔE = 4.6 → R_i = 100 − 4.6×... = ...**（投影片上的數字示範）。

### 3. ★★★ CRI 的已知缺陷（這是現代照明產業最重要的爭議，老師沒展開）
| # | 缺陷 | 後果 |
|---|---|---|
| 1 | **Ra 只平均 8 個「中低彩度」色樣，不含 R9（飽和紅）** | **★ 一顆 LED 可以 Ra = 90，但 R9 是負的 → 紅色物體（肉、血、木頭、皮膚）看起來慘不忍睹** |
| 2 | **「平均」會掩蓋個別色樣的災難** | 7 個 95 分 + 1 個 30 分，平均仍有 87 |
| 3 | **用已廢止的 CIE 1964 U\*V\*W\* 色空間**（高度不均勻） | 色差計算本身就不準 |
| 4 | **用過時的 von Kries 型適應變換** | 與現代 CAT02/CAT16 差距明顯 |
| 5 | **參考光源隨 CCT 改變** | **★ 不同色溫的燈之間，Ra 不能互相比較**（2700K 的 Ra 90 與 6500K 的 Ra 90 不是同一回事） |
| 6 | **只評「忠實度（fidelity）」，不評「偏好」** | 有些光源會**增強飽和度**，人反而更喜歡，但 CRI 會扣分 |

**補充缺陷（2026-08 查證新增）**：
- **★ CRI 在 5000 K 處是「不連續的」**——因為參考光源在此切換（黑體 ↔ D 系列）。這比「不同色溫不能互比」更精確
- **「CRI 對 5000 K 以下的光源特別不適合做視覺評估」**
- 只有 8 個色樣 → **廠商可以針對這 8 個色樣「優化光譜」刷分**
- **CRI 上一次更新是 1974 年**

**現代的替代方案**：
- **CIE 224:2017 —— Rf（保真度指數）**：99 個色樣、CAM02-UCS 色空間、CAT02
- **★ IES TM-30-20 —— Rf（保真度）+ Rg（色域指數）**：99 個色樣，**Rg 描述「飽和度是被壓縮還是被放大」**，並附 **Color Vector Graphic**
- **CQS（Colour Quality Scale, NIST）**、**GAI（色域面積指數）**、**CRI2012**、**TLCI**（影視專用）

### ★★★ 2025 年 1 月：CIE 已正式建議停用 CRI

> **CIE Position Statement on Colour Quality Metrics（2025 年 1 月）**
> **CIE 正式建議照明產業，從過時且有時不準確的 CRI (Ra)，
> 轉換到 CIE 224:2017 定義的 General Colour Fidelity Index (Rf)。**

**CIE 自己列的三個理由**：
1. **使用過時的色空間（CIE 1960）**
2. **只用 8 個色樣**
3. **★ 對窄帶發光體（LED）特別有問題**

**重要細節**：
- **CIE 224:2017 的 Rf 與 IES TM-30-18 的 Rf 已完全一致（harmonized）** —— 兩大體系整合完成
- **但這份聲明只談保真度，沒有納入 TM-30 的 Rg 或 Preference Design Intent**
- **TM-30 的完整做法仍是 Rf + Rg 雙指標**

> **★ 對本節的影響：這整節在教的 Ra，CIE 自己已經建議停用了。**
> **課程仍要學**（它是歷史基礎，也還存在於法規與產品標示中），

**實務建議（更新版）**：買 LED 至少看 **Rf + Rg + R9**；若只拿得到 Ra，**務必額外索取 R9**。

### 4. CAT02 矩陣有負值的意義（老師只說「有些是負的」）
```
CAT02 的 M_CAT02 矩陣：
  [ 0.7328   0.4296  −0.1624 ]
  [−0.7036   1.6975   0.0061 ]
  [ 0.0030   0.0136   0.9834 ]
```
- 這叫 **sharpened cone responses（銳化錐反應）**——**刻意讓三條靈敏度曲線比真實錐細胞更窄、更分離**。
- 目的：**讓 von Kries 型的「各通道獨立乘增益」在數學上更有效**（通道間越不重疊，獨立縮放的假設越成立）。
- **代價**：極飽和色可能算出**負的錐反應**，導致模型不穩定 → **這正是 CAM16 改用 CAT16 的理由**（見 L17）。

### 5. D 因子（老師提到 CAT02「有 D 因子」，補上式子）
```
D = F · [ 1 − (1/3.6) · exp( (−L_A − 42) / 92 ) ]
```
- **D = 1 → 完全適應**；**D = 0 → 完全不適應**
- **這是 von Kries 型變換做不到的事**——傳統 von Kries 隱含假設「永遠完全適應」。
- 實務上看螢幕時 **D 通常只有 0.6–0.9**（部分適應到室內環境光），這是螢幕白點校正常出問題的原因。

### 6. 「越省電、色彩品質越差」有例外
- 老師這句在**傳統光源**（鈉燈、螢光燈）上完全成立。
- **但 LED 打破了這個規律**：
  - 現代高演色 LED 可同時做到 **Ra > 95** 與 **效能 > 100 lm/W**
  - 不過**仍然有取捨**：要高 Ra 就要加紅色螢光粉（在 620–660 nm），而**那個波段的視覺效率低** → 效能會掉 **10–25%**
- **所以本質的取捨還在，只是整條曲線被 LED 往上推了。**
