## 1. 物體的三種型態（00:01:31–00:03:01）★ 必考

| 型態 | 定義 | 例子 |
|---|---|---|
| **Opaque 不透明** | 光**無法穿透**，全靠反射 | 布料、印刷品、塗料 |
| **Transparent 透明** | 光穿透，**進出強度接近相同** | 清水、玻璃、彩色溶液 |
| **Translucent 半透明** | **一部分反射、一部分穿透**，最複雜 | 塑膠、皮膚、牛奶、玉、紙 |

老師註記：translucent 最麻煩，因為顏色不是只從單一表面反射出來的。

## 2. 折射率 Refractive Index 與 Snell's Law（00:03:01–00:06:30）

**定義方式**：光從空氣（n₁ ≈ 1.0003）以 45° 入射，進入材料後折射成 28°：
```
n₁ · sin θ₁ = n₂ · sin θ₂
→ n₂ = sin45° / sin28° ≈ 0.707 / 0.469 ≈ 1.51   （典型玻璃/樹脂）
```
（常被寫成 "snail's law"，正確是 **Snell's law**。）

**常見材料折射率（老師投影片上的表）**：

**（2026-08-26 由教材 逐字核對，數值全部確認）**

| 材料 | **n（投影片值）** | 備註 |
|---|---|---|
| Vacuum 真空 | **1.0000** | |
| Air 空氣 | **1.0003** | 幾乎等於 1 |
| **Vinyl resin 乙烯樹脂** | **1.48** | 透明基質（常被誤寫成 "linear resin"，實為 **vinyl**） |
| **BaSO₄** 硫酸鋇 | **1.64** | 白 |
| **ZnO** 氧化鋅 | **2.02** | 白 |
| **ZnS** 硫化鋅 | **2.37** | 白 |
| **TiO₂ (A) 銳鈦礦 anatase** | **2.55** | 白 |
| **TiO₂ (R) 金紅石 rutile** | **2.76** | **最白、遮蓋力最強** |

**老師要你看懂的關鍵**：白色顏料的共同點是**折射率高**。
> **折射率與周圍樹脂差越大 → 散射能力越強 → 越白、遮蓋力越好。**
所以 TiO₂ rutile 是工業上最主流的白色顏料。

**塗料 = 樹脂（resin, 樹脂）＋ 顏料（pigment, 色料）**。混合比例決定它偏向 **scattering power（散射力）** 還是 **absorption power（吸收力）**。

## 3. Fresnel 反射：光澤到底有多少（00:07:30–00:08:32）

**Fresnel's law（垂直入射）**：
```
ρ = ( (n₂ − n₁) / (n₂ + n₁) )²
```
以 n₂ = 1.5、n₁ = 1 代入 → **ρ ≈ 0.04，也就是 4%**。

**這 4% 的意義**：任何塑膠/塗料/玻璃表面，都有約 **4% 的光在表面被直接鏡面反射掉**，這部分**不帶物體顏色**（第一界面反射）。這正是：
- 為什麼 SPI 與 SPE 量出來會差一截
- 為什麼「濕的東西看起來顏色比較深」（水填平表面，減少第一界面散射）
- 為什麼深色樣品的色差量測特別受光澤影響

## 4. 表面型態分類（00:08:32–00:10:01）

| 類型 | 行為 |
|---|---|
| **Mirror 鏡面** | 進來多少、以鏡面方向出去多少（理想化 100%） |
| **Matte 全霧面** | 完全漫反射；**不管哪個角度看都一樣**（如紡織品） |
| **Semi-matte / 部分光澤** | 大多數真實材料：一部分鏡面 + 一部分漫射，**換角度看就會出現光澤** |

老師的考題形式：「**有幾種表面型態？**」→ 鏡面、霧面、半光澤（部分漫反射）。

## 5. 透射材料與 Lambert–Beer 定律（00:11:02–00:16:35）★ 必考

**量測前提（老師列的假設）**：
1. 有色溶液**吸收光**
2. **吸收量取決於濃度**
3. 吸收曲線的**形狀取決於化合物本身**（跟反射率曲線很像）
4. **單色平行光垂直射入 cell 壁**（parallel in, parallel out，只是變弱）

**穿透的指數衰減（直觀示範）**：
每 1 cm 透過 50% →
`1 cm: 50% → 2 cm: 25% → 3 cm: 12.5% → 4 cm: 6.25%`
**穿透率隨厚度呈指數下降，不是線性。**

**Lambert–Beer Law**：
```
A = ε · c · l
A = log₁₀(100 / T%)  =  log₁₀(I₀ / I_T)
```
- **A** = absorbance 吸光度
- **ε** = extinction coefficient 消光係數（材料本身的特性常數；常被誤植為 "extinguished constant"）
- **c** = concentration 濃度
- **l** = cell length 光徑長度

**兩個關鍵性質**：
1. **A 對 c 呈良好線性關係**（固定 l、ε 時，斜率就是 εl）
2. **A 具有加成性（additive）**
   → 這是**配色（colour formulation / recipe prediction）能用數學求解**的根本原因。

### ★ 加成性的正式寫法（教材「Calibration curve」）
```
單一化合物：      A = e · c · l

★ 兩種化合物混合 (A & B)：
   A_λ  =  e_A,λ · c_A · l  +  e_B,λ · c_B · l

                                     （在同一個波長 λ 下）
```
> **關鍵在於每個化合物「在該波長」有自己的 e**。
> 投影片的校正曲線圖畫的是 **吸光度 vs 濃度**的兩條不同斜率直線——**斜率就是 e·l**。
> 注意投影片用 **e** 而非 ε，並定義為 *"Constant for a particular compound at a particular wavelength"*。

## 6. Kubelka–Munk 理論（00:16:35–00:21:47）

**問題背景**：用顯微鏡看塗層 → 樹脂裡佈滿顏料顆粒。光進去之後在顆粒間**反覆散射、來回反彈**，極度複雜。

**KM 的策略**：**把複雜問題簡化**——只考慮**上、下兩個方向的光通量（two-flux）**。

### ★ 投影片「Fluxes at a turbid medium」的完整符號
```
        ┌───────────────────────────────┐
   D    │  i(x) ↓      S·i(x)dx ↑       │   D  = 總厚度
   x ───┤              K·j(x)dx ↓       │   x  = 深度
   dx   ├ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┤   dx = 微薄層
        │  K·i(x)dx ↓  S·j(x)dx ↑       │
        └───────────────────────────────┘   j(x) ↑ 上行通量
```
| 符號 | 意義 |
|---|---|
| **i(x)** | **向下（入射方向）的光通量** |
| **j(x)** | **向上（返回方向）的光通量** |
| **K** | **absorption coefficient 吸收係數** |
| **S** | **scattering coefficient 散射係數** |
| **K·i(x)dx** | 下行通量在 dx 內**被吸收**的量 |
| **S·i(x)dx** | 下行通量在 dx 內**被散射成上行**的量 |
| **K·j(x)dx / S·j(x)dx** | 上行通量的對應項 |

**微分方程對 dx 積分 → 得到漫反射率 R∞。**

**另一張投影片**（教材「Microscopic view of a light reaching a translucent medium」）
畫出顏料顆粒散布在介質中，標示：**Incident Light、Specular Reflection、Diffuse Reflection、Backing、Diffuse Transmission** —— 這是 KM 要簡化的「真實」情況。

**核心關係式（老師只帶過概念，標準式為）**：
```
K/S = (1 − R∞)² / (2 R∞)
```
（R∞ = 無限厚不透明層的反射率）

**為什麼重要**：K/S 也具**加成性**，所以「已知各色料的 K/S → 反推要放多少比例才能配出目標色」，這就是**電腦配色（CCM）**的理論基礎。紡織、塗料、塑膠業全靠它。

（常被誤植為 "Quebec Monk"，正確是 **Kubelka–Munk**。）

## 🔍 與標準說法的出入 / 需要留意

1. **「鏡面 = 100% 進、100% 出」**
   - 是理想化。真實鍍鋁鏡約 **88–92%**，增強鍍銀鏡約 **95–98%**。教學用近似。

2. **Fresnel 4% 的適用條件**
   - `ρ = ((n₂−n₁)/(n₂+n₁))²` 是**垂直入射**的特例。
   - 入射角變大時 ρ 急遽上升（掠角接近 100%），且**偏振態會分離**（s 偏振 vs p 偏振，Brewster 角）。老師講的 4% 只在近垂直時成立。
   - 另外此式假設材料**無吸收（k=0）**；金屬要用複折射率，結論完全不同（見 L01 出入第 4 點）。

3. **Lambert–Beer 的失效條件（老師沒講，但實務常踩）**
   - 高濃度時**偏離線性**（分子間交互作用、締合）
   - 樣品**有散射**（懸浮、混濁）時整套式子不成立
   - 必須是**單色光**；若頻寬太寬，吸收峰陡的樣品會產生假的非線性
   - 螢光樣品會加光回來，A 被低估

4. **Kubelka–Munk 的限制**
   - 假設：**完全漫射的照明與樣品內部光場、光只有上下兩方向、樣品側向無限大、無鏡面/第一界面反射**。
   - 實務上要另加 **Saunderson correction** 修正第一界面反射（也就是第 3 節那 4%）才會準。
   - **單常數 KM（single-constant）** 只適用於「白 + 一種色料」的染色業；**塗料/塑膠要用雙常數（two-constant，K 與 S 各自獨立）**。
   - 老師此節只講到概念，沒展開這些前提；實際做配色時這些前提就是誤差來源。

5. **折射率表的細節**
   - 老師沒說明 TiO₂ 的 A 型 / R 型是什麼。**A = anatase 銳鈦礦（n≈2.55）、R = rutile 金紅石（n≈2.7）**。
   - Rutile 折射率高、遮蓋力強、耐候佳，是主流；anatase 光催化活性強，會加速樹脂粉化（chalking），所以外用塗料不用它。這個實務差異值得記。
