# 「老師講法 vs 標準說法」總彙整
把 19 節課裡所有「出入之處」集中在這裡，依**性質**分 **A–H 八類**。
**考試以老師教材為準；做研究、寫論文、寫程式以本表右欄為準。**

| 類 | 內容 | 怎麼用 |
|---|---|---|
| **A** | 明確的口誤或錯誤 | **必須更正**（其中 A12、A13、A16 已由投影片翻案） |
| **B** | 教學簡化 | 方向對但不精確 |
| **C** | 老師的研究立場 | 教科書不一定有，但很有價值 |
| **D** | 老師沒講但實作必備的補充 | 寫程式 / 寫論文時看 |
| **E** | 2021 年之後的發展 | 課程已過時的部分 |
| **F** | **投影片本身印錯**（20 項） | **★ 老師照唸沒錯，是教材的錯 —— 考試照投影片，實作用正確版** |
| **G** | **投影片對、老師口述錯**（11 項） | **★ 以投影片為準** |
| **H** | **只有抽投影片才有、課堂沒講的內容**（3 項） | **★ 課堂上沒有講到，額外收穫** |

# A. 明確的口誤或錯誤（需要更正）

| # | 老師的說法 | 正確 | 出處 |
|---|---|---|---|
| A1 | **「瞳孔（pupil）有顏色，有藍色綠色灰色」**（講了兩次） | **有顏色的是虹膜 iris；瞳孔是開孔，永遠是黑的** | L02, L07 |
| A2 | **D65 白點座標唸成 0.346 / 0.359** | **那是 D50 2°（0.3457, 0.3585）。D65 2° 是 (0.3127, 0.3290)** | L02 |
| A3 | **「燈泡發黑是過度氧化（over-oxidization）」** | **是鎢絲高溫昇華沉積在玻璃上**。燈泡內是真空或惰性氣體，沒有氧可以氧化。理解成氧化會使鹵素循環的原理說不通 | L06 |
| A4 | **「燈絲加熱到 3700 K」** | **鎢的熔點就是 3695 K**。實際工作溫度：一般燈泡 2700–2900 K、鹵素 2900–3200 K | L06 |
| A5 | **汞譜線 405 / 436 / 456 / 577 nm** | **沒有 456。應為 546.1 nm（綠）**，這是螢光燈光譜上最顯眼的一根線 | L06 |
| A6 | **「左眼 → 右腦、右眼 → 左腦」** | **不是以「眼睛」分，是以「視野」分**。鼻側視網膜纖維在視交叉處交叉 → **兩眼的左半視野都送右腦** | L07 |
| A7 | **「桿細胞峰值 555 nm / 600 nm」**（口述時說混了） | **明視覺 V(λ) 峰 555 nm；暗視覺 V′(λ) 峰 507 nm**。這 48 nm 的差就是 **Purkinje shift**，也是夜視偏藍的原因 | L18 |
| A8 | **「亮度 CSF 是 high-pass」**（前面講對是 band-pass，後面口誤） | **亮度 CSF 是 band-pass 帶通**（峰 3–5 CPD）；**色度 CSF 才是 low-pass** | L14 |
| A9 | **Weber 定律「1990 年代」** | **1834 年**。順序：Weber 1834 → Fechner 1860 → Thurstone 1927 → Torgerson 1954 → Stevens 1957 | L09 |
| A10 | **「1 個 z ≈ 65%」** | **68.27%**（±1σ）；±2σ = 95.45%；**95% 對應 1.96σ**（他後面用 1.96 是對的） | L09 |
| A11 | **Hering 是「德國化學家」** | **德國生理學家（physiologist）**，1834–1918 | L11 |
| ~~A12~~ | ~~**NCS 是「瑞典、挪威、葡萄牙」的標準**~~ | **★ 2026-08-26 翻案 → 移至 F8**。教材「NCS - Summary」原文就寫 `Sweden, Noway and Portugal`，**老師照唸，不是口誤**（標準說法仍是 Spain） | L11 |
| ~~A13~~ | ~~**「Ostwald 系統是瑞士標準」**~~ | **★ 2026-08-26 解謎**：教材「Ostwald - History」最後一列寫 **`1960 Swiss Color Atlas 2541`** → 老師指的是這本**瑞士色彩圖冊**，不是「瑞士國家標準」。Wilhelm Ostwald 本人是**德國**化學家（1909 諾貝爾化學獎）；美國實作是 *Color Harmony Manual*；**DIN 6164 才是德國標準** | L12 |
| A14 | **OSA-UCS 委員會「1969/1930」** | 兩個不同委員會：**OSA Colorimetry Committee（1930s–1943）→ Munsell Renotation**；**OSA Committee on Uniform Color Scales（1947 成立）→ OSA-UCS（1974/1977）** | L12 |
| A15 | **OSA-UCS 是「dodecahedron 十二面體」** | **12 個等距鄰居構成 cuboctahedron（截半立方體）**；十二面體有 12 面但 20 頂點 | L12 |
| **A16** | **MacAdam 的觀察者叫 "Peter Lutin"** | ✅ **2026-08-26 由投影片直接證實**：教材「Non-uniformity (MacAdam Data, 1942)」上明文寫著 **"25 colour centres / One observer (PGN) / Visual colorimeter / JND – Just noticeable difference"** → **PGN = Perley G. Nutting Jr.**；「Peter Lutin」是聽寫時的誤植 | L13 |
| A17 | **MacAdam「右眼看一個、左眼看另一個」** | 用的是**雙眼觀看的二分視野視覺色度計**，不是分眼觀看 | L13 |
| **A18** | **CRI 用「10° 色匹配函數」** | ✅ **2026-08-26 查證結案：錯。CIE 13.3 程序第一步明文寫 *"Using the 2° standard observer…"* → 全程用 CIE 1931 2°**。其餘步驟（von Kries CAT、CIE 1964 U\*V\*W\*、R_i=100−4.6ΔE_i、Ra 為 8 色樣平均、5000 K 分界）老師都講對了 | L19 |
| A19 | **「NCS 有 14,012 個色樣」** | **1,412 個**（Edition 1）；Edition 2 約 **1,750** 個 | L11 |
| **A20** | **「Stiles & Burch 18 位」** | ⚠️ **2026-08-26 修正我自己的歸因**：這**不是**口誤——**教材本身就寫 "Stile & Burch - 18 obs (1959)"**。<br>**通行文獻是 49 人**（1959 年 10° 大視野研究；1955 年的 2° 前導研究才是 10 人）。**Wright 10、Guild 7、Speranskaya 27 則投影片與文獻一致。**<br>**考題照投影片寫 18，論文寫 49。**（記錄裡的「4549」是把 45/49 之類的數字黏在一起） | L02 |

# B. 教學簡化 —— 方向正確但不精確（考試可用，實作要補足）

| # | 老師的簡化 | 完整說法 | 出處 |
|---|---|---|---|
| B1 | **「CIE 分成 1931 系統（ABC）與 1964 系統（D）」** | **1931/1964 的正式意義是「2° 標準觀察者」與「10° 補充標準觀察者」**，不是照明體分期。時間點吻合但概念層次不同 | L01 |
| B2 | **可見光 380–780 / 400–700 混用** | CMF 完整定義域 **360–830 nm**；實用表格 380–780；工程實務 400–700。**三個數字要分清場合** | L01 |
| B3 | **「照明體 B 現在很少用」** | **B 已被 CIE 正式廢止（obsolete）**；C 則仍保留於少數產業（Munsell、部分塗料、牙科） | L01 |
| B4 | **「鏡面反射永遠是白色」** | 對**介電質**成立（Neutral Interface Reflection 假設）；**對金屬不成立**——金屬的鏡面反射帶色，所以金屬漆要用多角度分光儀 | L01 |
| B5 | **「三原色等量相加匹配 D65 白」** | **CIE 1931 RGB 系統的正式定義是匹配「等能白 Illuminant E」** | L02 |
| B6 | **激發純度 = 彩度、主波長 = 色相** | 那是**色度圖上的幾何量**，不是感知量。已知偏差：**Abney effect**（加白後色相偏移）、**Bezold–Brücke effect**（改亮度色相偏移） | L02 |
| B7 | **「RGB 螢幕在青綠區不準是因為 CMF 有負值」** | 更精確：**三個實體原色張的三角形無法涵蓋整個馬蹄形** → 這是**色域限制**，不是 CMF 的缺陷 | L02 |
| B8 | **Fresnel「4%」** | 只在**近垂直入射**且**材料無吸收**時成立；入射角變大時 ρ 急升，且偏振態分離（Brewster 角） | L03 |
| B9 | **「鏡面 100% 進、100% 出」** | 真實鍍鋁鏡約 88–92%，增強鍍銀約 95–98% | L03 |
| B10 | **Lambert–Beer 直接可用** | **失效條件**：高濃度非線性、樣品有散射、光源非單色、樣品有螢光 | L03 |
| B11 | **Kubelka–Munk 概念** | 前提：完全漫射光場、光只有上下兩方向、樣品側向無限大、無第一界面反射。**實務要加 Saunderson correction**；**染色業用單常數 KM，塗料/塑膠要用雙常數** | L03 |
| B12 | **蝦蟹煮熟變紅 = thermochromism** ⚠️ | **thermochromism 定義是「可逆」的溫度變色**。蝦蟹變紅是**不可逆的蛋白質變性**。色度學裡真正的 thermochromism 是某些染料在燈的熱下**可逆偏色** | L04 |
| B13 | **三刺激值色度計「x̄ 短波副峰 ≈ z̄/4」** | 業界慣用比例約 **0.17–0.2**，不是 0.25 | L04 |
| B14 | **「量表面色一定要接觸式」** | 過於絕對。非接觸式分光儀存在（濕樣品、線上檢測）。他自己講脈衝氙燈時也說「強度高所以可做非接觸量測」——前後矛盾 | L04 |
| B15 | **多角度只有 25/45/75/110 四角** | **現行標準（ASTM E2194 / DIN 6175-2 / ISO 18314）是五個離鏡角：15/25/45/75/110**，其中 **15° 對判別金屬感（flop）最關鍵** | L04 |
| B16 | **「Type A = 隨機誤差、Type B = 系統誤差」** ⚠️ 重要 | **GUM（ISO/IEC Guide 98-3）刻意廢棄了隨機/系統二分法**：**Type A = 用統計方法評估**、**Type B = 用其他方法（校正證書、規格書、經驗）評估**。分類依據是「怎麼評估」不是「誤差性質」 | L05 |
| B17 | **Spectralon 反射率 95–96%** | **Spectralon（燒結 PTFE）在 400–1500 nm 約 99%**；BaSO₄ 約 98%。但老師指出的核心問題（半透明、會漏光、會老化）完全正確 | L05 |
| B18 | **「Metamerism 是因為其中一個樣品色不恆常」** | 更嚴謹：**同色異譜的破裂量 = 兩樣品各自「色不恆常向量」之差**。兩者可以都不恆常，只要方向大小相同就仍相配 | L05, L15 |
| B19 | **鎢絲燈效率「20%」** | 白熾燈**光視效能約 15 lm/W**（理論極限 683）→ **整體效率約 2–3%**。他表格裡的「20」是 lm/W 不是百分比，講課時把兩個數字混了 | L06 |
| B20 | **「地面日光少了藍光」與「D65 比黑體藍」** | 要分三種光：**直射日光**（藍被散射掉→偏黃）、**天空光**（藍被散射進來→極藍）、**全球日光 = 太陽+天空**（CIE D 系列描述的是這個，所以含豐富 UV） | L06 |
| B21 | **CRI「跟日光比」** | **CCT < 5000 K → 跟同色溫的黑體比；≥ 5000 K → 跟同色溫的 D 系列比** | L06, L19 |
| B22 | **LED 壽命 100,000 小時** | 那是晶片理想值。**實際燈具 L70 壽命通常 25,000–50,000 小時**，受限於驅動電源與散熱 | L06 |
| B23 | **「六個 unique hues」** | **標準是四個唯一色相：紅、黃、綠、藍**（Hering）。白與黑不是色相，是無彩軸兩端 | L07 |
| B24 | **「褐色 = 紅 + 黃」** | 更關鍵：**褐色是「低亮度的橙色」，且只能以 related colour 存在**。單獨放在全黑背景中會變成橘色 | L07, L16 |
| B25 | **「最常見的色覺異常是紅移到綠」** | **最常見是 Deuteranomaly 綠色弱（M 錐往 L 移），約佔男性 5%** | L08 |
| B26 | **「色覺異常主要發生在男性」** | **只適用於紅綠系（X 性聯）**。**Tritan（藍）是第 7 對體染色體遺傳，男女比例相同**，且極罕見（~1/10,000） | L08 |
| B27 | **色覺異常「8% 男性」** | 那是**北歐/白人男性**。**東亞男性約 4–5%**，非洲裔 3–4% | L08 |
| B28 | **Fechner「1850」** | **1850 是靈感日（Fechner Day）；正式出版《Elemente der Psychophysik》是 1860 年** | L09 |
| B29 | **「觀察者永遠用 100 人」** | 適用於偏好/影像品質研究。**CIE 視覺色差資料集通常 20–40 人但重複次數多**；CIE 建議至少 20 人。決定人數的是「你要估什麼」 | L10 |
| B30 | **「偏好沒有經驗的觀察者」** | 是一個**立場**不是通則。做**色差容差**研究時業界常用**受訓評色員**，因為觀察者間變異小得多。取決於你要測「一般人知覺」還是「專業判準」 | L10 |
| B31 | **Munsell「40 個色相」** | 完整系統 **10 主色相 × 10 = 100 個**；市售圖譜常用 40 個（每 2.5 單位一張） | L11 |
| B32 | **「CIELAB 基於 Munsell」** | 更精確：**CIELAB 是為了逼近 Munsell renotation 的間隔而設計**，直接前身是 **Adams–Nickerson chromatic value space (ANLAB)** | L11 |
| B33 | **「ΔE > 3 就 fail」** | 只是一個例子。實際容差因產業而異：高階顯示器/影像 ΔE₀₀ < 1–2；紡織 CMC(2:1) < 1；汽車內裝常 < 1 | L13 |
| B34 | **「嚴格說色差公式只能用在塗料」** | 技術上正確但實務上會嚇到人。正確心態：**知道你偏離參考條件多遠，然後用 parametric factors 補**（紡織用 CMC(2:1)、影像用 ΔE₀₀(2:1:1)、色域映射用 CAM02-UCS） | L14 |
| B35 | **PF/3 當評估指標** | **CIE 現在建議用 STRESS**（García, Huertas, Melgosa & Cui, 2007），因為有明確統計意義、可做 F 檢定 | L14 |
| B36 | **記憶色「更亮且更鮮豔」** | 最穩健的結論是**「更飽和 / 彩度更高」**；明度方向因物體而異（天空、草地的記憶色可能更暗） | L16 |
| B37 | **「saturation 可用於機器視覺辨識物體」** | 在**同一光源、只有強度改變（陰影）**時成立；**光源顏色改變時 saturation 也會變**。完整解法需要色恆常演算法或多光譜影像。HSV 的 S 也不等於 CIECAM02 的 s | L16 |
| B38 | **Y_b「0.18」** | **CIECAM02 的 Y_b 要以「相對於白 = 100」的百分比輸入 → 填 20（或 18），不是 0.18**。填 0.18 會算出離譜結果 | L17 |
| B39 | **明視覺/暗視覺分界用 lux** | **CIE 正式定義用亮度 cd/m²**：photopic > 約 3–5、scotopic < 約 0.005、mesopic 在中間 | L18 |
| B40 | **「越省電、色彩品質越差」** | 在傳統光源成立。**LED 打破了這條規律**（可同時 Ra > 95 且 > 100 lm/W），但**取捨仍在**：加紅色螢光粉（620–660 nm）會掉 10–25% 效能 | L19 |

# C. 老師的研究立場 / CIE 內部動態（教科書上不一定有）

| # | 立場 | 說明 | 出處 |
|---|---|---|---|
| **C1** | **「CIE 1931 2° 色匹配函數有問題，我們正在推廣 CIE 2006 CMF」** | 已知缺陷是**短波（藍紫）區靈敏度被低估**。歷史修正 Judd(1951) → Vos(1978) → **CIE 170-1:2006 / 170-2:2015 錐細胞基礎 CMF**。CIE 2006 提供**連續視野（2°–10° 任意值）**與**年齡相關**。實務衝擊最大的是**窄帶光源（LED/OLED/雷射）**。**但所有工業標準、色差公式、ICC 色彩管理仍建立在 1931/1964 上** → 考試以舊版為準 | L05, L08 |
| **C2** | **「整個現代色度學建立在 1920 年代 17 個英國人的視覺上」** | 老師誠實承認「它不代表全世界」。這是他推動 CIE 2006 CMF、以及**在實驗室重建多通道色匹配設備**的根本動機 | L02, L16 |
| **C3** | **「未來需要的是光譜複製（spectral reproduction）」** | 他的結論：所有跨媒體問題的根源都是同色異譜，只有回到光譜層級才能根治。這是他研究團隊現在的主軸 | L16 |
| **C4** | **「算色差用 CIEDE2000；要色空間別用 CIELAB，用 CAM02-UCS」** | **CIEDE2000 是距離公式不是色空間**：不滿足三角不等式、色相角 0°/360° 處不連續、中性軸附近不平滑 → 不能拿來做內插、聚類、色域映射 | L13, L14 |
| **C5** | **判斷「均勻色空間」的兩個標準**（他當場考學生，只答一個給 50 分） | **① 每個橢圓要接近正圓 ② ★ 所有橢圓的大小在各色區要一致**。CIELAB 的大小差約 10 倍 | L14 |
| **C6** | **影像色差 K_L 應設 2** | **ΔE₀₀(2:1:1)**：明度差的重要性只有彩度/色相差的一半。多個獨立資料集（含北京印刷學院）驗證 | L14 |
| **C7** | **CIECAM97s → CIECAM02 的三個具體理由** | ① 黑的 lightness 不等於 0 ② 近中性色的 chroma 不等於 0 ③ **亮度改變時 saturation 應保持不變，但 CAM97s 在低亮度變化很大** | L17 |
| **C8** | **「相機的 SSF ≠ 人眼 CMF」= observer metamerism** | 把相機當成另一個觀察者。這個框架貫穿他的影像量色研究（DigiEye 系統） | L04, L05, L15 |
| **C9** | **「CIELAB 也是色貌模型」** | 教學上很好用（都是 XYZ + 白點 → 屬性）。但 CIELAB 只做「白點除法」，缺 L_A、Y_b、surround，且在 XYZ 空間除法是 **"wrong von Kries"** | L14, L17 |
| **C10** | **「Ostwald 停產是因為 full colour 定義在最飽和顏料上」** | 新顏料年年出現 → 系統天天過期 → 跟不上、太貴 → 停產。**反觀 NCS 的 full colour 是想像的、不印出來，所以永遠不會過期**。設計哲學決定產品壽命 | L12 |
| **C11** | **「反射率是物體的指紋」** | 反覆強調：能傳反射率就傳反射率，比傳 XYZ 更好。因為有反射率就能算任意照明體下的顏色、能做電腦配色 | L05, L12 |
